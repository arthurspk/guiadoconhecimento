## 🔎 Como a lista é montada

> A seleção é automática e reproduzível; nada é escrito à mão.

- As consultas de cada profissão ficam em `data/repos-ia-consultas.json`, agrupadas por tema.
- O script `scripts/coletar_repos_ia.py` consulta a busca pública do GitHub e ordena por estrelas.
- Só entram repositórios ativos, com descrição, com sinal claro de IA no nome, na descrição ou nos tópicos, e fora de uma lista de bloqueio (conteúdo adulto, pirataria, trapaça).
- As estrelas são as do dia da coleta. Um repositório pode aparecer em mais de uma profissão.
