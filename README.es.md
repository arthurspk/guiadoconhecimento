<h1 align="center">Guia do Conhecimento</h1>

## 🎯 La propuesta

> **Guia do Conhecimento** es un mapa de conocimiento abierto y gratuito: **55357 links** organizados en **9 sectores**, **72 áreas** y **38 profesiones**, para que **cualquier persona** encuentre los mejores sitios, cursos, herramientas, repositorios, listas awesome, comunidades y utilidades de su área: desarrollo, datos, seguridad, diseño, edición de video, cine, fotografía, música, marketing, tráfico pago, ventas, finanzas, derecho, salud, ciencia, educación, idiomas y mucho más. Cada área empieza con **esenciales elegidos a mano**, incluye una sección de **inteligencia artificial aplicada a esa profesión** y continúa con los links de las mejores listas curadas de la comunidad. Además, cada profesión tiene **1000 repositorios de IA**. Todo link tiene descripción, y la guía completa está en **12 idiomas**.

- 🗂️ [Catálogo de áreas](i18n/es/areas/CATALOGO.md): las 72 áreas, por sector, con el conteo de links.
- 🧭 [Rutas por profesión](i18n/es/trilhas/README.md): 38 rutas, desde desarrollador front-end hasta filmmaker, desde gestor de tráfico hasta docente.
- 🧠 [Repositorios de IA por profesión](i18n/es/ia/profissoes/README.md): 38000 repositorios de IA, 1000 para cada profesión.

## 💡 Cómo está organizada esta guía

> Tres niveles, de lo general a lo específico: **sector** (ej.: Diseño y Creación) → **área** (ej.: Edición de Video) → **tema** (ej.: Editores no lineales). Cada área es una página con índice, una sección **⭐ Empieza por aquí**, una sección **🤖 IA** y los temas ordenados de mayor a menor, cada uno con su descripción. Todo proviene de una base de datos abierta (`data/links.jsonl`) y se genera con scripts en Python, así que la guía completa se puede regenerar, validar y ampliar. La organización sigue la de las guías [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) y [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Scripts disponibles

> Todo se genera con Python. Ninguna página se edita a mano.

| Script | Qué hace |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Descarga las listas curadas (Scrapling, con git como respaldo) y extrae cada link con nombre, descripción y tema. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normaliza, deduplica, aplica la política de licencias, exige descripción y elige los links de cada área con tope y rotación entre fuentes. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Busca en GitHub los repositorios de IA de cada profesión, 1000 por profesión. |
| [`scripts/descrever.py`](scripts/descrever.py) | Busca la descripción pública de los repositorios que quedaron sin descripción. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Traduce descripciones y temas a los idiomas de la guía, sin conexión, con modelos abiertos. |
| [`scripts/gerar.py`](scripts/gerar.py) | Genera el README, las páginas de sector, área, ruta e IA en todos los idiomas, el catálogo y el CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Comprueba si los links responden y marca los rotos. |
| [`tests/validar.py`](tests/validar.py) | Verifica datos, páginas, anclas, descripciones, idiomas y conteos. |

## 🛠️ Regenerar y validar

> Solo la stdlib de Python 3 es obligatoria para generar y validar. Scrapling mejora la recolección, y Argos Translate hace la traducción.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```

## 🤝 Contribución

> Las sugerencias son muy bienvenidas: un link que faltó, un área nueva, una ruta, una mejor traducción.

- **Link nuevo:** agrégalo en `data/essenciais.json` (si es esencial del área) o sugiere una **lista curada** en `data/fontes.json`. Luego ejecuta el generador.
- **Link roto o mala traducción:** abre un issue con la dirección de la página y el link.
- Paso a paso en [docs/08 · Cómo contribuir](docs/08-como-contribuir.md) y en [CONTRIBUTING.md](CONTRIBUTING.md).
