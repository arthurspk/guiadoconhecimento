## 🤖 IA para Design UI/UX

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com design ui/ux. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Documentação do servidor MCP oficial do Figma, que dá a agentes de IA o contexto dos arquivos de design para gerar código e editar o canvas; uso amplo exige assento Dev ou Full em plano pago.
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Repositório oficial do Figma com guia de instalação e skills para agentes (implementar design, gerar biblioteca, regras de design system) usando o MCP do Figma.
- [Figma Make](https://www.figma.com/make/) - Recurso de IA do Figma que transforma prompts e frames em protótipos funcionais com código; incluído nos planos do Figma, com cota de créditos de IA.
- [Google Stitch](https://stitch.withgoogle.com/) - Experimento do Google Labs que gera interfaces de app e web a partir de texto ou imagem, com exportação para o Figma e para código.
- [Framer AI](https://www.framer.com/ai/) - Construtor de sites com agente de IA no canvas, que cria e edita páginas responsivas a partir de instruções; gratuito para começar, publicação profissional paga.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - Servidor MCP open source que envia o layout e os estilos de arquivos do Figma para Cursor, Claude Code e outros agentes implementarem telas com mais fidelidade.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Servidor MCP integrado ao Penpot, ferramenta de design open source, que permite a agentes de IA ler e criar elementos nos arquivos de design.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Skill oficial do Claude que orienta a criação de interfaces com direção visual definida, evitando o visual genérico típico de páginas geradas por IA.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Skill e comandos de design para agentes de código, com regras automáticas que detectam vícios visuais comuns em front-ends gerados por IA.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Skill com base pesquisável de estilos, paletas, pares tipográficos e diretrizes de UX para agentes gerarem interfaces em vários frameworks.
- [The Shape of AI](https://www.shapeof.ai/) - Biblioteca gratuita de padrões de UX para produtos com IA (entradas, ajustes, controles, sinais de confiança), útil para desenhar interfaces de recursos de IA.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Guia gratuito do Google para projetar produtos de IA centrados nas pessoas, com padrões sobre expectativas, explicabilidade, feedback e erros.
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Coleção de artigos e estudos do NN/g sobre IA em UX: pesquisa com IA, design de chatbots e divulgação de uso de IA; artigos gratuitos, cursos pagos.

### Mais ferramentas e recursos de IA

- [Accessibility DevKit LLM](https://github.com/lukeslp/accessibility-devkit-llm) - Alt text generation, WCAG auditing CLI, and MCP server using language models for accessibility workflows. Works with OpenAI, Anthropic, HuggingFace, and Ollama.
- [AI Web Design Codex](https://github.com/Eneryleen/ai-web-design-codex) - Knowledge base of 60 cross-linked guides on web design, UX, accessibility, and conversion, for humans and AI agents.
- [Accessibility Multiskill](https://github.com/lukeslp/accessibility-multiskill) - WCAG 2.2 AA skill for coding agents (Claude Code, Codex, Cursor) covering motor, cognitive, visual, and communication disabilities. Includes 10 audit scripts and production CSS utilities.
- [Designesy](https://www.designesy.org/) - 40-check design-system contract verification engine. Scores any URL against DTCG 2025.10 token conformance, WCAG 2.2 AA, motion, and typography. Includes DTCG token validator, stylelint plugin, and MCP server.
- [Alt Text Local AI](https://github.com/lukeslp/alt-text-local-ai) - Desktop app that generates alt text for images using local Ollama vision models — no API key needed, nothing leaves your machine.
- [RatedWithAI](https://ratedwithai.com/) - AI-powered website accessibility scanner that checks for ADA and WCAG 2.2 compliance, powered by axe-core. Free instant audit with actionable fix recommendations.
- [Tactual](https://github.com/tactual-dev/tactual) - Screen-reader navigation cost analyzer. Models the real effort for assistive technology (AT) users to find, reach, and operate interactive web content under 5 assistive-technology profiles. CLI, MCP server, and library API.
- [Transcription Vidéo (RGAA Checker)](https://rgaa-checker.com/outils/transcription-video) - Free AI subtitle generator for uploaded audio/video: produces VTT, SRT and TXT captions following French RGAA and Arcom subtitling guidelines. FR.
- [RGAA Checker](https://rgaa-checker.com/) - Web accessibility scanner aligned with the French RGAA 4.1 standard and WCAG. Combines static analysis, dynamic testing (axe-core) and AI image analysis, generates a conformity declaration, and flags the criteria that require manual verification. FR.
- [AltTextLab](https://www.alttextlab.com/) - AI-powered alt text generator for images.
