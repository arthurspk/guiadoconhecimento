### Essenciais de IA

- [Hugging Face Learn](https://huggingface.co/learn) - Catálogo de cursos gratuitos da Hugging Face: agentes, visão computacional, áudio, RL, difusão e cookbook de IA aberta. <sub>curso</sub>
- [Data Science Agent no Colab](https://developers.googleblog.com/en/data-science-agent-in-colab-with-gemini/) - Anúncio oficial do agente do Gemini no Google Colab que gera notebooks completos de análise a partir de descrições em linguagem natural.
- [Jupyter AI](https://github.com/jupyterlab/jupyter-ai) - Extensão oficial do Project Jupyter que adiciona chat e comandos de IA generativa ao JupyterLab, com vários provedores de modelos.
- [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) - Coleção de mais de 170 skills para Claude e outros agentes cobrindo bibliotecas científicas, estatística, ML e bases de dados; MIT.
- [Hugging Face MCP Server](https://huggingface.co/docs/hub/hf-mcp-server) - Servidor MCP oficial que permite ao assistente buscar modelos, datasets, Spaces e artigos do Hugging Face Hub.
- [MLflow para GenAI](https://mlflow.org/docs/latest/genai/) - Plataforma de código aberto para rastrear, avaliar e monitorar aplicações com LLMs e agentes, incluindo juízes LLM e gestão de prompts.
- [AutoGluon](https://github.com/autogluon/autogluon) - AutoML de código aberto da AWS que treina modelos fortes para tabelas, texto, imagem e séries temporais com poucas linhas de código.
- [LLM Zoomcamp (DataTalksClub)](https://github.com/DataTalksClub/llm-zoomcamp) - Curso gratuito e aberto sobre aplicações com LLMs: RAG, busca vetorial, avaliação e monitoramento. <sub>curso</sub>

- [mlpack](https://github.com/mlpack/mlpack) - A scalable C++ machine learning library (Python bindings).
