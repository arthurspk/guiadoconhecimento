## 🤖 IA para Datasets e Dados Abertos

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com datasets e dados abertos. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [SQL Console do Hugging Face](https://huggingface.co/docs/hub/datasets-viewer-sql-console) - Console no navegador (DuckDB) para consultar datasets do Hub em SQL ou linguagem natural e exportar resultados.
- [Corpus Carolina](https://huggingface.co/datasets/carolina-c4ai/corpus-carolina) - Corpus aberto de português brasileiro contemporâneo da USP/C4AI, com mais de 2 milhões de documentos e proveniência registrada; CC BY 4.0. <sub>pt-BR</sub>
- [Chatbot da Base dos Dados](https://basedosdados.org/chatbot-lp) - Chatbot com Gemini que transforma perguntas em consultas sobre mais de 740 tabelas públicas brasileiras; teste grátis de 7 dias, depois assinatura. <sub>pt-BR</sub>
- [Croissant (MLCommons)](https://mlcommons.org/working-groups/data/croissant/) - Padrão aberto de metadados para datasets de ML, usado pelo Hugging Face, Kaggle e Google Dataset Search.
- [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) - Artigo de referência que propõe documentar motivação, composição, coleta e usos recomendados de todo dataset de ML.
- [Data Provenance Initiative](https://www.dataprovenance.org) - Iniciativa de pesquisa que audita origem, licenças e restrições dos dados usados para treinar modelos de IA.
- [Common Crawl](https://commoncrawl.org) - Arquivo aberto e gratuito de rastreamentos da web com centenas de bilhões de páginas, base de muitos corpora de LLMs.
- [SDV (Synthetic Data Vault)](https://github.com/sdv-dev/SDV) - Biblioteca Python para gerar dados tabulares sintéticos a partir de dados reais, útil para testes e compartilhamento seguro.
- [distilabel](https://github.com/argilla-io/distilabel) - Framework de código aberto para gerar e avaliar datasets sintéticos com LLMs (instruções, preferências, avaliação).
- [Argilla](https://github.com/argilla-io/argilla) - Plataforma de código aberto para curadoria e anotação de dados com apoio de LLMs e feedback humano.
- [Label Studio](https://github.com/HumanSignal/label-studio) - Ferramenta de código aberto para rotular texto, imagem, áudio e vídeo, com pré-anotação por modelos de ML.
