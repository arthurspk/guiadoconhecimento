- [ShellGPT](https://github.com/TheR1D/shell_gpt) - CLI que gera e explica comandos de shell com LLMs direto no terminal; open source.

- [Gemini CLI](https://github.com/google-gemini/gemini-cli) - Agente de IA open source do Google para o terminal, com nível gratuito de uso.
- [GitHub Copilot CLI](https://github.com/github/copilot-cli) - Agente do GitHub Copilot para o terminal: constrói, depura e explica código por linguagem natural; requer plano Copilot.
- [Warp](https://www.warp.dev/) - Terminal com agentes de IA integrados para gerar comandos e automatizar tarefas; plano gratuito limitado.
- [Butterfish](https://butterfi.sh) - Shell com IA que sugere comandos e responde perguntas usando o histórico do terminal; open source.
- [TmuxAI](https://tmuxai.dev/) - Assistente de IA que observa os painéis do tmux e ajuda no terminal sem sair dele.
- [command-line assistant (RHEL Lightspeed)](https://github.com/rhel-lightspeed/command-line-assistant) - Assistente de IA da Red Hat para configurar, administrar e solucionar problemas no RHEL pela linha de comando.
- [Linux MCP Server (RHEL Lightspeed)](https://github.com/rhel-lightspeed/linux-mcp-server) - Servidor MCP somente leitura para diagnóstico e troubleshooting de sistemas Linux locais ou via SSH.
- [Desktop Commander MCP](https://github.com/wonderwhy-er/DesktopCommanderMCP) - Servidor MCP que dá a assistentes acesso a terminal, processos e edição de arquivos na máquina.
- [Ollama](https://ollama.com) - Roda modelos abertos localmente no Linux, macOS e Windows, mantendo os dados na máquina.
