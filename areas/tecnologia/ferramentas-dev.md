### Essenciais de IA

- [Claude Code](https://code.claude.com/docs/en/overview) - Documentação do agente de código da Anthropic para terminal, IDE, desktop e web, com MCP, skills e hooks; requer plano pago.
- [Claude Academy](https://academy.claude.com/) - Cursos gratuitos da Anthropic, incluindo Claude Code 101 e Claude Code in Action. <sub>curso</sub>
- [OpenAI Codex](https://openai.com/codex/) - Agente de programação da OpenAI disponível no terminal, IDE e nuvem; incluso em planos do ChatGPT.
- [GitHub Copilot](https://github.com/features/copilot) - Assistente de código do GitHub com autocompletar, chat e agente; tem plano gratuito limitado.
- [Cursor](https://www.cursor.com/) - Editor baseado no VS Code com agente de IA integrado; plano gratuito limitado.
- [Kiro](https://kiro.dev) - IDE agêntica da AWS que transforma prompts em especificações executáveis e código.
- [Junie (JetBrains)](https://junie.jetbrains.com/) - Agente de código da JetBrains que funciona com o modelo escolhido; tem versão gratuita Lite.
- [Continue](https://continue.dev/) - Extensão open source para VS Code e JetBrains que cria assistentes de código com qualquer modelo.
- [Zed](https://zed.dev/) - Editor de código open source e rápido com recursos de IA e suporte a agentes externos.
- [Superpowers](https://github.com/obra/superpowers) - Biblioteca de skills para agentes de código com fluxos de TDD, depuração, planejamento e revisão.
- [Anthropic Skills](https://github.com/anthropics/skills) - Repositório oficial de exemplos de skills para Claude, incluindo testes de web apps e criação de servidores MCP.
- [Awesome GitHub Copilot](https://github.com/github/awesome-copilot) - Coleção oficial de instruções, agentes, prompts e skills da comunidade para o GitHub Copilot.
- [Model Context Protocol](https://modelcontextprotocol.io) - Documentação do padrão aberto para conectar assistentes de IA a ferramentas, dados e APIs.
- [Getting Started with GitHub Copilot (GitHub Skills)](https://github.com/skills/getting-started-with-github-copilot) - Curso prático e gratuito do GitHub Skills para aprender a usar o Copilot dentro de um repositório. <sub>curso</sub>
- [Awesome Claude Code](https://github.com/hesreallyhim/awesome-claude-code) - Lista curada de skills, hooks, comandos e ferramentas da comunidade para o Claude Code.
