## 🤖 IA para Open Source

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com open source. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [Copilot Pro grátis para mantenedores](https://docs.github.com/en/copilot/how-tos/manage-your-account/get-free-access-to-copilot-pro) - Documentação do GitHub sobre acesso gratuito ao Copilot Pro para mantenedores de projetos open source populares.
- [CodeRabbit](https://www.coderabbit.ai) - Revisão automática de pull requests com IA; tem programa para projetos open source.
- [PR-Agent (Qodo)](https://github.com/qodo-ai/pr-agent) - Ferramenta open source que revisa, descreve e sugere melhorias em pull requests com LLMs.
- [OpenHands](https://github.com/OpenHands/OpenHands) - Plataforma open source de agentes de desenvolvimento que resolvem issues e abrem PRs.
- [goose](https://github.com/block/goose) - Agente de IA open source e extensível, hoje mantido na Agentic AI Foundation.
- [AGENTS.md](https://agents.md) - Formato aberto, um README para agentes, que diz a assistentes de código como trabalhar no seu repositório.
- [Agentic AI Foundation (AAIF)](https://aaif.io) - Fundação neutra da Linux Foundation que abriga MCP, AGENTS.md, goose e outros projetos abertos de IA agêntica. <sub>comunidade</sub>
- [Open Source AI Definition (OSI)](https://opensource.org/ai/open-source-ai-definition) - Definição da Open Source Initiative sobre o que torna um sistema de IA open source.
- [Política de IA generativa da Linux Foundation](https://www.linuxfoundation.org/legal/generative-ai) - Orientações para contribuir com código gerado por IA em projetos abertos, cobrindo licenças e propriedade intelectual.
