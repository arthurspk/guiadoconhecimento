### 💎 Essenciais de IA

- [v0 (Vercel)](https://v0.dev/) - Gera interfaces e apps em React/Next.js com Tailwind e shadcn/ui a partir de prompts; plano gratuito limitado.
- [Bolt.new](https://bolt.new) - Cria e roda aplicações web full-stack no navegador a partir de descrições em linguagem natural; plano gratuito limitado.
- [Lovable](https://lovable.dev/) - Construtor de aplicações web por chat, com integração a Supabase e GitHub; plano gratuito limitado.
- [Google Stitch](https://stitch.withgoogle.com/) - Ferramenta do Google que gera designs de interface e código front-end a partir de texto ou imagens.
- [Kombai](https://kombai.com/) - Agente especializado em front-end que converte designs do Figma em código de componentes.
- [Figma MCP Server (guia)](https://github.com/figma/mcp-server-guide) - Guia oficial do servidor MCP do Figma, que passa contexto de design para agentes gerarem código fiel ao layout. <sub>📖 documentação</sub>
- [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) - Servidor MCP oficial que permite ao agente controlar e inspecionar o Chrome: DOM, console, rede e performance.
- [shadcn/ui MCP Server](https://ui.shadcn.com/docs/mcp) - Permite que assistentes naveguem, busquem e instalem componentes de registries shadcn por linguagem natural. <sub>📖 documentação</sub>
- [UI UX Pro Max (skill)](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Skill para agentes de código com regras de design de UI/UX para várias plataformas e frameworks.
- [Impeccable (skill)](https://github.com/pbakaus/impeccable) - Skill e comandos de design para agentes de código, com regras que detectam padrões ruins em front-end gerado por IA.
- [screenshot-to-code](https://github.com/abi/screenshot-to-code) - Converte capturas de tela, mockups e designs em HTML/Tailwind, React ou Vue usando modelos de visão; open source.
- [IA integrada do Chrome (Built-in AI)](https://developer.chrome.com/docs/ai) - Documentação das APIs de IA que rodam no próprio navegador com modelos locais e do WebMCP para integrar sites a agentes. <sub>📖 documentação</sub>
- [AI SDK (Vercel)](https://github.com/vercel/ai) - Biblioteca TypeScript open source para criar interfaces de chat e recursos de IA em React, Next.js, Svelte e Vue.
