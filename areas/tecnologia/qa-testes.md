## 🤖 IA para QA e Testes

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com qa e testes. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - Agentes oficiais do Playwright (planner, generator e healer) que planejam, geram e corrigem testes end-to-end.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Servidor MCP da Microsoft que permite a agentes navegar e testar páginas via árvore de acessibilidade.
- [Stagehand](https://github.com/browserbase/stagehand) - Framework de automação de navegador que mistura código e instruções em linguagem natural; open source.
- [Keploy](https://github.com/keploy/keploy) - Gera testes de API e integração com mocks a partir do tráfego real gravado via eBPF; open source.
- [Qodo](https://www.qodo.ai/) - Plataforma de revisão de código e geração de testes com IA para PRs e IDEs; teste grátis, depois pago.
- [Diffblue](https://www.diffblue.com/) - Gera testes unitários Java automaticamente com IA; pago.
- [Applitools](https://applitools.com) - Plataforma de testes end-to-end com Visual AI para detectar regressões visuais; paga.
- [Meticulous](https://www.meticulous.ai/) - Gera e mantém testes de regressão visual a partir de sessões reais de usuários; pago.
- [Octomind](https://octomind.dev) - Agente que descobre, gera e mantém testes end-to-end em Playwright; pago.
- [Checksum](https://checksum.ai) - Gera e mantém testes end-to-end com IA a partir do uso real da aplicação; pago.
- [promptfoo](https://www.promptfoo.dev) - Ferramenta open source para testar, avaliar e fazer red teaming de aplicações com LLM.
- [DeepEval](https://github.com/confident-ai/deepeval) - Framework open source no estilo pytest para testes unitários de saídas de LLMs, RAG e agentes.
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - Certificação e syllabus gratuito do ISTQB sobre teste de sistemas de IA, incluindo ML e LLMs. <sub>curso</sub>
