## 🤖 IA para QA e Testes

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com QA e Testes. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### 💎 Essenciais de IA

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - Agentes oficiais do Playwright (planner, generator e healer) que planejam, geram e corrigem testes end-to-end. <sub>📖 documentação</sub>
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Servidor MCP da Microsoft que permite a agentes navegar e testar páginas via árvore de acessibilidade.
- [Stagehand](https://github.com/browserbase/stagehand) - Framework de automação de navegador que mistura código e instruções em linguagem natural; open source.
- [Keploy](https://github.com/keploy/keploy) - Gera testes de API e integração com mocks a partir do tráfego real gravado via eBPF; open source.
- [Qodo](https://www.qodo.ai/) - Plataforma de revisão de código e geração de testes com IA para PRs e IDEs; teste grátis, depois pago.
- [Diffblue](https://www.diffblue.com/) - Gera testes unitários Java automaticamente com IA; pago.
- [Applitools](https://applitools.com) - Plataforma de testes end-to-end com Visual AI para detectar regressões visuais; paga.
- [Meticulous](https://www.meticulous.ai/) - Gera e mantém testes de regressão visual a partir de sessões reais de usuários; pago.
- [Octomind](https://octomind.dev) - Agente que descobre, gera e mantém testes end-to-end em Playwright; pago.
- [Checksum](https://checksum.ai) - Gera e mantém testes end-to-end com IA a partir do uso real da aplicação; pago.
- [promptfoo](https://www.promptfoo.dev) - Ferramenta open source para testar, avaliar e fazer red teaming de aplicações com LLM.
- [DeepEval](https://github.com/confident-ai/deepeval) - Framework open source no estilo pytest para testes unitários de saídas de LLMs, RAG e agentes.
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - Certificação e syllabus gratuito do ISTQB sobre teste de sistemas de IA, incluindo ML e LLMs. <sub>🎓 curso</sub>

- [skipper](https://github.com/get-skipper/skipper) - Controle de execução em tempo real através do Google Spreadsheet, permitindo a mudança instantânea sem alterações de código.
- [TestLink](https://github.com/TestLinkOpenSourceTRMS/testlink-code) - Sistema de gerenciamento de casos em código aberto.
- [Testomatio](https://testomat.io/) - TCMS moderno permitindo sincronização de testes manuais e automatizados.
- [Cutaway](https://github.com/half144/cutaway) - Agentes codificadores gravam vídeos demo polidos de fluxos de web de um script JSON, com uma câmera de zoom, um cursor e um borrão.
- [Playwright Agent CLI](https://playwright.dev/agent-cli/introduction) - Interface de linha de comando oficial para automação do navegador projetada para agentes codificadores, com comandos eficientes e habilidades instaláveis.
- [Webcmd](https://github.com/agentrhq/webcmd) - CLI construído na Playwright que aprende a navegação de um site uma vez e compila-o em comandos determinísticos por local para agentes codificadores.
- [CasperJS](https://github.com/casperjs/casperjs) - Utilitário de scripts e testes de navegação para PhantomJS e SlimerJS.
- [Chromeless](https://github.com/graphcool/chromeless) - A automação do Chrome é simples, funciona localmente ou sem cabeça na AWS Lambda.
- [DalekJS](https://github.com/dalekjs/dalek) - Testes automáticos de navegador cruzado com JavaScript, não mais mantidos desde 4 de junho de 2017.
- [dpxdt](https://github.com/bslatkin/dpxdt) - Testes de ponta a ponta com Python.
- [Huxley](https://github.com/facebookarchive/huxley) - Framework Python baseado em Selenium Webdriver.
- [Selenium with C#](http://seleniumhq.github.io/selenium/docs/api/dotnet/index.html) - Selênio C# encadernação <sub>📖 documentação</sub>
- [Atata](https://github.com/atata-framework/atata) - Testes automáticos na web com base no Selenium WebDriver.
- [Strontium](https://github.com/jimevans/strontium) - Uma implementação .NET (mas desatualizada) para servidor Selenium/WebDriver (Remote)
- [TempMailGrab](https://tempmailgrab.com/api-docs) - API de e-mail descartável para caixas de entrada temporárias, extração OTP, links de verificação, e webhooks em testes de dramaturgo, Cypress e CI.
- [Temp Mail 24](https://temp-mail24.com/) - Caixa de entrada temporária baseada em navegador para o teste manual permitido.
- [8½ Minute Mail](https://8m30mail.com/) - Caixa de entrada temporária para verificação manual do e-mail, com 8 minutos-30 segundos de vida padrão e nenhuma conta necessária.
- [DATAMIMIC CE](https://github.com/rapiddweller/datamimic) - Motor determinístico aberto para dados de teste sintéticos e pseudônimo PII, acerte uma semente e obtenha saída idêntica com um hash procedência em cada corrida.
- [dbmask](https://github.com/sealandseacat/dbmask) - Máscaras de dados sensíveis em bancos de dados de teste SQL com falsificações determinísticas e verifica a linha mascarada por linha.
- [Dummy Data Lab](https://timliu724.github.io/dummy-data-lab/) - Ferramenta de navegador off-line e código aberto para transformar CSV ou TXT em dados manequins controlados e gerar conjuntos de dados de teste conectados sem carregar arquivos fonte.
- [Geb](http://www.gebish.org/) - Ele pode ser usado para scripting, raspagem e automação geral - ou igualmente como uma solução de teste funcional / web / aceitação via integração com estruturas de testes como Spock, JUnit & TestNG.
- [dart.webdriver](https://github.com/google/webdriver.dart) - Eles usam a interface do WebDriver JSON, e como tal, requerem o uso do servidor remoto do WebDriver.
- [WebdriverCSS](https://github.com/webdriverio/webdrivercss) - Ferramenta de teste de regressão para o WebdriverIO (atualmente desactualizado, por favor use wdio-screenshot por enquanto).
- [Website-Diff](https://github.com/GeiserX/Website-Diff) - Ferramenta de comparação inteligente com a máquina Wayback e testes de regressão visual via Selenium.
- [JMeter Ant Task](https://github.com/jfifield/ant-jmeter) - Uma tarefa para automatizar os planos de teste do JMeter.
- [JMeter Maven Plugin](https://github.com/jmeter-maven-plugin/jmeter-maven-plugin) - Plug-in Maven que fornece a capacidade de executar testes JMeter como parte da construção.
- [Elastic APM JS agent](https://github.com/elastic/apm-agent-rum-js) - O dramaturgo é usado para fazer testes de referência em navegadores.
- [Winium.Cruciatus](https://github.com/2gis/Winium.Cruciatus) - C# Framework para testes automatizados de aplicativos Windows baseados em plataformas WinFroms e WPF.
- [elgalu/docker-selenium](https://github.com/elgalu/docker-selenium) - Selênio em Docker com Chrome e Firefox mais suporte de gravação de vídeo.
