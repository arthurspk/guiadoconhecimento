## 🤖 IA para Bancos de Dados

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com bancos de dados. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [MCP Toolbox for Databases](https://github.com/googleapis/genai-toolbox) - Servidor MCP open source do Google que conecta agentes e IDEs a PostgreSQL, MySQL, SQL Server, BigQuery e outros.
- [DBHub](https://github.com/bytebase/dbhub) - Servidor MCP universal da Bytebase para consultar e explorar bancos SQL a partir de assistentes de IA.
- [Postgres MCP Pro](https://github.com/crystaldba/postgres-mcp) - Servidor MCP para PostgreSQL com análise de saúde do banco, planos de execução e recomendação de índices.
- [MongoDB MCP Server](https://github.com/mongodb-js/mongodb-mcp-server) - Servidor MCP oficial para consultar e administrar MongoDB e Atlas a partir de agentes de IA.
- [Supabase MCP](https://github.com/supabase-community/supabase-mcp) - Conecta assistentes de IA a projetos Supabase para criar tabelas, rodar SQL e gerenciar migrações.
- [Vanna](https://github.com/vanna-ai/vanna) - Framework open source de text-to-SQL que transforma perguntas em linguagem natural em consultas e respostas.
- [Wren AI](https://getwren.ai/oss) - Agente open source de text-to-SQL e BI com camada semântica sobre o banco de dados.
- [SQL Chat](https://github.com/sqlchat/sqlchat) - Cliente SQL baseado em chat que consulta e altera o banco por linguagem natural.
- [AI Assistant no DataGrip](https://www.jetbrains.com/help/datagrip/ai-assistant.html) - Recursos de IA da JetBrains no DataGrip para gerar, explicar e otimizar SQL; requer licença de IA.
- [dbForge AI Assistant](https://www.devart.com/dbforge/ai-assistant/) - Assistente de IA da Devart para escrever, otimizar e explicar SQL em várias bases; pago.
- [pgvector](https://github.com/pgvector/pgvector) - Extensão open source de busca vetorial para PostgreSQL, base de RAG e buscas semânticas no próprio banco.
- [BIRD-SQL](https://bird-bench.github.io) - Benchmark de referência para avaliar LLMs em text-to-SQL sobre bancos grandes e realistas.
