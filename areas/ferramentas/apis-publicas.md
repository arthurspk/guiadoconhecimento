### Essenciais de IA

- [Gemini API (Google AI Studio)](https://ai.google.dev/gemini-api/docs/pricing) - Cota gratuita de tokens para alguns modelos Gemini; atenção: no plano gratuito o conteúdo pode ser usado para melhorar os produtos do Google.

- [GitHub Models](https://docs.github.com/en/github-models/use-github-models/prototyping-with-ai-models) - Playground e API gratuitos, com limites, para prototipar com vários modelos usando a conta do GitHub.
- [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/) - Execute modelos de IA na rede da Cloudflare com 10 mil Neurons gratuitos por dia.
- [OpenRouter (modelos gratuitos)](https://openrouter.ai/models?max_price=0) - API única compatível com OpenAI; este filtro lista os modelos oferecidos a custo zero, com limites de uso.
- [Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers/pricing) - Acesso a milhares de modelos por uma API; contas gratuitas recebem um pequeno crédito mensal para testes.
- [API do Ollama](https://docs.ollama.com/api) - API REST local e compatível com OpenAI para usar modelos rodando na sua máquina, sem custo por token.
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io) - Padrão aberto para expor APIs e dados a assistentes de IA; útil para transformar uma API pública em ferramenta de agente.
