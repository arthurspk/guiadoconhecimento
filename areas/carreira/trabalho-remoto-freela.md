## 🤖 IA para Trabalho Remoto e Freelancer

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com trabalho remoto e freelancer. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [Uma (assistente de IA da Upwork)](https://www.upwork.com/uma) - Assistente de IA embutido na Upwork que ajuda freelancers a redigir propostas e clientes a escrever vagas; revise sempre o texto antes de enviar.
- [DeepL Tradutor](https://www.deepl.com/pt-BR/translator) - Tradutor com IA muito usado para atender clientes estrangeiros; versão gratuita com limites e plano Pro pago com mais privacidade.
- [Grammarly](https://www.grammarly.com) - Assistente de escrita em inglês com IA para e-mails e propostas a clientes internacionais; plano gratuito com revisão básica e cota de prompts.
- [Fathom](https://www.fathom.ai/) - Anotador de reuniões com IA, gratuito, que grava, transcreve e resume chamadas no Zoom, Google Meet e Teams.
- [tl;dv](https://tldv.io/pt-br/) - Assistente de reuniões com IA que grava, transcreve e resume chamadas em português; plano gratuito permanente. <sub>pt-BR</sub>
- [Otter.ai](https://otter.ai) - Transcrição e resumo automático de reuniões com plano gratuito; útil para registrar combinados com clientes (avise os participantes antes de gravar).
- [Gamma](https://gamma.app) - Gera apresentações, propostas e páginas a partir de texto com IA; plano gratuito com créditos iniciais.
- [Loom AI](https://www.loom.com/ai) - Recursos de IA do Loom para vídeos assíncronos (títulos, resumos, capítulos e remoção de pausas); disponíveis no plano pago Business + AI.

## ◾ Common Freelance Developer Position

- [Freelance Full-Stack Developer](https://www.coursera.org/articles/full-stack-developer) - Skilled in both front-end and back-end technologies, capable of handling entire web development processes. <sub>curso</sub>
- [Freelance Front-End Developer](https://www.coursera.org/articles/front-end-developer) - Specializes in creating the user interface and experience of a web application using HTML, CSS, and JavaScript frameworks. <sub>curso</sub>
- [Freelance Back-End Developer](https://www.coursera.org/articles/back-end-developer) - Focuses on server-side development, database management, and application logic using languages like Python, Ruby, or PHP. <sub>curso</sub>
- [Freelance Web Developer](https://www.coursera.org/articles/web-developer) - General web development skills, often including both front-end and back-end development. <sub>curso</sub>
- [Freelance Mobile App Developer](https://www.coursera.org/articles/mobile-app-development) - Develops mobile applications for platforms like iOS and Android, using Swift, Kotlin, or cross-platform technologies. <sub>curso</sub>
- [Freelance JavaScript Developer](https://www.toptal.com/javascript/job-description) - Specializes in JavaScript programming, including frameworks and libraries like React, Angular, or Node.js.
- [Freelance Java Developer](https://www.coursera.org/specializations/java-fullstack) - Focuses on Java development, suitable for enterprise-level applications, Android apps, and large systems. <sub>curso</sub>
- [Freelance PHP Developer](https://www.toptal.com/php/job-description) - Expertise in PHP, commonly used for web development and server-side scripting.
- [Freelance React Developer](https://www.coursera.org/articles/react-developer) - Specializes in the React JavaScript library for building user interfaces, particularly for single-page applications. <sub>curso</sub>
- [Freelance Ruby on Rails Developer](https://www.indeed.com/career/ruby-on-rails-developer) - Skilled in Ruby and the Rails framework, known for rapid development of web applications.
- [Freelance WordPress Developer](https://www.coursera.org/articles/wordpress-developer) - Specializes in creating and customizing websites and blogs using WordPress. <sub>curso</sub>
- [Freelance iOS Developer](https://www.toptal.com/ios/job-description) - Develops applications for Apple's iOS devices using Swift or Objective-C.
- [Freelance Android Developer](https://www.toptal.com/android/job-description) - Builds applications for Android devices using Java or Kotlin.
- [Freelance C# Developer](https://www.freelancermap.com/blog/what-does-c-developer-do/) - Skilled in C#, often used for developing Windows applications, games (using Unity), and enterprise software.
- [Freelance UX/UI Developer](https://intellipaat.com/blog/who-is-ui-ux-developer/) - Focuses on user experience and user interface design, ensuring applications are both functional and appealing.
