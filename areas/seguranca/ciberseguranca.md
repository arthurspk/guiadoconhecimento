## 🤖 IA para Cibersegurança

> Ferramentas, skills, MCPs, cursos, guias de prompt e uso responsável de IA para quem trabalha com cibersegurança. Veja também [🤖 IA para todas as áreas](../../ia/README.md).

### Essenciais de IA

- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/) - Lista de referência dos 10 maiores riscos de aplicações com LLM (prompt injection, vazamento de dados, agência excessiva etc.), com tradução para português.
- [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/) - Framework revisado por pares com os riscos mais críticos de agentes de IA autônomos e as defesas recomendadas.
- [OWASP AI Exchange](https://owaspai.org) - Guia aberto com mais de 300 páginas sobre ameaças e controles de segurança para sistemas de IA.
- [MITRE ATLAS](https://atlas.mitre.org) - Base de conhecimento de táticas e técnicas de ataque contra sistemas de IA, no estilo do MITRE ATT&CK.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) - Framework do NIST para gerir riscos de IA, com perfil específico para IA generativa e playbook de implementação.
- [Google SAIF](https://saif.google) - Secure AI Framework do Google: guia prático de segurança no ciclo de vida de sistemas de IA e agentes.
- [Microsoft Security Copilot](https://learn.microsoft.com/pt-br/copilot/security/microsoft-security-copilot) - Documentação oficial em português do assistente de IA da Microsoft para investigação de incidentes e caça a ameaças; pago. <sub>pt-BR</sub>
- [IA para segurança (Google Cloud)](https://cloud.google.com/security/ai?hl=pt-br) - Visão geral em português do SOC agêntico com Gemini, inteligência de ameaças Mandiant e proteção de sistemas de IA; produtos pagos. <sub>pt-BR</sub>
- [garak](https://github.com/NVIDIA/garak) - Scanner de vulnerabilidades de LLMs da NVIDIA que testa prompt injection, jailbreak, vazamento de dados e alucinação; código aberto.
- [PyRIT](https://github.com/Azure/PyRIT) - Framework de código aberto da Microsoft para automatizar red teaming de sistemas de IA generativa.
- [promptfoo](https://github.com/promptfoo/promptfoo) - Ferramenta de código aberto para testar e fazer red teaming de prompts, agentes e RAG, com relatórios mapeados ao OWASP.
- [Trail of Bits Skills](https://github.com/trailofbits/skills) - Marketplace de skills para Claude Code e Codex com auditoria de código, Semgrep, YARA, análise estática e revisão de cadeia de suprimentos.
- [PentestGPT](https://github.com/GreyDGL/PentestGPT) - Agente de pentest com LLM publicado no USENIX Security 2024, que guia e automatiza etapas de testes de intrusão; uso apenas autorizado.
- [GhidraMCP](https://github.com/LaurieWired/GhidraMCP) - Servidor MCP que conecta LLMs ao Ghidra para engenharia reversa e análise de malware assistida; código aberto.
- [HackAPrompt](https://www.hackaprompt.com) - Competição e plataforma gratuita de red teaming de IA para praticar prompt injection e jailbreak de forma ética. <sub>comunidade</sub>
