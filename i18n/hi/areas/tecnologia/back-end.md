- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) - Microsoft SDK को C#, पाइथन और जावा में LLM, प्लगइन्स और एजेंट को ऑर्केस्ट्रेट करने के लिए।
- [Laravel Boost](https://laravel.com/docs/boost) - आधिकारिक पैकेज जो एआई एजेंट लारवेल के विशिष्ट दिशानिर्देश, कौशल, MCP सर्वर और प्रलेखन देता है। <sub>📖 डॉक्यूमेंटेशन</sub>
- [FastAPI-MCP](https://github.com/tadata-org/fastapi_mcp) - मौजूदा FastAPI को MCP उपकरण के रूप में समापन बिंदुओं को प्रदर्शित करता है, जो API प्रमाणीकरण का पुन: उपयोग करता है।
- [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk) - आधिकारिक SDK सर्वर बनाने और पायथन में मॉडल कॉन्टेक्स्ट प्रोटोकॉल के ग्राहकों को।
- [MCP TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - आधिकारिक SDK Node.js/typeScript में MCP सर्वर और क्लाइंट बनाने के लिए।
- [Generative AI for Beginners (Microsoft)](https://github.com/microsoft/generative-ai-for-beginners) - Genrativa AI अनुप्रयोगों के निर्माण के लिए व्यावहारिक सबक के साथ नि: शुल्क पाठ्यक्रम: संकेत, आरएजी, फ़ंक्शन कॉलिंग और एजेंट। <sub>🎓 कोर्स</sub>
- [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks) - उपकरण उपयोग व्यंजनों, आरएजी के साथ आधिकारिक एंथ्रोपिक नोटबुक, एपीआई के माध्यम से संरचित निष्कर्षण और एजेंटों।
- [OpenAI Cookbook](https://github.com/openai/openai-cookbook) - OpenAI API को सेवाओं में एकीकृत करने के लिए उदाहरण और आधिकारिक गाइड: एम्बेडिंग, फ़ंक्शन कॉलिंग और समीक्षा।
