- [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/) - Standard language for integration and asynchronous message.
- [The Architecture of Open Source Applications](https://aosabook.org/en/) - Free books in which authors explain the architecture of known open source projects. <sub>📚 book</sub>
- [ByteByteGo](https://blog.bytebytego.com/) - Alex Xu Newsletter on system design with didactic diagrams.
- [High Scalability](https://highscalability.com/) - Large systems architecture and scalability case studies.
- [InfoQ - Architecture & Design](https://www.infoq.com/architecture-design/) - Talks, articles and podcasts about software architecture.
- [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected/) - AWS framework with six pillars of good cloud architecture practices. <sub>📖 documentation</sub>
- [Azure Architecture Center](https://learn.microsoft.com/pt-br/azure/architecture/) - Microsoft's reference architecture and cloud patterns in English. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
