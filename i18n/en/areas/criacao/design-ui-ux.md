## 🤖 AI for UI/UX Design

> AI tools, skills, MCPs, courses, prompt guides, and responsible-use resources for people working in UI/UX Design. See also [🤖 AI for every field](../../ia/README.md).

### 💎 AI essentials

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Documentation of Figma official MCP server, which gives AI agents the context of design files to generate code and edit canvas; wide use requires Dev or Full seat in paid plan. <sub>📖 documentation</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Official Figma Repository with Installation Guide and Skills for Agents (implement design, generate library, design system rules) using Figma MCP.
- [Figma Make](https://www.figma.com/make/) - Figma AI resource that transforms prompts and frames into functional prototypes with code; included in the Figma plans, with a share of AI credits.
- [Google Stitch](https://stitch.withgoogle.com/) - Google Labs experiment that generates app and web interfaces from text or image, with export to Figma and code.
- [Framer AI](https://www.framer.com/ai/) - Website builder with AI agent in canvas, which creates and edits responsive pages from instructions; free to start, paid professional publication.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - MCP open source server that sends Figma layout and file styles to Cursor, Claude Code and other agents implement screens more faithfully.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Penpot-integrated MCP server, open source design tool that allows AI agents to read and create elements in the design files.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Claude's official Skill that guides the creation of interfaces with defined visual direction, avoiding the typical generic look of pages generated by AI.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Skill and design commands for code agents, with automatic rules that detect common visual biases in front-ends generated by AI.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Skill based on searchable styles, palettes, typographical pairs and UX guidelines for agents to generate interfaces across multiple frameworks.
- [The Shape of AI](https://www.shapeof.ai/) - Free library of UX standards for AI products (entrys, adjustments, controls, signs of trust), useful to design IA resource interfaces.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Google's free guide to designing people-centered AI products with patterns about expectations, explanation, feedback and errors. <sub>📖 documentation</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Collection of NN/g articles and studies on AI in UX: research with AI, chatbot design and disclosure of use of AI; free articles, paid courses.
