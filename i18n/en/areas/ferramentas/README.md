## ⭐ A taste of each area

> The top essentials from each area in this sector, so you can get a feel for what each page offers.

### 🌍 Online Tools

- [iLovePDF](https://www.ilovepdf.com/pt) - Online tools to join, divide, compress and convert PDFs. <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - Free collection of PDF tools in the browser, without artificial limits. <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - Online file converter with support for more than 200 formats.
- [TinyPNG](https://tinypng.com/) - Compresss PNG, JPEG and WebP images while maintaining visual quality.
- [Squoosh](https://squoosh.app/) - Google image compressor running locally in the browser.

→ [See all 297 links for Online Tools](./ferramentas-online.md)

### 🪄 AI Tools

- [ChatGPT](https://chatgpt.com/) - OpenAI AI Wizard for text, code, images and search.
- [Claude](https://claude.ai/) - Anthropic AI Assistant for writing, analysis and programming.
- [Gemini](https://gemini.google.com/) - Google's AI Assistant integrated into the services of the Google account.
- [Microsoft Copilot](https://copilot.microsoft.com/) - Free Microsoft AI Wizard for chat and image creation.
- [Perplexity](https://www.perplexity.ai/) - Searcher with AI who responds by quoting the sources.

→ [See all 268 links for AI Tools](./ferramentas-ia.md)

### 🏠 Self-hosted

- [awesome-selfhosted.net](https://awesome-selfhosted.net/) - Navigable version of the main list of software to host yourself.
- [selfh.st](https://selfh.st/) - Weekly newsletter and self-hosted apps directory.
- [Docker Docs](https://docs.docker.com/) - Official Docker documentation, basis of most self-hosted facilities. <sub>📖 documentation</sub>
- [LinuxServer.io](https://www.linuxserver.io/) - Standard and documented Docker images for dozens of apps.
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) - Open virtualization platform for home and business servers.

→ [See all 299 links for Self-hosted](./self-hosted.md)

### 🖥️ Apps for macOS, Windows, and Linux

- [AlternativeTo](https://alternativeto.net/) - Find alternatives to any program, filtering by system and license.
- [Homebrew](https://brew.sh/) - Package Manager for macOS and Linux.
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - Official Windows package manager by command line. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - Windows program installer via command line, no UAC.
- [Ninite](https://ninite.com/) - Install and update multiple Windows programs at once, without toolbars.

→ [See all 298 links for Apps for macOS, Windows, and Linux](./apps-sistemas.md)

### 📲 Apps for Android and iOS

- [F-Droid](https://f-droid.org/) - Free and open source Android app store.
- [Obtainium](https://obtainium.imranr.dev/) - Install and update Android apps directly from the release pages (GitHub, GitLab).
- [Aurora OSS](https://auroraoss.com/) - Aurora Store project, alternative open source client for the Play Store.
- [Signal](https://signal.org/) - Messenger with end-to-end encryption, no ads and no tracking.
- [Organic Maps](https://organicmaps.app/) - Offline maps with navigation, trails and no tracking based on OpenStreetMap.

→ [See all 208 links for Apps for Android and iOS](./apps-celular.md)

### 🧩 Browser Extensions

- [uBlock Origin](https://ublockorigin.com/) - Lightweight, open source ad blocker and trackers.
- [Privacy Badger](https://github.com/EFForg/privacybadger) - Extension of the EFF that learns and blocks invisible trackers.
- [Dark Reader](https://darkreader.org/) - Apply dark mode to any site, with brightness and contrast adjustments.
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - Automatically jumps sponsored snippets on YouTube videos.
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - Replay the estimated count of disks on YouTube.

→ [See all 207 links for Browser Extensions](./extensoes-navegador.md)

### 🔗 Public APIs

- [Public APIs](https://github.com/public-apis/public-apis) - The best known list of free APIs, organized by category.
- [BrasilAPI](https://brasilapi.com.br/) - Free API with CEP, CNPJ, banks, holidays, FIPE and other Brazilian data. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - Free webservice of CEP query in JSON or XML. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Exchange series, Selic, Pix and credit with API access. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - Catalogue of open data sets from the federal government. <sub>🇧🇷 pt-BR</sub>

→ [See all 298 links for Public APIs](./apis-publicas.md)
