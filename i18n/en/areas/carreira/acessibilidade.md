## ⭐ Start here

> The essentials for Accessibility, hand-picked by the curators: if you only have time for a few links, these are the ones.

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) - W3C recommendation defining accessibility criteria for web content. <sub>📖 documentation</sub>
- [WCAG 2.1 em português](https://www.w3c.br/traducoes/wcag/wcag21-pt-BR/) - Official translation into Portuguese of the WCAG 2.1 guidelines, by W3C Brasil. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [W3C WAI](https://www.w3.org/WAI/) - W3C Web Accessibility Initiative Portal, with guides per profile. <sub>📖 documentation</sub>
- [eMAG](https://emag.governoeletronico.gov.br/) - Accessibility Model in Electronic Government, Brazilian reference based on WCAG. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [Lei Brasileira de Inclusão](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2015/lei/l13146.htm) - Law 13,146/2015, which guarantees the rights of people with disabilities, including digital access. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [MDN Acessibilidade](https://developer.mozilla.org/pt-BR/docs/Web/Accessibility) - MDN documentation and tutorials on semantic HTML, ARIA and good practices. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [The A11Y Project](https://www.a11yproject.com/) - Checklist, articles and community resources to make accessibility practical.
- [WebAIM](https://webaim.org/) - Articles, training and research on web accessibility.
- [WAVE](https://wave.webaim.org/) - An online and browser-wide accessibility reviewer.
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) - Checks if the contrast between colors meets WCAG AA and AAA levels.
- [axe-core](https://github.com/dequelabs/axe-core) - Automated accessibility testing engine used in various tools.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse) - Chrome Audit that includes automatic accessibility checks.
- [NVDA](https://www.nvaccess.org/) - Free open source screen player for Windows, essential for testing.
- [VLibras](https://www.gov.br/pt-br/apps/vlibras) - Federal government suite that translates digital content to Libras. <sub>🇧🇷 pt-BR</sub>
- [Hand Talk](https://www.handtalk.me/br/) - Brazilian company with app and translation plugin for Libras. <sub>🇧🇷 pt-BR</sub>
- [Inclusive Components](https://inclusive-components.design/) - Standards of accessible interface components explained step by step.
- [Learn Accessibility (web.dev)](https://web.dev/learn/accessibility) - Free Google course on web accessibility, from basics to tests. <sub>🎓 course</sub>
- [Web Accessibility (Udacity)](https://www.udacity.com/course/web-accessibility--ud891) - Free web accessibility course created with Google. <sub>🎓 course</sub>
