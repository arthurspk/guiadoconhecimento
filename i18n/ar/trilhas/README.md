## 🎨 مطوّر Front-end

> يبني الواجهات التي يستخدمها الناس في المتصفح.

1. **[🎨 Front-end](../areas/tecnologia/front-end.md)**: HTML وCSS وJavaScript والأطر البرمجية وإمكانية الوصول وأداء الويب.
2. **[🔤 لغات البرمجة](../areas/tecnologia/linguagens.md)**: Python وJavaScript وJava وGo وRust وC# وPHP وKotlin وSwift وعشرات غيرها.
3. **[🖌️ تصميم UI/UX](../areas/criacao/design-ui-ux.md)**: تصميم الواجهات وبحوث تجربة المستخدم وأنظمة التصميم والنماذج الأولية.
4. **[♿ إمكانية الوصول](../areas/carreira/acessibilidade.md)**: إمكانية الوصول الرقمي والتقنيات المساعدة والإدماج.
5. **[🛠️ أدوات المطوّرين](../areas/tecnologia/ferramentas-dev.md)**: المحررات وGit والطرفيات والإنتاجية وأدوات التطوير المساعدة.
6. **[✅ ضمان الجودة والاختبار](../areas/tecnologia/qa-testes.md)**: الاختبارات الآلية واليدوية واختبارات الأداء والجوّال وجودة البرمجيات.
7. **[🎁 الموارد المجانية](../areas/ferramentas/recursos-gratuitos.md)**: مكتبات الصور والأيقونات والخطوط واللوحات اللونية والنماذج التوضيحية (mockups) والقوالب.
8. **[💼 المسيرة المهنية والوظائف](../areas/carreira/carreira-vagas.md)**: الوظائف والسيرة الذاتية والمقابلات وخرائط المسار المهني والرواتب.
