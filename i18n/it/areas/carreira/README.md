### ♿ Accessibilità

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) - Raccomandazione W3C che definisce i criteri di accessibilità per il contenuto web. <sub>📖 documentazione</sub>
- [WCAG 2.1 em português](https://www.w3c.br/traducoes/wcag/wcag21-pt-BR/) - Traduzione ufficiale in portoghese delle linee guida WCAG 2.1, di W3C Brasil. <sub>📖 documentazione · 🇧🇷 pt-BR</sub>
- [W3C WAI](https://www.w3.org/WAI/) - W3C Web Accessibility Initiative Portal, con guide per profilo. <sub>📖 documentazione</sub>
- [eMAG](https://emag.governoeletronico.gov.br/) - Modello di Accessibilità in Governo Elettronico, riferimento brasiliano basato su WCAG. <sub>📖 documentazione · 🇧🇷 pt-BR</sub>
- [Lei Brasileira de Inclusão](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2015/lei/l13146.htm) - Legge 13,146/2015, che garantisce i diritti delle persone con disabilità, incluso l'accesso digitale. <sub>📖 documentazione · 🇧🇷 pt-BR</sub>
