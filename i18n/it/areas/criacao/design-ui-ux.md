## 🤖 IA per Design UI/UX

> Strumenti, skill, MCP, corsi, guide ai prompt e uso responsabile dell'IA per chi lavora con Design UI/UX. Vedi anche [🤖 IA per tutte le aree](../../ia/README.md).

### 💎 Essenziali di IA

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Documentazione del server MCP ufficiale Figma, che dà agli agenti AI il contesto dei file di progettazione per generare codice e modificare la tela; ampio uso richiede Dev o sede completa in piano… <sub>📖 documentazione</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Deposito ufficiale Figma con Guida all'installazione e competenze per gli agenti (progetto di implementazione, generare biblioteca, regole del sistema di progettazione) utilizzando Figma MCP.
- [Figma Make](https://www.figma.com/make/) - Figma AI risorsa che trasforma i suggerimenti e le cornici in prototipi funzionali con codice; incluso nei piani di Figma, con una parte dei crediti AI.
- [Google Stitch](https://stitch.withgoogle.com/) - Google Labs esperimento che genera app e interfacce web da testo o immagine, con esportazione a Figma e codice.
- [Framer AI](https://www.framer.com/ai/) - Produttore di siti web con agente AI in tela, che crea e modifica pagine reattive da istruzioni; gratuito per iniziare, pagato pubblicazione professionale.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - Server open source MCP che invia layout Figma e stili di file a Cursor, Claude Code e altri agenti implementano schermi più fedelmente.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Server MCP integrato da penpot, strumento di progettazione open source che consente agli agenti AI di leggere e creare elementi nei file di design.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Abilità ufficiale di Claude che guida la creazione di interfacce con direzione visiva definita, evitando il tipico aspetto generico delle pagine generate dall'AI.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Competenze e comandi di progettazione per gli agenti del codice, con regole automatiche che rilevano i comuni pregiudizi visivi nei front-end generati dall'IA.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Abilità basata su stili ricercabili, palette, coppie tipografiche e linee guida UX per gli agenti di generare interfacce attraverso più framework.
- [The Shape of AI](https://www.shapeof.ai/) - Libreria gratuita degli standard UX per i prodotti AI (imposte, regolazioni, controlli, segni di fiducia), utile alla progettazione delle interfacce risorse IA.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Guida gratuita di Google per la progettazione dei prodotti AI concentrati sulle persone con modelli su aspettative, spiegazioni, feedback e errori. <sub>📖 documentazione</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Raccolta di articoli e studi NN/g su AI in UX: ricerca con AI, progettazione chatbot e divulgazione dell'uso di AI; articoli gratuiti, corsi a pagamento.

### 🧪 Altri strumenti e risorse di IA

- [Accessibility DevKit LLM](https://github.com/lukeslp/accessibility-devkit-llm) - Generazione di testi, WCAG che controlla CLI e server MCP utilizzando modelli linguistici per flussi di lavoro di accessibilità.
- [AI Web Design Codex](https://github.com/Eneryleen/ai-web-design-codex) - Base di conoscenza di 60 guide cross-linked su web design, UX, accessibilità e conversione, per gli esseri umani e agenti AI.
- [Accessibility Multiskill](https://github.com/lukeslp/accessibility-multiskill) - WCAG 2.2 AA per gli agenti di codifica (Codice Claude, Codex, Cursor) che coprono le disabilità motorie, cognitive, visive e comunicative.
- [Designesy](https://www.designesy.org/) - 40-check design-system contratto motore di verifica. Scores qualsiasi URL contro DTCG 2025.10 token conformance, WCAG 2.2 AA, movimento e tipografia. Include DTCG token validatore, stylelint plugin…
- [Alt Text Local AI](https://github.com/lukeslp/alt-text-local-ai) - App desktop che genera testo alt per le immagini utilizzando modelli di visione Ollama locale — nessuna chiave API necessaria, nulla lascia la vostra macchina.
- [RatedWithAI](https://ratedwithai.com/) - Scanner di accessibilità del sito web alimentato dall'IA che controlla la conformità ADA e WCAG 2.2, alimentata da axe-core.
- [Tactual](https://github.com/tactual-dev/tactual) - Modelli il vero sforzo per gli utenti di tecnologia assistiva (AT) di trovare, raggiungere e utilizzare contenuti web interattivi sotto 5 profili di tecnologia assistive. CLI, MCP...
- [Transcription Vidéo (RGAA Checker)](https://rgaa-checker.com/outils/transcription-video) - Generatore di sottotitoli AI gratuito per audio/video caricato: produce capzioni VTT, SRT e TXT seguendo le linee guida francesi RGAA e Arcom.
- [RGAA Checker](https://rgaa-checker.com/) - Combina analisi statiche, test dinamici (axe-core) e analisi delle immagini AI, genera una dichiarazione di conformità e bandiere...
- [AltTextLab](https://www.alttextlab.com/) - Generatore di testo alt alimentato dall'intelligenza artificiale per immagini.
