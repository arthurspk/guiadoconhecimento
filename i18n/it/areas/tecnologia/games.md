### 💎 Essenziali di IA

- [Unity AI](https://unity.com/products/ai) - Utensili AI Unity: Assistente in editor, CLI, server MCP e plugin; procedura guidata richiede crediti o piani.
- [Unity ML-Agents](https://github.com/Unity-Technologies/ml-agents) - Toolkit open source per formare NPC e agenti con un apprendimento migliorato ed imitazione all'interno di Unity.
- [Unity MCP](https://github.com/CoplayDev/unity-mcp) - Server MCP che collega gli assistenti AI all'editor Unity per creare scene, script e attività.
- [Godot MCP](https://github.com/Coding-Solo/godot-mcp) - Server MCP per gli agenti di aprire, ruotare e debug progetti nel motore Godot.
- [Unreal MCP](https://github.com/chongdashu/unreal-mcp) - Server MCP che consente di controllare Unreal Engine da linguaggio naturale degli assistenti AI.
- [Blender MCP](https://github.com/ahujasid/blender-mcp) - Collega Blender agli assistenti AI per la modellazione 3D, scene e materiali guidati.
- [NVIDIA ACE for Games](https://developer.nvidia.com/ace) - NVIDIA set di tecnologie per creare personaggi di gioco conversazione e autonomi.
- [Scenario](https://www.scenario.com) - Generando la piattaforma AI per i giochi asset (immagine, 3D, video, audio) addestrati in stile studio; pagato.
- [Meshy](https://www.meshy.ai/) - Genera modelli 3D strutturati da testo o immagine per l'uso nei motori.
- [Ludo.ai](https://ludo.ai/) - Strumento di ricerca del mercato, ideazione e generazione degli asset per la progettazione dei giochi; paga con test.
- [Rosebud AI](https://rosebud.ai) - Crea giochi 2D e 3D che possono essere giocati nel browser da descrizioni in lingua naturale.
- [Hugging Face Deep RL Course](https://huggingface.co/learn/deep-rl-course/unit0/introduction) - Allenamento gratuito per il rinforzo con agenti addestrati in giochi e ambienti come Godot RL Agents. <sub>🎓 corso</sub>
- [AI Game DevTools](https://github.com/Yuan-ManX/ai-game-devtools) - Ampio catalogo di strumenti AI per fase della produzione di giochi.
