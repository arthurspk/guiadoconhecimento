- [screenshot-to-code](https://github.com/abi/screenshot-to-code) - Converti screenshot, mockup e disegni in HTML/Tailwind, React o Vue utilizzando modelli di visualizzazione; open source.
- [IA integrada do Chrome (Built-in AI)](https://developer.chrome.com/docs/ai) - Documentazione delle API AI in esecuzione sul proprio browser con modelli locali e WebMCP per integrare i siti web negli agenti. <sub>📖 documentazione</sub>
- [AI SDK (Vercel)](https://github.com/vercel/ai) - Libreria open source TypeScript per creare interfacce di chat e funzioni AI in React, Next.js, Svelte e Vue.
