## 🤖 IA per QA e Test

### 💎 Essenziali di IA

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - Agenti ufficiali di Playwright (planner, generatore e riscaldatore) che progettano, generano e correggono i test finali. <sub>📖 documentazione</sub>
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Server Microsoft MCP che consente agli agenti di navigare e testare le pagine tramite l'albero dell'accessibilità.
- [Stagehand](https://github.com/browserbase/stagehand) - Quadro di automazione del browser che mescola codice e istruzioni in lingua naturale; open source.
- [Keploy](https://github.com/keploy/keploy) - Generare test API e integrazione con i mock dal traffico reale registrato tramite eBFF; open source.
- [Qodo](https://www.qodo.ai/) - Piattaforma di revisione del codice e generazione di test AI per PR e IDE; prova gratuita, poi pagato.
- [Diffblue](https://www.diffblue.com/) - Genera test unità Java automaticamente con AI; pagato.
- [Applitools](https://applitools.com) - Piattaforma di test end-to-end con Visual AI per rilevare regressioni visive; pagata.
- [Meticulous](https://www.meticulous.ai/) - Genera e mantiene i test di regressione visiva da sessioni utente reali; pagato.
- [Octomind](https://octomind.dev) - Agente che scopre, genera e mantiene i test end-to-end in Playwright; pagato.
- [Checksum](https://checksum.ai) - Genera e mantiene i test end-to-end con AI dall'uso effettivo della domanda; pagata.
- [promptfoo](https://www.promptfoo.dev) - Strumento open source per testare, valutare e applicazioni di team rosso con LLM.
- [DeepEval](https://github.com/confident-ai/deepeval) - Quadro open source in stile pitest per prove unità di uscite LLM, RAG e agenti.
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - Certificazione ISTQB gratuita e syllabus sui test dei sistemi AI, tra cui ML e LLM. <sub>🎓 corso</sub>

- [Cutaway](https://github.com/half144/cutaway) - Gli agenti di codifica registrano i video demo lucidati dei flussi web da uno script JSON, con una fotocamera zooming, un cursore e sfocatura del movimento.
- [Playwright Agent CLI](https://playwright.dev/agent-cli/introduction) - Interfaccia ufficiale di riga di comando per l'automazione del browser progettata per gli agenti codificanti, con comandi a basso consumo e competenze installabili.
- [Webcmd](https://github.com/agentrhq/webcmd) - CLI costruito su Playwright che impara una volta la navigazione di un sito e lo compila in comandi deterministici per-sito per gli agenti codificanti.
- [CasperJS](https://github.com/casperjs/casperjs) - Utilità di scripting e test per PhantomJS e SlimerJS. (archiviato 2018)
- [Chromeless](https://github.com/graphcool/chromeless) - Automazione Chrome reso semplice. Corre localmente o senza testa su AWS Lambda. (archiviato 2018)
- [DalekJS](https://github.com/dalekjs/dalek) - Test automatizzato del browser con JavaScript. Non più mantenuto dal 4 giu 2017.
- [dpxdt](https://github.com/bslatkin/dpxdt) - Test end-to-end con Python.
- [Huxley](https://github.com/facebookarchive/huxley) - Quadro Python basato su Selenium Webdriver.
- [Selenium with C#](http://seleniumhq.github.io/selenium/docs/api/dotnet/index.html) - Selenio C# bindings <sub>📖 documentazione</sub>
- [Atata](https://github.com/atata-framework/atata) - Test automatizzati di fotoricettore completo struttura in evidenza basato su Selenium WebDriver.
- [Strontium](https://github.com/jimevans/strontium) - Un'implementazione .NET (ma obsoleta) per Selenium/WebDriver (Remote) Server
- [TempMailGrab](https://tempmailgrab.com/api-docs) - API e-mail usa e getta per postazioni temporanee, estrazione OTP, link di verifica e webhooks in Playwright, Cypress e CI test.
- [Temp Mail 24](https://temp-mail24.com/) - Posta in arrivo temporanea basata sul browser per il test manuale di registrazione consentito.
- [8½ Minute Mail](https://8m30mail.com/) - Posta in arrivo temporanea per il test di verifica manuale delle e-mail, con una durata predefinita di 8 minuti-30 secondi e nessun account richiesto.
- [DATAMIMIC CE](https://github.com/rapiddweller/datamimic) - Motori a sorgente aperta e deterministica per i dati di test sintetici pilotati da modelli e la pseudonimizzazione PII. Perdere un seme ed ottenere output byte-identico con un hash dimostrativo su…
- [dbmask](https://github.com/sealandseacat/dbmask) - Maschera dati sensibili in database di test SQL con falsi deterministici e verifica la riga mascherante per fila.
- [Dummy Data Lab](https://timliu724.github.io/dummy-data-lab/) - Strumento browser offline, open source per trasformare CSV o TXT in dati fittizi controllati e generare set di dati collegati senza caricare file sorgente.
- [Geb](http://www.gebish.org/) - Può essere utilizzato per lo scripting, il raschiamento e l'automazione generale — o altrettanto come una soluzione di test funzionale/web/accettazione tramite integrazione con framework di prova…
- [dart.webdriver](https://github.com/google/webdriver.dart) - Fornisce attacchi WebDriver per Dart. Questi utilizzano l'interfaccia di WebDriver JSON, e come tale, richiedono l'uso del server remoto WebDriver.
- [WebdriverCSS](https://github.com/webdriverio/webdrivercss) - Strumento di test di regressione per WebdriverIO (attualmente deprecato, si prega di utilizzare wdio-screenshot per il momento).
- [Website-Diff](https://github.com/GeiserX/Website-Diff) - Strumento di confronto intelligente pagina web con supporto Wayback Machine e test di regressione visiva tramite Selenium.
- [JMeter Ant Task](https://github.com/jfifield/ant-jmeter) - Compito Ant per automatizzare l'esecuzione dei piani di test JMeter.
- [JMeter Maven Plugin](https://github.com/jmeter-maven-plugin/jmeter-maven-plugin) - Maven plugin che fornisce la capacità di eseguire test JMeter come parte della costruzione.
- [Elastic APM JS agent](https://github.com/elastic/apm-agent-rum-js) - Playwright viene utilizzato per eseguire test di benchmark attraverso i browser.
- [Winium.Cruciatus](https://github.com/2gis/Winium.Cruciatus) - C# Framework per il test automatizzato di applicazione Windows basato su piattaforme WinFroms e WPF.
- [elgalu/docker-selenium](https://github.com/elgalu/docker-selenium) - Selenium in Docker con Chrome & Firefox più supporto per la registrazione video.
