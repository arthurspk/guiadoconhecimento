### 💎 Essenziali di IA

- [SQL Console do Hugging Face](https://huggingface.co/docs/hub/datasets-viewer-sql-console) - Browser Console (DuckDB) per visualizzare i dataset Hub in SQL o la lingua naturale ed esportare risultati. <sub>📖 documentazione</sub>
- [Corpus Carolina](https://huggingface.co/datasets/carolina-c4ai/corpus-carolina) - Corpus ha aperto dal portoghese brasiliano contemporaneo di USP/C4AI, con oltre 2 milioni di documenti e provenienza registrata; CC BY 4.0. <sub>🇧🇷 pt-BR</sub>
- [Chatbot da Base dos Dados](https://basedosdados.org/chatbot-lp) - Chatbot con Gemini che trasforma le domande in query su più di 740 tavoli pubblici brasiliani; prova gratuita di 7 giorni, poi firma. <sub>🇧🇷 pt-BR</sub>
- [Croissant (MLCommons)](https://mlcommons.org/working-groups/data/croissant/) - Aprire il modello di metadati per i dataset ML, utilizzato da Hugging Face, Kaggle e Google Dataset Search. <sub>📖 documentazione</sub>
- [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) - Articolo di riferimento che propone documentare motivazione, composizione, raccolta e usi consigliati di tutti i dataset ML. <sub>📖 documentazione</sub>
- [Data Provenance Initiative](https://www.dataprovenance.org) - Iniziativa di ricerca che verifica l'origine, le licenze e le restrizioni dei dati utilizzati per formare i modelli AI.
- [Common Crawl](https://commoncrawl.org) - Archivio di monitoraggio web aperto e gratuito con centinaia di miliardi di pagine, la base di molti LLM corpora.
- [SDV (Synthetic Data Vault)](https://github.com/sdv-dev/SDV) - Libreria Python per generare dati tabulari sintetici da dati reali, utili per la prova e la condivisione sicura.
- [distilabel](https://github.com/argilla-io/distilabel) - Quadro open source per generare e valutare set di dati sintetici con LLM (istruzioni, preferenze, valutazione).
- [Argilla](https://github.com/argilla-io/argilla) - Piattaforma open source per la cura e l' annotazione dei dati con supporto LLM e feedback umano.
- [Label Studio](https://github.com/HumanSignal/label-studio) - Strumento open source per l'etichettatura di testo, immagine, audio e video con pre-notazione da modelli ML.
