### 🌍 Strumenti Online

- [iLovePDF](https://www.ilovepdf.com/pt) - Strumenti online per unire, dividere, comprimere e convertire i PDF. <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - Raccolta gratuita di strumenti PDF nel browser, senza limiti artificiali. <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - Convertitore di file online con supporto per oltre 200 formati.
- [TinyPNG](https://tinypng.com/) - Comprime immagini PNG, JPEG e WebP mantenendo la qualità visiva.
- [Squoosh](https://squoosh.app/) - Compressore di immagine Google in esecuzione localmente nel browser.

→ [Vedi tutti i 297 link di Strumenti Online](./ferramentas-online.md)

### 🖥️ App per macOS, Windows e Linux

- [AlternativeTo](https://alternativeto.net/) - Trova alternative a qualsiasi programma, filtraggio per sistema e licenza.
- [Homebrew](https://brew.sh/) - Gestione dei pacchetti per macOS e Linux.
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - Gestore di pacchetti ufficiale Windows per riga di comando. <sub>📖 documentazione · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - Installatore del programma di Windows tramite riga di comando, senza UAC.
- [Ninite](https://ninite.com/) - Installare e aggiornare più programmi di Windows in una sola volta, senza barre degli strumenti.

→ [Vedi tutti i 298 link di App per macOS, Windows e Linux](./apps-sistemas.md)

### 📲 App per Android e iOS

- [F-Droid](https://f-droid.org/) - Libero e open source Android app store.
- [Obtainium](https://obtainium.imranr.dev/) - Installare e aggiornare le app Android direttamente dalle pagine di rilascio (GitHub, GitLab).
- [Aurora OSS](https://auroraoss.com/) - Aurora Store progetto, client open source alternativo per il Play Store.
- [Signal](https://signal.org/) - Messaggero con crittografia end-to-end, senza annunci e nessun tracciamento.

### 🧩 Estensioni del Browser

- [uBlock Origin](https://ublockorigin.com/) - Leggero, open source ad blocker e trackers.
- [Privacy Badger](https://github.com/EFForg/privacybadger) - Estensione del EFF che impara e blocca i tracker invisibili.
- [Dark Reader](https://darkreader.org/) - Applicare la modalità oscura a qualsiasi sito, con regolazioni di luminosità e contrasto.
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - Salta automaticamente i frammenti sponsorizzati sui video di YouTube.
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - Riproduci il numero stimato di dischi su YouTube.

→ [Vedi tutti i 207 link di Estensioni del Browser](./extensoes-navegador.md)

### 🔗 API Pubbliche

- [Public APIs](https://github.com/public-apis/public-apis) - La lista più nota delle API gratuite, organizzata per categoria.
- [BrasilAPI](https://brasilapi.com.br/) - API gratuita con CEP, CNPJ, banche, vacanze, FIPE e altri dati brasiliani. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - Webservice gratuito di query CEP in JSON o XML. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Serie di scambio, Selic, Pix e credito con accesso API. <sub>📖 documentazione · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - Catalogo dei dati aperti dal governo federale. <sub>🇧🇷 pt-BR</sub>
