## 🔎 Come viene costruita la lista

> La selezione è automatica e riproducibile; nulla è scritto a mano.

- Le query di ogni professione si trovano in `data/repos-ia-consultas.json`, raggruppate per tema.
- Lo script `scripts/coletar_repos_ia.py` interroga la ricerca pubblica di GitHub e ordina per stelle.
- Entrano solo repository attivi, con descrizione, con un chiaro segnale di IA nel nome, nella descrizione o negli argomenti, e fuori da una lista di blocco (contenuti per adulti, pirateria, imbrogli).
- Le stelle sono quelle del giorno della raccolta. Un repository può comparire in più di una professione.
