### 💎 Esenciales de IA

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - Agentes oficiales de Playwright (planificador, generador y calentador) que planifican, generan y corrigen las pruebas finales a extremo. <sub>📖 documentación</sub>
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Servidor MCP de Microsoft que permite a los agentes navegar y probar páginas vía árbol de accesibilidad.
- [Stagehand](https://github.com/browserbase/stagehand) - Marco de automatización del navegador que mezcla código e instrucciones en lenguaje natural; fuente abierta.
- [Keploy](https://github.com/keploy/keploy) - Generar pruebas de API e integración con mocks del tráfico real registrado a través de EBFF; código abierto.
- [Qodo](https://www.qodo.ai/) - Plataforma de revisión del código y generación de pruebas AI para PRs e IDE; prueba gratuita, luego pagada.
- [Diffblue](https://www.diffblue.com/) - Genera pruebas de unidad Java automáticamente con IA; pagadas.
- [Applitools](https://applitools.com) - Plataforma de pruebas final a extremo con Visual AI para detectar regresiones visuales; pagado.
- [Meticulous](https://www.meticulous.ai/) - Genera y mantiene pruebas de regresión visual desde sesiones reales del usuario; pagadas.
- [Octomind](https://octomind.dev) - Agente que descubre, genera y mantiene pruebas de extremo a extremo en Playwright; pagado.
- [Checksum](https://checksum.ai) - Genera y mantiene pruebas de extremo a extremo con IA desde el uso real de la aplicación; pagada.
- [promptfoo](https://www.promptfoo.dev) - Herramienta de código abierto para probar, evaluar y aplicaciones en equipo rojo con LLM.
- [DeepEval](https://github.com/confident-ai/deepeval) - Marco de código abierto al estilo Pytest para pruebas unitarias de LLM, RAG y productos agentes.
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - Certificación y programa gratuitos de ISTQB sobre pruebas de sistemas AI, incluyendo ML y LLM. <sub>🎓 curso</sub>
