### 🔀 Ingeniería de Datos

- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) - Curso libre y abierto construyendo una tubería completa con Docker, Terraform, dbt, Spark y Kafka. <sub>🎓 curso</sub>
- [roadmap.sh - Data Engineer](https://roadmap.sh/data-engineer) - script interactivo que estudiar para convertirse en un ingeniero de datos.
- [Microsoft Learn - Engenheiro de Dados](https://learn.microsoft.com/pt-br/training/career-paths/data-engineer) - Ruta oficial y gratuita portuguesa con módulos de ingeniería de datos en Azure. <sub>🎓 curso · 🇧🇷 pt-BR</sub>
- [Designing Data-Intensive Applications](https://dataintensive.net/) - El libro de Martin Kleppmann sobre los fundamentos de sistemas de datos distribuidos, almacenamiento y streaming. <sub>📚 libro</sub>
- [Big Book of Data Engineering](https://www.databricks.com/resources/ebook/big-book-of-data-engineering) - Databricks libre ebook con patrones y casos prácticos de oleoductos y lagos. <sub>📚 libro</sub>

→ [Ver los 210 links de Ingeniería de Datos](./engenharia-de-dados.md)

### 🧠 Ciencia de Datos y Machine Learning

- [Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) - Curso introductorio Clásico ML de Stanford y DeepLearning.AI, con opción de registro gratuita. <sub>🎓 curso</sub>
- [Machine Learning Crash Course (Google)](https://developers.google.com/machine-learning/crash-course) - Curso gratuito y práctico de Google con vídeos, vistas interactivas y ejercicios. <sub>🎓 curso</sub>
- [Practical Deep Learning for Coders (fast.ai)](https://course.fast.ai/) - Curso de Aprendizaje Profundo gratuito aplicado a aquellos que ya programan, con PyTorch y Fastai. <sub>🎓 curso</sub>
- [An Introduction to Statistical Learning](https://www.statlearning.com/) - Libro de referencia en el aprendizaje estadístico, con libre PDF y ediciones en R y Python. <sub>📚 libro</sub>
- [Dive into Deep Learning](https://d2l.ai/) - Libro interactivo y gratuito de aprendizaje profundo con código ejecutable en PyTorch, TensorFlow y JAX. <sub>📚 libro</sub>

### ✨ IA Generativa y LLMs

- [Prompt Engineering Guide](https://www.promptingguide.ai/pt) - Guía abierta para técnicas de ingeniería Prompt, RAG y Agent con versión portuguesa. <sub>📖 documentación · 🇧🇷 pt-BR</sub>
- [Generative AI for Beginners (Microsoft)](https://github.com/microsoft/generative-ai-for-beginners) - Curso gratuito en 21 lecciones sobre aplicaciones con generativa AI, con traducción al portugués. <sub>🎓 curso</sub>
