## ⭐ Un adelanto de cada área

> Los primeros esenciales de cada área de este sector, para que te hagas una idea de lo que hay en cada página.

### 🌍 Herramientas Online

- [iLovePDF](https://www.ilovepdf.com/pt) - Herramientas en línea para unir, dividir, comprimir y convertir PDFs. <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - Colección gratuita de herramientas PDF en el navegador, sin límites artificiales. <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - Conversor de archivos en línea con soporte para más de 200 formatos.
- [TinyPNG](https://tinypng.com/) - Compresora imágenes PNG, JPEG y WebP manteniendo la calidad visual.
- [Squoosh](https://squoosh.app/) - Compresor de imagen de Google que se ejecuta localmente en el navegador.

→ [Ver los 297 links de Herramientas Online](./ferramentas-online.md)

### 🪄 Herramientas de IA

- [ChatGPT](https://chatgpt.com/) - OpenAI AI Wizard para texto, código, imágenes y búsqueda.
- [Claude](https://claude.ai/) - Antropopic AI Assistant for writing, analysis and programming.
- [Gemini](https://gemini.google.com/) - El Asistente de IA de Google se integra en los servicios de la cuenta de Google.
- [Microsoft Copilot](https://copilot.microsoft.com/) - Gratuito Microsoft AI Wizard para chat y creación de imagen.
- [Perplexity](https://www.perplexity.ai/) - Buscador con AI que responda citando las fuentes.

→ [Ver los 268 links de Herramientas de IA](./ferramentas-ia.md)

### 🏠 Self-hosted

- [awesome-selfhosted.net](https://awesome-selfhosted.net/) - Versión navegable de la lista principal del software para acogerse.
- [selfh.st](https://selfh.st/) - Boletín semanal y directorio de aplicaciones auto hospedadas.
- [Docker Docs](https://docs.docker.com/) - Documentación oficial de Docker, base de la mayoría de las instalaciones auto hospedadas. <sub>📖 documentación</sub>
- [LinuxServer.io](https://www.linuxserver.io/) - Imágenes de Docker estándar y documentadas para docenas de aplicaciones.
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) - Plataforma de virtualización abierta para servidores domésticos y empresariales.

→ [Ver los 299 links de Self-hosted](./self-hosted.md)

### 🖥️ Apps para macOS, Windows y Linux

- [AlternativeTo](https://alternativeto.net/) - Busque alternativas a cualquier programa, filtrando por sistema y licencia.
- [Homebrew](https://brew.sh/) - Administrador de paquetes para macOS y Linux.
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - Administrador oficial del paquete de Windows por línea de comandos. <sub>📖 documentación · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - Windows programa instalador a través de línea de comandos, no UAC.
- [Ninite](https://ninite.com/) - Instala y actualiza varios programas de Windows a la vez, sin barras de herramientas.

→ [Ver los 298 links de Apps para macOS, Windows y Linux](./apps-sistemas.md)

### 📲 Apps para Android e iOS

- [F-Droid](https://f-droid.org/) - Libre y de código abierto Android App store.
- [Obtainium](https://obtainium.imranr.dev/) - Instala y actualiza las aplicaciones Android directamente desde las páginas de lanzamiento (GitHub, GitLab).
- [Aurora OSS](https://auroraoss.com/) - Proyecto Aurora Store, cliente de código abierto alternativo para el Play Store.
- [Signal](https://signal.org/) - Mensajero con encriptación de extremo a extremo, sin anuncios y sin seguimiento.
- [Organic Maps](https://organicmaps.app/) - Mapas sin línea con navegación, senderos y ningún seguimiento basado en OpenStreetMap.

→ [Ver los 208 links de Apps para Android e iOS](./apps-celular.md)

### 🧩 Extensiones de Navegador

- [uBlock Origin](https://ublockorigin.com/) - Ligero, bloqueador de anuncios y rastreadores de código abierto.
- [Privacy Badger](https://github.com/EFForg/privacybadger) - Ampliación del EFF que aprende y bloquea los rastreadores invisibles.
- [Dark Reader](https://darkreader.org/) - Aplicar modo oscuro a cualquier sitio, con brillo y ajustes de contraste.
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - Automáticamente salta fragmentos patrocinados en videos de YouTube.
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - Reproduce el recuento estimado de discos en YouTube.

→ [Ver los 207 links de Extensiones de Navegador](./extensoes-navegador.md)

### 🔗 APIs Públicas

- [Public APIs](https://github.com/public-apis/public-apis) - La lista más conocida de API libres, organizada por categoría.
- [BrasilAPI](https://brasilapi.com.br/) - API gratuita con CEP, CNPJ, bancos, vacaciones, FIPE y otros datos brasileños. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - Servicio web gratuito de consulta CEP en JSON o XML. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Serie de intercambio, Selic, Pix y crédito con acceso API. <sub>📖 documentación · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - Catálogo de conjuntos de datos abiertos del gobierno federal. <sub>🇧🇷 pt-BR</sub>

→ [Ver los 298 links de APIs Públicas](./apis-publicas.md)

### ⚡ Automatización y No-code

- [n8n](https://n8n.io/) - Automatización de corriente con editor visual y código, que puede ser auto-anfitriona.
- [Zapier](https://zapier.com/) - Automatización sin código que conecta miles de aplicaciones.
- [Make](https://www.make.com/) - Automatización visual de flujos con miles de integraciones y plan libre.
- [IFTTT](https://ifttt.com/) - Fácil gatillo y automatizaciones de acción entre las aplicaciones y el hogar inteligente.
- [Node-RED](https://nodered.org/) - Programación de flujo visual para integrar APIs, dispositivos y servicios.
