- [File name](https://www.youtube.com/watch?v=h2SWuUobbr0) - 짧은 설명 이름을 사용하십시오. <sub>🎬 동영상</sub>
- [Optimization](https://imageoptim.com/) - 일부 메타 정보를 제거하여 이미지를 최적화합니다.
- [Responsive Images](https://www.w3.org/TR/html-picture-element/) - 창 크기에 가장 최적화된 이미지가 나옵니다.
- [Unplayable content](https://developers.google.com/webmasters/mobile-sites/mobile-seo/common-mistakes/unplayable-content) - unplayable 비디오 콘텐츠를 피하십시오. Flash 대신 HTML5 태그를 사용하십시오. <sub>📖 문서</sub>
- [AppLinks](http://applinks.org/documentation/) - 콘텐츠에 대한 링크는이 메타데이터를 사용하여 앱으로 딥링크로 사용할 수 있습니다.
- [mobile friendly](https://googlewebmastercentral.blogspot.be/2014/11/helping-users-find-mobile-friendly-pages.html) - 모바일 최적화된 사이트가 검색 결과에 표시됩니다. 모바일 친화적 인 사이트에 대한 테스트.
- [Smart App Banner](https://developer.apple.com/library/ios/documentation/AppleApplications/Reference/SafariWebContent/PromotingAppswithAppBanners/PromotingAppswithAppBanners.html) - Safari는 웹 사이트에서 App Store에서 앱을 홍보하는 표준화 된 방법을 제공하는 스마트 앱 배너 기능이 있습니다. <sub>📖 문서</sub>
- [Tap targets](https://developers.google.com/speed/docs/insights/SizeTapTargetsAppropriately) - 클릭할 수 있는 링크는 너무 작아야 합니다. <sub>📖 문서</sub>
- [HTML sitemap](https://www.youtube.com/watch?v=hi5DGOu1uA0) - HTML sitemap은 사이트 방문자가 쉽게 웹 사이트를 탐색 할 수 있습니다. <sub>🎬 동영상</sub>
- [Image sitemap](https://support.google.com/webmasters/answer/178636) - 이미지가 이미지 검색 결과에서 찾을 수 있음을 증가시킵니다.
- [Mobile sitemap](https://support.google.com/webmasters/answer/6082207) - 기능 폰의 경우 모바일 사이트 맵을 만들 수 있습니다.
- [Video sitemap](https://support.google.com/webmasters/answer/80471) - 확인, 검색 엔진에 대해 알고 모든 비디오 콘텐츠 사이트에.
- [XML sitemap](https://support.google.com/webmasters/answer/183668) - 페이지를 색인하기 위해 검색 엔진을 돕습니다.
- [Facebook](https://developers.facebook.com/docs/sharing/best-practices) - 웹 사이트 및 모바일 앱에 대한 모범 사례 공유. <sub>📖 문서</sub>
- [OpenGraph](http://ogp.me/) - Open Graph 프로토콜은 소셜 그래프에서 풍부한 객체가 될 웹 페이지를 가능하게합니다.
- [Social Profiles](https://developers.google.com/webmasters/structured-data/customize/social-profiles) - Google 검색 결과에 소셜 프로필을 추가합니다. <sub>📖 문서</sub>
- [Twitter](https://dev.twitter.com/cards/getting-started) - 트위터 카드로, 당신은 사진을 첨부 할 수 있습니다, 비디오 및 미디어 경험은 Tweets.

- [Google Search Console (GWT)](https://www.google.com/webmasters/) - 웹마스터를 허용하여 색인 상태를 확인하고 웹 사이트의 가시성을 최적화하십시오.
- [Google Tag Manager](https://www.google.com/analytics/tag-manager/) - Google Analytics Tag Manager에 대해 자세히 알아보기 및 IT 요청을 단순화하는 데 도움이 될 수있는 방법. 몇 번의 클릭으로 새로운 태그를 시작합니다.
- [Facebook Debugger](https://developers.facebook.com/tools/debug) - 스크랩을 입력하면 페이지의 마크업이 Facebook에 어떻게 표시되는지 확인할 수 있습니다. <sub>📖 문서</sub>
- [Pinterest](https://developers.pinterest.com/rich_pins/validator/) - 리치 핀을 유효 하 고 Pinterest에 그들을 얻을 적용. <sub>📖 문서</sub>
- [Structured Data Testing Tool](https://developers.google.com/structured-data/testing-tool/) - 풍부한 스니펫 또는 URL에서 붙여 넣기. <sub>📖 문서</sub>
- [Twitter card validator](https://cards-dev.twitter.com/validator) - 메타 태그로 페이지의 URL을 입력하여 유효성 검사합니다.
- [OuiSEO](https://github.com/carlsednaoui/seo-bookmarklet) - 페이지 SEO 및 소셜 메타 데이터 정보를 보여주는 오픈 소스 bookmarklet.
- [SEO Bookmarklet](https://twkm.ca/projects/seo-bookmarklet) - One-Stop SEO 책갈피는 빠르게 On-Site SEO를 검토합니다.
- [MozBar](https://moz.com/tools/seo-toolbar) - Moz의 SEO 도구 모음은 많은 페이지 SEO 요소, 도메인 및 페이지 권위 플러스 빠른 nofollow toggle에 대한 액세스를 제공합니다. 지금 무료 도구를 다운로드
- [Jekyll SEO Tag](https://github.com/jekyll/jekyll-seo-tag) - 검색 엔진 및 소셜 네트워크에 대한 메타 데이터 태그를 추가하는 Jekyll 플러그인은 사이트 내용을 더 잘 색인하고 표시합니다.
- [Basic SEO Features](https://typo3.org/extensions/repository/view/seo_basics) - 페이지 당 제목 태그에 대한 별도의 필드를 추가, 쉽고 SEO 친화적 인 키워드 및 새로운 모듈에서 설명 편집뿐만 아니라 유연한 Google 사이트 맵.
- [Google sitemap](https://typo3.org/extensions/repository/view/dd_googlesitemap) - 고성능 Google 사이트 맵 구현은 다른 유사한 확장으로 일반적인 오류를 피합니다.
- [All in One SEO Pack](https://wordpress.org/plugins/all-in-one-seo-pack/) - WordPress 용 가장 다운로드 된 플러그인 (최대 30 만 다운로드). 검색 엔진에 대한 사이트를 자동으로 최적화 할 수있는 하나의 SEO 팩에서 모든 것을 사용합니다.
- [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/) - WordPress SEO 개선 : 더 나은 콘텐츠를 작성하고 Yoast SEO 플러그인을 사용하여 완전히 최적화 된 WordPress 사이트가 있습니다.
- [Slim SEO](https://wordpress.org/plugins/slim-seo/) - 경량 WordPress SEO 플러그인으로 당신을 위한 자동화 된 SEO 작업.
