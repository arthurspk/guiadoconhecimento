## ⭐ 여기서 시작하세요

> 큐레이션에서 엄선한 QA와 테스트의 필수 링크입니다. 시간이 많지 않다면 이것만 보세요.

- [BSTQB](https://bstqb.online/) - ISTQB의 브라질 대표, 인증 및 무료 연구 자료. <sub>🇧🇷 pt-BR</sub>
- [ISTQB](https://www.istqb.org/) - 공식 소프트웨어 테스트 및 광택에 대한 인증의 국제 기관.
- [Julio de Lima](https://www.youtube.com/@juliodelimas) - QA의 소프트웨어 테스트, 자동화 및 경력에 대한 브라질 채널. <sub>📺 채널 · 🇧🇷 pt-BR</sub>
- [Ministry of Testing](https://www.ministryoftesting.com/) - ꀰ사, 코스 및 행사와 테스터의 국제 커뮤니티. <sub>👥 커뮤니티</sub>
- [Test Automation University](https://testautomationu.applitools.com/) - 무료 시험 자동화 과정 전문가에 의해 가르침. <sub>🎓 강좌</sub>
- [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) - 시험에 대한 참조 문서는 연습에서 피라미드.
- [Selenium](https://www.selenium.dev/documentation/) - 브라우저 자동화를 위한 Selenium WebDriver 및 Grid 문서. <sub>📖 문서</sub>
- [Playwright](https://playwright.dev/) - Chromium, Firefox 및 WebKit에 대한 테스트 프레임 워크를 종료하십시오.
- [Cypress](https://docs.cypress.io/) - End-to-end 테스트 프레임 워크 문서 및 웹 구성 요소. <sub>📖 문서</sub>
- [Appium](https://appium.io/docs/en/latest/) - 모바일 테스트 자동화 프레임 워크의 문서. <sub>📖 문서</sub>
- [Robot Framework](https://robotframework.org/) - 오픈 소스 키워드 중심 테스트 자동화 프레임 워크.
- [Cucumber](https://cucumber.io/docs/) - Gherkin에 대한 BDD 도구 문서. <sub>📖 문서</sub>
- [Jest](https://jestjs.io/pt-BR/) - JavaScript 테스트 프레임 워크는 포르투갈어로 문서화됩니다. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [pytest](https://docs.pytest.org/) - 메인 파이썬 테스트 프레임 워크의 문서. <sub>📖 문서</sub>
- [JUnit](https://junit.org/) - 표준 Java 생태계 테스트 프레임 워크. <sub>📖 문서</sub>
- [Grafana k6](https://grafana.com/docs/k6/latest/) - JavaScript 스크립트를 사용하여 로드 및 성능 테스트 도구의 문서. <sub>📖 문서</sub>
- [Apache JMeter](https://jmeter.apache.org/) - 오픈 소스로드 및 성능 테스트 도구.
- [Postman Learning Center](https://learning.postman.com/) - Postman과 API를 테스트하고 자동화하는 문서. <sub>📖 문서</sub>
- [The Internet (Heroku)](https://the-internet.herokuapp.com/) - 웹 테스트 자동화를 수행 할 준비가 된 시나리오가있는 사이트.
- [Sauce Demo](https://www.saucedemo.com/) - 훈련 테스트 자동화에 사용되는 데모 숍.

- [Stagehand](https://github.com/browserbase/stagehand) - 자연적인 언어에 있는 부호와 지시를 섞는 브라우저 자동화 기구; 근원을 여십시오.
- [Keploy](https://github.com/keploy/keploy) - eBFF를 통해 기록된 실제 트래픽에서 조끼와 API 테스트 및 통합을 생성; 오픈 소스.
- [Qodo](https://www.qodo.ai/) - 코드 검토 플랫폼 및 AI 테스트 세대 PR과 IDE; 무료 평가판, 그 후 지불.

- [Meticulous](https://www.meticulous.ai/) - 실제 사용자 세션에서 시각적 회귀 테스트를 생성하고 유지; 유료.
- [Octomind](https://octomind.dev) - 발견, 생성 및 Playwright에서 최종 테스트 유지; 유료.

- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - 무료 ISTQB 인증 및 ML과 LLM을 포함한 AI 시스템 테스트에 실라루스. <sub>🎓 강좌</sub>
