- [LanguageTool](https://languagetool.org/pt-BR) - Grammar 중개인은 어떤 텍스트 필드에서 작동 포르투갈어 지원. <sub>🇧🇷 pt-BR</sub>

- [Refined GitHub](https://github.com/refined-github/refined-github) - GitHub 인터페이스에 수십 가지의 향상을 추가하는 확장.
