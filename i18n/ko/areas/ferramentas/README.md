## ⭐ 영역별 맛보기

> 이 부문에 속한 각 영역의 첫 필수 링크로, 각 페이지에 무엇이 있는지 미리 볼 수 있습니다.

### 🌍 온라인 도구

- [iLovePDF](https://www.ilovepdf.com/pt) - 온라인 도구 가입, 분할, 압축 및 PDF 변환. <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - 브라우저의 PDF 도구 무료 컬렉션, 인공 제한없이. <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - 200 개 이상의 형식의 지원이있는 온라인 파일 변환기.
- [TinyPNG](https://tinypng.com/) - PNG, JPEG 및 WebP 이미지를 압축하여 시각적 품질을 유지하십시오.
- [Squoosh](https://squoosh.app/) - 브라우저에서 로컬로 실행되는 Google 이미지 압축기.

→ [온라인 도구의 링크 297개 모두 보기](./ferramentas-online.md)

- [Claude](https://claude.ai/) - 쓰기, 분석 및 프로그래밍을위한 Anthropic AI Assistant.

- [Perplexity](https://www.perplexity.ai/) - 소스를 인용하여 응답하는 AI와 함께 검색.

### 🏠 Self-hosted

- [awesome-selfhosted.net](https://awesome-selfhosted.net/) - 소프트웨어의 주요 목록의 Navigable 버전은 자신을 호스팅합니다.
- [selfh.st](https://selfh.st/) - 주간 뉴스 레터 및 셀프 호스팅 앱 디렉토리.
- [Docker Docs](https://docs.docker.com/) - 공식 Docker 문서, 대부분의 자체 호스팅 시설. <sub>📖 문서</sub>
- [LinuxServer.io](https://www.linuxserver.io/) - 수십 개의 앱을 위한 표준 및 문서화 Docker 이미지.
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) - 홈 및 비즈니스 서버에 대한 가상화 플랫폼을 엽니 다.

→ [Self-hosted의 링크 299개 모두 보기](./self-hosted.md)

### 🖥️ macOS, Windows, Linux 앱

- [AlternativeTo](https://alternativeto.net/) - 모든 프로그램에 대한 대안을 찾아 시스템 및 라이센스에 의해 필터링.
- [Homebrew](https://brew.sh/) - macOS 및 Linux용 패키지 관리자.
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - 명령행의 공식 Windows 패키지 관리자. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - 명령 줄을 통해 Windows 프로그램 설치자, UAC 없음.
- [Ninite](https://ninite.com/) - 도구 모음없이 한 번에 여러 Windows 프로그램을 설치하고 업데이트하십시오.

→ [macOS, Windows, Linux 앱의 링크 298개 모두 보기](./apps-sistemas.md)

### 📲 Android와 iOS 앱

- [F-Droid](https://f-droid.org/) - 무료 및 오픈 소스 Android 앱 스토어.
- [Obtainium](https://obtainium.imranr.dev/) - 릴리스 페이지에서 직접 Android 앱 설치 및 업데이트 (GitHub, GitLab).
- [Aurora OSS](https://auroraoss.com/) - Aurora Store 프로젝트, Play 스토어에 대한 대안 오픈 소스 클라이언트.
- [Signal](https://signal.org/) - end-to-end 암호화, 광고 없음 및 추적을 가진 메신저.
- [Organic Maps](https://organicmaps.app/) - OpenStreetMap을 기반으로 탐색, 트레일 및 추적이있는 오프라인지도.

→ [Android와 iOS 앱의 링크 208개 모두 보기](./apps-celular.md)

### 🧩 브라우저 확장 프로그램

- [uBlock Origin](https://ublockorigin.com/) - 경량, 오픈 소스 광고 차단제 및 추적기.
- [Privacy Badger](https://github.com/EFForg/privacybadger) - EFF의 확장은 보이지 않는 추적기를 배우고 차단합니다.
- [Dark Reader](https://darkreader.org/) - 밝기 및 대비 조정과 함께 모든 사이트에 어두운 모드를 적용하십시오.
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - 자동으로 YouTube 동영상에서 스폰서 스니펫을 이동합니다.
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - YouTube에서 디스크의 추정된 수를 재생합니다.

→ [브라우저 확장 프로그램의 링크 207개 모두 보기](./extensoes-navegador.md)

### 🔗 공개 API

- [Public APIs](https://github.com/public-apis/public-apis) - 무료 API의 가장 잘 알려진 목록, 범주에 의해 조직.
- [BrasilAPI](https://brasilapi.com.br/) - CEP, CNPJ, 은행, 휴일, FIPE 및 기타 브라질 데이터 무료 API. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - JSON 또는 XML에서 CEP 쿼리의 무료 웹 서비스. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Exchange 시리즈, API 액세스와 Selic, Pix 및 크레딧. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 연방 정부에서 열린 데이터 세트 카탈로그. <sub>🇧🇷 pt-BR</sub>

- [Agência Brasil Fotos](https://agenciabrasil.ebc.com.br/fotos) - EBC 공공 회사 photojournalism 수집; 신용 규칙을 확인하십시오. <sub>🇧🇷 pt-BR</sub>
