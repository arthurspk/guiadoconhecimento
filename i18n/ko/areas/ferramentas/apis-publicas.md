- [BrasilAPI](https://brasilapi.com.br/) - CEP, CNPJ, 은행, 휴일, FIPE 및 기타 브라질 데이터 무료 API. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - JSON 또는 XML에서 CEP 쿼리의 무료 웹 서비스. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Exchange 시리즈, API 액세스와 Selic, Pix 및 크레딧. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 연방 정부에서 열린 데이터 세트 카탈로그. <sub>🇧🇷 pt-BR</sub>
- [API do Portal da Transparência](https://api.portaldatransparencia.gov.br/) - 데이터, 계약 및 연방 정부 서버 지출 API. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [Dados Abertos da Câmara](https://dadosabertos.camara.leg.br/) - MPs, 투표, 제안 및 집 비용 API. <sub>📖 문서 · 🇧🇷 pt-BR</sub>
- [AwesomeAPI](https://docs.awesomeapi.com.br/) - 무료 브라질 동전 인용 API 및 CEP. <sub>🇧🇷 pt-BR</sub>
- [JSONPlaceholder](https://github.com/typicode/jsonplaceholder) - 무료 가짜 REST API 테스트 및 프로토 타입.
- [PokéAPI](https://pokeapi.co/) - 무료 REST 및 GraphQL API with Pokémon data, 공부에 좋은.
- [REST Countries](https://restcountries.com/) - 국가 데이터: 인구, 통화, 언어, 깃발.
- [Open-Meteo](https://open-meteo.com/) - 무료, keyless 기후 API 미리보기 및 역사.
- [OpenWeather](https://openweathermap.org/api) - 현재 날씨와 예측을 위한 무료 플랜으로 Weather API.
- [NASA Open APIs](https://api.nasa.gov/) - 무료 NASA API, Mars에서 일과 이미지의 천문학 사진처럼.
