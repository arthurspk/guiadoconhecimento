## 🔎 목록을 만드는 방법

> 선정은 자동으로 이루어지고 다시 재현할 수 있으며, 손으로 쓴 것은 없습니다.

- 직업별 검색 쿼리는 `data/repos-ia-consultas.json`에 주제별로 묶여 있습니다.
- `scripts/coletar_repos_ia.py` 스크립트가 GitHub 공개 검색을 호출하고 스타 수 순으로 정렬합니다.
- 활발히 관리되고, 설명이 있으며, 이름·설명·토픽에 AI라는 신호가 분명하고, 차단 목록(성인 콘텐츠, 불법 복제, 부정행위)에 없는 저장소만 포함됩니다.
- 스타 수는 수집한 날 기준입니다. 한 저장소가 여러 직업에 나타날 수 있습니다.
