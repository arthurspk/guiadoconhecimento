- [LinkedIn Vagas](https://www.linkedin.com/jobs/) - アラートと簡略化されたアプリケーションを使用して、最大の専門ネットワークからバカンシを検索します。

- [Glassdoor Brasil](https://www.glassdoor.com.br/) - 従業員が報告するVacancies、会社の評価および賃金の範囲。 <sub>🇧🇷 pt-BR</sub>
- [Indeed Brasil](https://br.indeed.com/) - さまざまなウェブサイトや企業から広告を集約する求人検索アプリ。 <sub>🇧🇷 pt-BR</sub>
- [Catho](https://www.catho.com.br/) - カリキュラムの登録と給与ガイドでバカンシーズのブラジルサイト。 <sub>🇧🇷 pt-BR</sub>
