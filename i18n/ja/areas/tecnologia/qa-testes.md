## ⭐ まずはここから

> QAとテストの厳選リンクです。キュレーターが選び抜いたもので、時間があまりないときはまずこれらをどうぞ。

- [ISTQB](https://www.istqb.org/) - 公式ソフトウェアのテストおよび用語集の証明の国際組織。
- [Julio de Lima](https://www.youtube.com/@juliodelimas) - QAのソフトウェアテスト、オートメーションおよびキャリアに関するブラジルのチャネル。 <sub>📺 チャンネル · 🇧🇷 pt-BR</sub>
- [Ministry of Testing](https://www.ministryoftesting.com/) - 試験官の国際コミュニティは、記事やコース、イベントでもあります。 <sub>👥 コミュニティ</sub>
- [Test Automation University](https://testautomationu.applitools.com/) - 専門家が教える無料のテスト自動化コース。 <sub>🎓 コース</sub>
- [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) - 練習中のテストピラミッドに関する参照記事。
- [Selenium](https://www.selenium.dev/documentation/) - Selenium WebDriver およびブラウザの自動化のための Grid ドキュメント。 <sub>📖 ドキュメント</sub>
- [Playwright](https://playwright.dev/) - クロム、FirefoxおよびWebKit用のエンドツーエンドのテストフレームワーク。
- [Cypress](https://docs.cypress.io/) - エンドツーエンドのテストフレームワークのドキュメントとWebコンポーネント。 <sub>📖 ドキュメント</sub>
- [Appium](https://appium.io/docs/en/latest/) - モバイルテスト自動化フレームワークのドキュメント。 <sub>📖 ドキュメント</sub>
- [Robot Framework](https://robotframework.org/) - オープンソースのキーワード指向のテスト自動化フレームワークを開きます。
- [Cucumber](https://cucumber.io/docs/) - Gherkin による BDD ツールのドキュメント。 <sub>📖 ドキュメント</sub>
- [Jest](https://jestjs.io/pt-BR/) - ポルトガル語のドキュメントで JavaScript テストフレームワーク。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [pytest](https://docs.pytest.org/) - 主要な Python テストフレームワークのドキュメント。 <sub>📖 ドキュメント</sub>
- [JUnit](https://junit.org/) - 標準的なJavaエコシステムテストフレームワーク。 <sub>📖 ドキュメント</sub>
- [Grafana k6](https://grafana.com/docs/k6/latest/) - JavaScriptスクリプトでロードおよびパフォーマンステストツールのドキュメント。 <sub>📖 ドキュメント</sub>
- [Apache JMeter](https://jmeter.apache.org/) - オープンソースのロードとパフォーマンステストツール。
- [Postman Learning Center](https://learning.postman.com/) - Postman で API をテストし、自動化するドキュメント。 <sub>📖 ドキュメント</sub>
- [The Internet (Heroku)](https://the-internet.herokuapp.com/) - ウェブテストの自動化を実践するシナリオでサイト。
- [Sauce Demo](https://www.saucedemo.com/) - テストオートメーションを訓練するのに使用される実証店。

## 🤖 QAとテストのAI

> QAとテストの仕事に役立つAIツール、スキル、MCP、コース、プロンプトガイド、責任あるAI利用の情報をまとめています。[🤖 すべての分野のAI](../../ia/README.md)もあわせてご覧ください。

### 💎 AIの厳選リンク

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - プレイライト(プランナー、発電機およびヒーター)の公式エージェントが計画し、エンドツーエンドのテストを生成して正しいものにします。 <sub>📖 ドキュメント</sub>
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Microsoft MCP サーバーは、エージェントがアクセシビリティツリーを使用してページを閲覧およびテストすることを可能にします。
- [Stagehand](https://github.com/browserbase/stagehand) - コードと自然言語の指示を混合するブラウザ自動化フレームワーク;オープンソース。
- [Keploy](https://github.com/keploy/keploy) - eBFF で記録された実際のトラフィックからのモックと API テストおよび統合を生成します。オープンソース.
- [Qodo](https://www.qodo.ai/) - コードレビュープラットフォームとPRやIDEのAIテスト生成。無料トライアル、その後有料。
- [Diffblue](https://www.diffblue.com/) - JavaユニットテストをAIで自動生成し、有料化。
- [Applitools](https://applitools.com) - ビジュアルAIによるエンドツーエンドテストプラットフォームで、視覚的な回帰を検知します。
- [Meticulous](https://www.meticulous.ai/) - 実際のユーザーセッションから視覚的な回帰テストを生成し、維持します。
- [Octomind](https://octomind.dev) - Playwrightでエンドツーエンドのテストを発見し、生成して維持するエージェント。有料。
- [Checksum](https://checksum.ai) - アプリケーションの実際の使用からAIでエンドツーエンドのテストを生成し、維持します。
- [promptfoo](https://www.promptfoo.dev) - LLMでテスト、評価および赤いチーム・アプリケーションをテストするオープンソース・ツール。
- [DeepEval](https://github.com/confident-ai/deepeval) - LLM、RAGおよびエージェントの出力ユニットテスト用のPytestスタイルのオープンソースフレームワーク。
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - MLやLLMなどのAIシステムテストでISTQB認証とシラバスが無料です。 <sub>🎓 コース</sub>
