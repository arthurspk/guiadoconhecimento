- [Khan Academy - Biologia](https://pt.khanacademy.org/science/biology) - ポルトガル語での無料クラスと生物学の演習。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [SiBBr](https://www.sibbr.gov.br/) - ブラジル生物多様性情報システム。種や生態系のデータを統合しています。 <sub>🇧🇷 pt-BR</sub>
- [Flora e Funga do Brasil](https://floradobrasil.jbrj.gov.br/) - ブラジルの植物、藻類および真菌の公式カタログは、リオデジャネイロの植物園によって維持されます。 <sub>🇧🇷 pt-BR</sub>
- [Instituto Butantan](https://butantan.gov.br/) - バイオメディカル研究センターとワクチンおよび血清の生産、科学的な普及コンテンツ。 <sub>🇧🇷 pt-BR</sub>
- [NCBI](https://www.ncbi.nlm.nih.gov/) - バイオメディカルとゲノムデータベースポータル(GenBank、BLAST、Gene、PubMed)。
- [Ensembl](https://www.ensembl.org/) - アノテーションやツールでゲノムブラウザやその他の生物を検証します。
- [UniProt](https://www.uniprot.org/) - シーケンスおよびタンパク質関数の参照ベース。
- [RCSB PDB](https://www.rcsb.org/) - 3D構造のタンパク質と核酸の銀行, 視聴者と一緒に.
- [AlphaFold Protein Structure Database](https://alphafold.ebi.ac.uk/) - 開いたアクセスAIによって提供される200,000,000以上の蛋白質の構造。
- [Galaxy](https://usegalaxy.org/) - プログラミングのないバイオインフォマティクス分析のための無料のWebプラットフォーム。
- [Bioconductor](https://www.bioconductor.org/) - ゲノムと生物学的データ解析のためのRパッケージの設計。
- [Biopython](https://biopython.org/) - コンピュータ生物学とバイオインフォマティクスのためのPythonライブラリ。
- [Rosalind](https://rosalind.info/) - プログラミングによるバイオインフォマティクスを学習するための実用的な問題。 <sub>🎓 コース</sub>
- [EMBL-EBI Training](https://www.ebi.ac.uk/training/) - データベースとバイオインフォマティクスツールに関する無料のコースやチュートリアル。 <sub>🎓 コース</sub>
- [Biostars](https://www.biostars.org/) - バイオインフォマティクスやゲノムに関する質問と回答のフォーラム。 <sub>👥 コミュニティ</sub>
- [GBIF](https://www.gbif.org/) - 種発生時のオープンデータのグローバルネットワーク。
- [iNaturalist](https://www.inaturalist.org/) - 植物、動物および真菌を登録し、特定するために自然主義者のネットワーク。 <sub>👥 コミュニティ</sub>

## 🤖 生物学とバイオインフォマティクスのAI

> 生物学とバイオインフォマティクスの仕事に役立つAIツール、スキル、MCP、コース、プロンプトガイド、責任あるAI利用の情報をまとめています。[🤖 すべての分野のAI](../../ia/README.md)もあわせてご覧ください。

### 💎 AIの厳選リンク

- [AlphaFold Server](https://alphafoldserver.com/) - Google DeepMind Web サービスには、AlphaFold 3 を使用して、タンパク質構造とその相互作用を DNA、RNA および結合剤と予測します。無料非商用利用。
- [ColabFold](https://github.com/sokrypton/ColabFold) - Google Colabのノートブックで稼働しているAlphaFoldのアクセラレーテッドバージョンが、自分のインフラなしで構造を予測します。無料
- [ESM (EvolutionaryScale)](https://github.com/evolutionaryscale/esm) - タンパク質言語モデルESM3とESM Cは、シーケンス、構造体および機能の生成と解析を行う。オープンソース。
- [Evo 2 (Arc Institute)](https://github.com/ArcInstitute/evo2) - すべてのドメインのゲノムで訓練されたDNAの基礎モデルは、多様体の効果を予測し、シーケンスを生成する。
- [AlphaGenome](https://github.com/google-deepmind/alphagenome) - Google DeepMind API と、DNA シーケンスにおけるバリアントの規制効果を予測するモデル。非商用利用。
- [Virtual Cells Platform (Biohub/CZI)](https://virtualcellmodels.cziscience.com/) - ML-readyデータ、生物学者が定義したベンチマークとコードレス空間を含む仮想セルモデルを備えたエコシステム。
- [Biomni](https://github.com/snap-stanford/Biomni) - LLM、ツール、データベースを組み合わせて生物学の研究を行うスタンフォードバイオメディカルエージェント。
- [Life Sciences Marketplace para Claude](https://github.com/anthropics/life-sciences) - MCP と、PubMed、BioRender、Synapse などのライフサイエンスツール用のスキルサーバーを備えた Anthropic 公式プラグイン。
