### 📊 データ分析とBI

- [Documentação do Power BI](https://learn.microsoft.com/pt-br/power-bi/) - デスクトップからクラウドサービスまで、Power BIのポルトガル語で公式ドキュメント。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [Certificação PL-300 (Power BI Data Analyst)](https://learn.microsoft.com/pt-br/credentials/certifications/data-analyst-associate/) - パワーBIデータ分析認定の公式サイトで、無料学習ガイドと実用的評価をしています。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [DAX Guide](https://dax.guide/) - Power BIとExcelで使用されているDAX言語機能および演算子の完全な参照。 <sub>📖 ドキュメント</sub>
- [Fundação Bradesco - Escola Virtual](https://www.ev.org.br/) - 基本から上級までのExcelを含む証明書付きの無料のオンラインコース。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [Hashtag Treinamentos](https://www.youtube.com/@HashtagTreinamentos) - Excel、Power BI、SQL、およびPythonのクラスを持つブラジルのチャンネル。 <sub>📺 チャンネル · 🇧🇷 pt-BR</sub>

### 🔀 データエンジニアリング

- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) - Docker、Terraform、dbt、SparkおよびKafkaとの完全なパイプラインを造る自由で開いたコース。 <sub>🎓 コース</sub>
- [roadmap.sh - Data Engineer](https://roadmap.sh/data-engineer) - データエンジニアになるための学習よりもインタラクティブなスクリプト。
- [Microsoft Learn - Engenheiro de Dados](https://learn.microsoft.com/pt-br/training/career-paths/data-engineer) - Azureのデータエンジニアリングモジュールを備えた公式および無料のポルトガル語コース。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [Designing Data-Intensive Applications](https://dataintensive.net/) - 分散型データシステム、ストレージおよびストリーミングの基礎に関するマーティン・クルップマンの本。 <sub>📚 書籍</sub>
- [Big Book of Data Engineering](https://www.databricks.com/resources/ebook/big-book-of-data-engineering) - パイプラインや湖畔のパターンと実用的なケースを備えたDatabricksの無料電子ブック。 <sub>📚 書籍</sub>

→ [データエンジニアリングの全210件のリンクを見る](./engenharia-de-dados.md)

### 🧠 データサイエンスとmachine learning

- [Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) - スタンフォードとDeepLearning.AIのクラシックML入門コース、無料登録オプション。 <sub>🎓 コース</sub>
- [Machine Learning Crash Course (Google)](https://developers.google.com/machine-learning/crash-course) - Googleの動画、インタラクティブなビューと演習で無料で実用的なコース。 <sub>🎓 コース</sub>
- [Practical Deep Learning for Coders (fast.ai)](https://course.fast.ai/) - PyTorch と fastai を使って、既にプログラムしている人には、ディープラーニングコースが適用されます。 <sub>🎓 コース</sub>
- [An Introduction to Statistical Learning](https://www.statlearning.com/) - RとPythonの無料のPDFおよびエディションを使用して、統計学習における参照書。 <sub>📚 書籍</sub>
- [Dive into Deep Learning](https://d2l.ai/) - PyTorch、TensorFlow、JAX で実行可能なコードを持つインタラクティブかつ無料のディープラーニングブック。 <sub>📚 書籍</sub>

→ [データサイエンスとmachine learningの全298件のリンクを見る](./ciencia-de-dados-ml.md)

### 🗃️ データセットとオープンデータ

- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - ブラジル連邦政府の公式オープンデータカタログ。 <sub>🇧🇷 pt-BR</sub>
- [Base dos Dados](https://basedosdados.org/) - 数百ものブラジルのデータベースが処理され、SQL、Python、Rの準備ができるパブリックデータレイク。 <sub>🇧🇷 pt-BR</sub>
- [Brasil.IO](https://brasil.io/) - 企業、給与および選挙などのブラジルの公的なデータのオープンなフォーマットのリポジトリ。 <sub>🇧🇷 pt-BR</sub>
- [IBGE](https://www.ibge.gov.br/) - ブラジルにおける統計と地理の公式研究所のポータル。 <sub>🇧🇷 pt-BR</sub>
- [SIDRA - IBGE](https://sidra.ibge.gov.br/) - 研究テーブル、検閲とインデックスの相談・ダウンロードを行うIBGEシステム。 <sub>🇧🇷 pt-BR</sub>
