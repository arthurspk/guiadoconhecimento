## ⭐ まずはここから

> データセットとオープンデータの厳選リンクです。キュレーターが選び抜いたもので、時間があまりないときはまずこれらをどうぞ。

- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - ブラジル連邦政府の公式オープンデータカタログ。 <sub>🇧🇷 pt-BR</sub>
- [Base dos Dados](https://basedosdados.org/) - 数百ものブラジルのデータベースが処理され、SQL、Python、Rの準備ができるパブリックデータレイク。 <sub>🇧🇷 pt-BR</sub>
- [Brasil.IO](https://brasil.io/) - 企業、給与および選挙などのブラジルの公的なデータのオープンなフォーマットのリポジトリ。 <sub>🇧🇷 pt-BR</sub>
- [IBGE](https://www.ibge.gov.br/) - ブラジルにおける統計と地理の公式研究所のポータル。 <sub>🇧🇷 pt-BR</sub>
- [SIDRA - IBGE](https://sidra.ibge.gov.br/) - 研究テーブル、検閲とインデックスの相談・ダウンロードを行うIBGEシステム。 <sub>🇧🇷 pt-BR</sub>
- [Portal da Transparência](https://portaldatransparencia.gov.br/) - 連邦政府の支出、契約、サーバーおよび利点に関するデータ, オープンなダウンロードで. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do TSE](https://dadosabertos.tse.jus.br/) - 公式選挙データ:候補、electorate、結果および説明責任。 <sub>🇧🇷 pt-BR</sub>
- [Microdados do INEP](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados) - ENEM、学校Censusおよび他の教育評価からのマイクロデータ。 <sub>🇧🇷 pt-BR</sub>
- [DATASUS](https://datasus.saude.gov.br/) - SUの情報源、データおよび健康情報システムの供給部 <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - 中央銀行の利息シリーズ、為替レート、クレジットおよび支払いをAPIで取得します。 <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos da Câmara dos Deputados](https://dadosabertos.camara.leg.br/) - MP、投票および立法的な提案に関するAPIとアーカイブ。 <sub>🇧🇷 pt-BR</sub>
- [Querido Diário](https://github.com/okfn-brasil/querido-diario) - 公正な自治体の日記を収集し、リリースするオープンナレッジブラジルプロジェクト。 <sub>🇧🇷 pt-BR</sub>
- [Kaggle Datasets](https://www.kaggle.com/datasets) - コミュニティノートブックで何千ものパブリックデータセットを数えています。
- [Hugging Face Datasets](https://huggingface.co/datasets) - 機械学習とAIのための100万以上のデータセットを備えたハブ。
- [UCI Machine Learning Repository](https://archive.ics.uci.edu/) - MLの教えと研究のための古典的なデータセットリポジトリ。
- [Google Dataset Search](https://datasetsearch.research.google.com/) - Google Searcherは、Web公開されたデータセットを見つけることに特化しています。
- [Our World in Data](https://ourworldindata.org/) - 健康、貧困、気候、教育および世界経済に関するデータとグラフを開きます。
- [World Bank Open Data](https://data.worldbank.org/) - すべての国から開発指標を、無料アクセスで表示します。
- [data.europa.eu](https://data.europa.eu/) - 欧州諸国や機関から100万以上のオープンデータセットを集約するポータル。

## 🤖 データセットとオープンデータのAI

> データセットとオープンデータの仕事に役立つAIツール、スキル、MCP、コース、プロンプトガイド、責任あるAI利用の情報をまとめています。[🤖 すべての分野のAI](../../ia/README.md)もあわせてご覧ください。

### 💎 AIの厳選リンク

- [SQL Console do Hugging Face](https://huggingface.co/docs/hub/datasets-viewer-sql-console) - ブラウザコンソール(DuckDB)は、SQLまたは自然言語のハブデータセットを表示し、結果をエクスポートします。 <sub>📖 ドキュメント</sub>
- [Corpus Carolina](https://huggingface.co/datasets/carolina-c4ai/corpus-carolina) - 現代ブラジルのUSP/C4AIポルトガル語からオープンしたコーパスは、200万を超える文書と登録済みの実績を持ちます。 CC BY 4.0. <sub>🇧🇷 pt-BR</sub>
- [Chatbot da Base dos Dados](https://basedosdados.org/chatbot-lp) - 質問を740以上のブラジルの公共テーブルに変えるGeminiとチャットボット。 7日間の無料テスト、署名。 <sub>🇧🇷 pt-BR</sub>
- [Croissant (MLCommons)](https://mlcommons.org/working-groups/data/croissant/) - Hugging Face、Kaggle、Google Dataset Search で使用している ML データセット用のメタデータパターンを開きます。 <sub>📖 ドキュメント</sub>
- [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) - すべてのMLデータセットのモチベーション、構成、コレクションおよび推奨用途を文書化する参考文献記事。 <sub>📖 ドキュメント</sub>
- [Data Provenance Initiative](https://www.dataprovenance.org) - AIモデルを訓練するために使用されるデータの起源、ライセンスおよび制限を監査する研究イニシアチブ。
- [Common Crawl](https://commoncrawl.org) - 数百億ページで、LMSの無償版追跡アーカイブをオープンし、多くのLLMs corporaに基づいて作成します。
- [SDV (Synthetic Data Vault)](https://github.com/sdv-dev/SDV) - Python ライブラリは、実際のデータから合成の表形式のデータを生成し、テストや安全な共有に役立ちます。
- [distilabel](https://github.com/argilla-io/distilabel) - LLM(指示、好み、評価)で合成データセットを生成および評価するためのオープンソースフレームワーク。
- [Argilla](https://github.com/argilla-io/argilla) - LLMサポートと人間のフィードバックで、キュレーターシップやデータアノテーションのためのオープンソースプラットフォーム。
- [Label Studio](https://github.com/HumanSignal/label-studio) - MLモデルによる事前通知でテキスト、画像、音声およびビデオをラベル付けするためのオープンソースツール。
