### 🛡️ サイバーセキュリティ

- [Cartilha de Segurança para Internet (CERT.br)](https://cartilha.cert.br/) - 詐欺、パスワード、マルウェアおよびデータ保護に関するフェクシクルを持つブラジルの無料素材。 <sub>🇧🇷 pt-BR</sub>
- [CERT.br](https://www.cert.br/) - ブラジルの事件に対する国家的反応、統計、良い慣行と材料。 <sub>🇧🇷 pt-BR</sub>
- [OWASP Top 10](https://top10.owasp.org/) - ウェブアプリケーションにおける最も重要なセキュリティリスクのリスト。 <sub>📖 ドキュメント</sub>
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) - 理論と実践的な研究室で無料のWebセキュリティトレーニング。 <sub>🎓 コース</sub>
- [Hacker101](https://www.hacker101.com/) - HackerOneの無料WebセキュリティとCTFクラスは、バグ賞金を狙いました。 <sub>🎓 コース</sub>

### 🔎 OSINTと調査

- [OSINT Framework](https://github.com/lockfale/osint-framework) - 調査したデータの種類によって編成されたOSINTツールのインタラクティブマップ。
- [Bellingcat](https://www.bellingcat.com/) - オープンソースの調査で世界基準である調査ジャーナリストの組織。
- [Bellingcat Online Investigation Toolkit](https://bellingcat.gitbook.io/toolkit) - 研究ツールのカタログ、使用ガイド付き。
- [Guias da Bellingcat](https://www.bellingcat.com/category/resources/how-tos/) - 実用的な地理位置チュートリアル、衛星画像と検証。
- [Abraji](https://abraji.org.br/) - 調査ジャーナリスト協会、コースと評価ガイド。 <sub>👥 コミュニティ · 🇧🇷 pt-BR</sub>

→ [OSINTと調査の全205件のリンクを見る](./osint.md)

### 🕶️ プライバシーとデータ保護

- [LGPD - Lei 13.709/2018](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm) - 一般データ保護法の公式および更新されたテキスト。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [ANPD](https://www.gov.br/anpd/pt-br) - ガイド、規則および報告チャネルが付いている国家データ保護の権限。 <sub>🇧🇷 pt-BR</sub>
- [Curso de Introdução à LGPD (Escola Virtual.Gov)](https://www.escolavirtual.gov.br/curso/153) - LGPDで連邦政府のオープンコースとフリーコース、証明書付き。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [Cartilha CERT.br - Fascículos](https://cartilha.cert.br/fasciculos/) - プライバシー、データ保護、ソーシャルネットワーク、および漏洩に関する無料のfascicles。 <sub>🇧🇷 pt-BR</sub>
- [Surveillance Self-Defense (EFF)](https://ssd.eff.org/pt-br) - デジタル監視から身を守るためにポルトガルのEFFガイド。 <sub>🇧🇷 pt-BR</sub>
