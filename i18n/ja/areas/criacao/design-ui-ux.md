## ⭐ まずはここから

> UI/UXデザインの厳選リンクです。キュレーターが選び抜いたもので、時間があまりないときはまずこれらをどうぞ。

- [Figma](https://www.figma.com/) - インターフェイスの設計、試作および手渡のための市場の標準的な共同用具は自由計画と設計します。
- [Penpot](https://penpot.app/) - Figma への代替オープンソース, ブラウザで実行し、セルフホストすることができます.
- [Laws of UX](https://lawsofux.com/) - インターフェイス設計に適用される心理学の主要な法律とヒューリスティックスのコレクション。
- [Nielsen Norman Group - Artigos](https://www.nngroup.com/articles/) - ユーザビリティ調査、UX研究およびインタラクション設計に基づく記事や動画。
- [Material Design 3](https://m3.material.io/) - インターフェイスのためのガイドライン、コンポーネントおよびトークンが付いているGoogleの設計システム。 <sub>📖 ドキュメント</sub>
- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) - iOS、macOSなどのプラットフォームでインターフェイスを設計するための公式Appleガイドライン。 <sub>📖 ドキュメント</sub>
- [WCAG - W3C WAI](https://www.w3.org/WAI/standards-guidelines/wcag/) - Webコンテンツアクセシビリティガイドライン(WCAG 2.2)の公式概要 <sub>📖 ドキュメント</sub>
- [Google UX Design Professional Certificate](https://www.coursera.org/professional-certificates/google-ux-design) - 研究から試作まで、完全なUXプロセスを覆うCoursraのGoogle認定。 <sub>🎓 コース</sub>
- [Interaction Design Foundation](https://www.interaction-design.org/) - UXコースと百科事典、インタラクションデザイン。オープン記事やサブスクリプションコースも用意しています。 <sub>🎓 コース</sub>
- [Mobbin](https://mobbin.com/) - 実際の画面のライブラリとUIリファレンス用のアプリやウェブサイトのストリーム、無料プラン。
- [The Component Gallery](https://component.gallery/) - 公開設計システムの数十種類から事例を持つインターフェイスコンポーネントのカタログ。
- [Growth.Design - Case Studies](https://growth.design/case-studies) - 既知の企業におけるUX決定と製品心理学に関するコミックケースの研究。
- [UX Collective Brasil](https://brasil.uxdesign.cc/) - UX、UI、キャリアデザインに関する記事や翻訳でポルトガル語の出版物。 <sub>🇧🇷 pt-BR</sub>
- [Origamid](https://www.origamid.com/) - UIデザイン、タイポグラフィとフロントエンドのコースを持つブラジルの学校。 <sub>🎓 コース · 🇧🇷 pt-BR</sub>
- [Refactoring UI](https://www.refactoringui.com/) - インターフェイスをより明確にし、より美しくする必要がある人のためのUIの技術の実用的な本。 <sub>📚 書籍</sub>
- [Dribbble](https://dribbble.com/) - 視覚的なインスピレーションとUIポートフォリオのためのデザイナーのコミュニティ。 <sub>👥 コミュニティ</sub>

## 🤖 UI/UXデザインのAI

> UI/UXデザインの仕事に役立つAIツール、スキル、MCP、コース、プロンプトガイド、責任あるAI利用の情報をまとめています。[🤖 すべての分野のAI](../../ia/README.md)もあわせてご覧ください。

### 💎 AIの厳選リンク

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - 図間公式MCPサーバのドキュメンテーション、AIエージェントはデザインファイルのコンテキストを生成し、キャンバスを編集します。幅広い用途では有料プランでDevまたはFullシートが必要です。 <sub>📖 ドキュメント</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Figma MCP を用いたインストレーションガイドとエージェントのスキル(導入設計、ライブラリの作成、デザインシステムルール)による公式図鑑リポジトリ。
- [Figma Make](https://www.figma.com/make/) - プロンプトとフレームをコードで機能的なプロトタイプに変換し、Figma AI リソースに含まれている。これは、AI クレジットのシェアを持つ Figma 計画に含まれる。
- [Google Stitch](https://stitch.withgoogle.com/) - テキストや画像からアプリとWebインターフェイスを生成するGoogle Labs実験、図表にエクスポートします。
- [Framer AI](https://www.framer.com/ai/) - キャンバスでAIエージェントとWebサイトビルダー。これにより、レスポンシブページを指示から作成および編集できます。無料で開始、有料のプロフェッショナルな出版物。
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - MCP オープンソースサーバーは、Figma のレイアウトやファイルスタイルを Cursor, Claude コードやその他のエージェントに送信し、画面をより忠実に実行します。
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - ペンポ集積MCPサーバー、AIエージェントが設計ファイル内の要素を読み取り作成できるようにオープンソースの設計ツール。
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Claudeの公式スキルは、AIによって生成されたページの典型的な汎用的な外観を避ける、定義された視覚的方向でインターフェイスの作成を導きます。
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - コードエージェントのスキルと設計コマンド、AIが生成したフロントエンドで共通視線を検知する自動ルール。
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - エージェントの検索可能なスタイル、パレット、タイポグラフィペアとUXガイドラインに基づいてスキルは、複数のフレームワーク間でインターフェイスを生成します。
- [The Shape of AI](https://www.shapeof.ai/) - AI製品のUX規格(エントリー、調整、制御、信頼の兆し)の無料ライブラリ。IAリソースインターフェイスの設計に役立ちます。
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - 期待、説明、フィードバック、エラーに関するパターンで人中心のAI製品を設計するためのGoogleの無料ガイド。 <sub>📖 ドキュメント</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - UXにおけるAIに関するNN/gの記事や研究の収集:人工知能の研究、チャットボットの設計とAIの使用の開示;無料記事、有料コース。

### 🧪 その他のAIツールとリソース

- [Accessibility DevKit LLM](https://github.com/lukeslp/accessibility-devkit-llm) - Altテキスト生成、WCAG 監査 CLI、MCP サーバーで言語モデルを使用してアクセシビリティワークフロー。OpenAI、Anthropic、HuggingFace、Ollama と連携します。

- [Designesy](https://www.designesy.org/) - 40-check設計システム契約検証エンジン。 DTCG 2025.10トークンの適合、WCAG 2.2 AA、モーション、およびタイポグラフィに対するURLをスコアします。 DTCGトークンバリデータ、スタイルリンプラグイン、および...

- [RatedWithAI](https://ratedwithai.com/) - ADAとWCAG 2.2のコンプライアンスをチェックするAIを搭載したWebサイトアクセシビリティスキャナー。実用的な修正推奨事項で無料のインスタント監査。
- [Tactual](https://github.com/tactual-dev/tactual) - スクリーンリーダーのナビゲーションコストアナライザ。 5つの補助技術プロファイルの下でインタラクティブなWebコンテンツを探し、到達し、操作するための支援技術の(AT)ユーザーのための本当の努力をモデル化します。 CLI、MCP...
- [Transcription Vidéo (RGAA Checker)](https://rgaa-checker.com/outils/transcription-video) - アップロードされたオーディオ/ビデオのための無料のAIサブタイトルジェネレータ:フランスのRGAAとArcom字幕ガイドラインに従うVTT、SRTおよびTXTキャプションを生成します。 FR.
- [RGAA Checker](https://rgaa-checker.com/) - ウェブアクセシビリティスキャナーは、フランス語 RGAA 4.1 標準およびWCAG と整列しました。静的解析、動的テスト(アッセンコア)、AI イメージ分析を組み合わせて、適合宣言、フラグを作成します。
- [AltTextLab](https://www.alttextlab.com/) - 映像のAIを搭載したaltテキストジェネレータ。
