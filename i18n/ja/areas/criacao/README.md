## ⭐ 各分野のさわり

> この部門の各分野から最初の厳選リンクを紹介します。各ページの雰囲気をつかめます。

### 🖌️ UI/UXデザイン

- [Figma](https://www.figma.com/) - インターフェイスの設計、試作および手渡のための市場の標準的な共同用具は自由計画と設計します。
- [Penpot](https://penpot.app/) - Figma への代替オープンソース, ブラウザで実行し、セルフホストすることができます.
- [Laws of UX](https://lawsofux.com/) - インターフェイス設計に適用される心理学の主要な法律とヒューリスティックスのコレクション。
- [Nielsen Norman Group - Artigos](https://www.nngroup.com/articles/) - ユーザビリティ調査、UX研究およびインタラクション設計に基づく記事や動画。
- [Material Design 3](https://m3.material.io/) - インターフェイスのためのガイドライン、コンポーネントおよびトークンが付いているGoogleの設計システム。 <sub>📖 ドキュメント</sub>

→ [UI/UXデザインの全193件のリンクを見る](./design-ui-ux.md)

### 🖍️ グラフィックデザインとイラスト

- [GIMP](https://www.gimp.org/) - 再接触、構成およびグラフィックの作成のための自由で、自由なイメージの編集者。
- [Inkscape](https://inkscape.org/) - オープンソースのベクトルグラフィックエディタ、Illustratorに代わる。
- [Krita](https://krita.org/) - オープンソースのデジタル絵画とイラストプログラム。
- [Photopea](https://www.photopea.com/) - PSD、AI、Figmaなどのフォーマットに対応したブラウザのイメージエディタです。
- [Affinity](https://www.affinity.studio/) - 個々の使用のための専門のスイートの設計、写真および図表は、放します。

### 🎞️ 動画編集

- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - 編集、カラーグレーディング、VFX、オーディオを1つのツールで無料版で行うプロフェッショナルエディタ。
- [Treinamento oficial DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve/training) - PDFブックと無料の黒色ビデオクラス、ポルトガル語のいくつかのモジュール。 <sub>🎓 コース</sub>
- [Kdenlive](https://kdenlive.org/) - マルチカム、カラーグレーディングと自動字幕付きKDEオープンソースビデオエディタ。
- [Shotcut](https://www.shotcut.org/) - 様々な形式のネイティブ編集で、無料かつマルチプラットフォームのビデオエディタ。
- [OpenShot](https://www.openshot.org/) - 初心者のための簡単なオープンソースのビデオエディタ, キーフレームと効果.

### 🪄 映像・音響素材

- [Lutify.me Free LUTs](https://lutify.me/free-luts/) - Premiere、DaVinci Resolves、Final CutとPhotoshop互換性のあるシネマトグラフィックLUTの無料パッケージ。
- [Juan Melara - Print Film Emulation LUTs](https://juanmelara.com.au/blog/print-film-emulation-luts-for-download) - 無料のコピーフィルムエミュレーションLUT(コダック2383と富士フイルム3510)、それらを使用する方法の説明。 <sub>📄 学術論文</sub>
- [Fresh LUTs](https://freshluts.com/) - コミュニティリポジトリは、他のカラーリストによって作成されたLUTを検索し、ダウンロードして送信する。
- [ARRI LUT Generator](https://www.arri.com/en/learn-help/learn-help-camera-system/tools/lut-generator) - LogC3 から変換 LUT を生成し、設定およびポストプロダクションへ出力する公式 ARRI ツール。
- [Panasonic LUT Library (V-Log)](https://av.jpn.support.panasonic.com/support/global/cs/dsc/download/lut/index.html) - パナソニックの公式ウェブサイトでV-Log用LUTをLumixカメラに記録しました。

→ [映像・音響素材の全306件のリンクを見る](./recursos-audiovisuais.md)

### 🎧 音声、音楽、ポッドキャスト

- [Audacity](https://www.audacityteam.org/) - 録音、切断、クリーニングノイズおよびオーディオのエクスポートのための無料のオーディオエディタ。
- [REAPER](https://www.reaper.fm/) - 安いライセンスと延長無料評価でDAWを点灯し、完了します。
- [Ardour](https://ardour.org/) - DAWは複数のトラックの録音、編集および混合のためのオープンソースを開けます。
- [LMMS](https://lmms.io/) - シーケンサー、シンセサイザーおよびピアノ ロールが付いている自由な音楽生産の場所。
- [BandLab](https://www.bandlab.com/) - ブラウザやモバイル、Cakewalkの所有者に音楽を制作する無料のプラットフォーム。

→ [音声、音楽、ポッドキャストの全215件のリンクを見る](./audio-musica.md)
