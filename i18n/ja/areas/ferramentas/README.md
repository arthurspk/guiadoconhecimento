## ⭐ 各分野のさわり

> この部門の各分野から最初の厳選リンクを紹介します。各ページの雰囲気をつかめます。

### 🌍 オンラインツール

- [iLovePDF](https://www.ilovepdf.com/pt) - PDFを結合、分割、圧縮および変換するためのオンラインツール。 <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - 人工的な限界なしでブラウザのPDFツールの無料コレクション。 <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - 200以上のフォーマットをサポートするオンラインファイルコンバータ。
- [TinyPNG](https://tinypng.com/) - ビジュアル品質を維持しながらPNG、JPEG、WebP画像を圧縮します。
- [Squoosh](https://squoosh.app/) - ブラウザでローカルに走るGoogleイメージコンプレッサー。

→ [オンラインツールの全297件のリンクを見る](./ferramentas-online.md)

### 🪄 AIツール

- [ChatGPT](https://chatgpt.com/) - テキスト、コード、画像および検索用のOpenAI AIウィザード。
- [Claude](https://claude.ai/) - 執筆、分析およびプログラミングのためのanthropic AIアシスタント。
- [Gemini](https://gemini.google.com/) - GoogleのAIアシスタントがGoogleアカウントのサービスに統合しました。
- [Microsoft Copilot](https://copilot.microsoft.com/) - チャットとイメージ作成のための無料のMicrosoft AI Wizard。
- [Perplexity](https://www.perplexity.ai/) - ソースを引用することで応答するAIで探す。

→ [AIツールの全268件のリンクを見る](./ferramentas-ia.md)

### 🏠 セルフホスト

- [awesome-selfhosted.net](https://awesome-selfhosted.net/) - ソフトウェアの主要なリストの Navigable バージョンは、自分自身をホストします。
- [selfh.st](https://selfh.st/) - 毎週のニュースレターとセルフホストアプリディレクトリ。
- [Docker Docs](https://docs.docker.com/) - ドッカーの公式ドキュメント、最も自発的な施設の基礎。 <sub>📖 ドキュメント</sub>
- [LinuxServer.io](https://www.linuxserver.io/) - 多数のアプリのDockerイメージを標準化し、文書化しました。
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) - 仮想化プラットフォームをホームサーバーやビジネスサーバ向けにオープン。

→ [セルフホストの全299件のリンクを見る](./self-hosted.md)

### 🖥️ macOS・Windows・Linux向けアプリ

- [AlternativeTo](https://alternativeto.net/) - システムとライセンスでフィルタリングするプログラムの代替品を見つけます。
- [Homebrew](https://brew.sh/) - macOSとLinux用のパッケージマネージャ。
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - コマンドラインで公式のWindowsパッケージマネージャ。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - コマンドラインでWindowsプログラムインストーラー、UACなし。
- [Ninite](https://ninite.com/) - ツールバーなしで複数のWindowsプログラムを一度にインストールして更新します。

→ [macOS・Windows・Linux向けアプリの全298件のリンクを見る](./apps-sistemas.md)

### 📲 Android・iOS向けアプリ

- [F-Droid](https://f-droid.org/) - 無料のオープンソースのAndroidアプリストア。
- [Obtainium](https://obtainium.imranr.dev/) - リリースページ(GitHub、GitLab)からAndroidアプリを直接インストールして更新します。
- [Aurora OSS](https://auroraoss.com/) - オーロラストアプロジェクト、Play Storeの代替オープンソースクライアント。
- [Signal](https://signal.org/) - エンドツーエンドの暗号化、広告無しおよび追跡が付いているメッセンジャー。
- [Organic Maps](https://organicmaps.app/) - OpenStreetMapに基づくナビゲーション、トレイル、追跡なしのオフラインマップ。

→ [Android・iOS向けアプリの全208件のリンクを見る](./apps-celular.md)

### 🧩 ブラウザ拡張機能

- [uBlock Origin](https://ublockorigin.com/) - 軽量、オープンソース広告ブロッカーとトラッカー。
- [Privacy Badger](https://github.com/EFForg/privacybadger) - 見えないトラッカーを学習し、ブロックするEFFの延長。
- [Dark Reader](https://darkreader.org/) - 明るさおよび対照の調節とあらゆる場所に暗いモードを適用して下さい。
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - YouTube動画でスポンサードスニペットを自動的にジャンプします。
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - YouTubeでディスクの推定数を再生します。

→ [ブラウザ拡張機能の全207件のリンクを見る](./extensoes-navegador.md)

### 🔗 公開API

- [Public APIs](https://github.com/public-apis/public-apis) - カテゴリで編成された無料のAPIの最もよく知られたリスト。
- [BrasilAPI](https://brasilapi.com.br/) - CEP、CNPJ、銀行、祝日、FIPEなどのブラジルデータを含む無料API。 <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - JSON または XML で CEP クエリの無料 Web サービス。 <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - 交換シリーズ、Sellic、Pix、APIアクセスでクレジット。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 連邦政府からのオープンデータセットのカタログ。 <sub>🇧🇷 pt-BR</sub>

→ [公開APIの全298件のリンクを見る](./apis-publicas.md)

### ⚡ 自動化とノーコード

- [n8n](https://n8n.io/) - セルフホストできるビジュアルエディタとコードで自動化をストリーミングします。
- [Zapier](https://zapier.com/) - 数千のアプリを接続するコード自動化はありません。
- [Make](https://www.make.com/) - 何千もの統合と無料プランでフローの視覚的自動化。
- [IFTTT](https://ifttt.com/) - アプリとスマートホーム間の簡単なトリガーおよびアクションの自動化。
- [Node-RED](https://nodered.org/) - API、デバイス、サービスを統合するためのビジュアルフロープログラミング。
