> 公開APIの厳選リンクです。キュレーターが選び抜いたもので、時間があまりないときはまずこれらをどうぞ。

- [Public APIs](https://github.com/public-apis/public-apis) - カテゴリで編成された無料のAPIの最もよく知られたリスト。
- [BrasilAPI](https://brasilapi.com.br/) - CEP、CNPJ、銀行、祝日、FIPEなどのブラジルデータを含む無料API。 <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - JSON または XML で CEP クエリの無料 Web サービス。 <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - 交換シリーズ、Sellic、Pix、APIアクセスでクレジット。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 連邦政府からのオープンデータセットのカタログ。 <sub>🇧🇷 pt-BR</sub>
- [API do Portal da Transparência](https://api.portaldatransparencia.gov.br/) - データ、契約および連邦政府のサーバーを費やすAPI。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [Dados Abertos da Câmara](https://dadosabertos.camara.leg.br/) - MP、投票、提案およびハウス費用のAPI。 <sub>📖 ドキュメント · 🇧🇷 pt-BR</sub>
- [AwesomeAPI](https://docs.awesomeapi.com.br/) - ブラジルのコイン見積APIとCEPを無料で配布しています。 <sub>🇧🇷 pt-BR</sub>
- [JSONPlaceholder](https://github.com/typicode/jsonplaceholder) - テストおよびプロトタイプのための自由な擬似REST API。
- [PokéAPI](https://pokeapi.co/) - REST APIとGraphQL APIをPokémonデータで無料で使用でき、勉強にとても便利です。
- [REST Countries](https://restcountries.com/) - 国のデータ:人口、通貨、言語、フラグ。
- [Open-Meteo](https://open-meteo.com/) - プレビューと履歴を備えた、無料でキーレスな気候API。
- [OpenWeather](https://openweathermap.org/api) - 現在の天気と予報のための無料プラン付きの気象API。
- [NASA Open APIs](https://api.nasa.gov/) - 星の天文台写真や画像などの無料NASA API。
