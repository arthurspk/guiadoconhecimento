## 🔎 リストの作り方

> 選定は自動で行われ、再現可能です。手作業で書いたものはありません。

- 各職種の検索クエリは `data/repos-ia-consultas.json` にテーマ別にまとめています。
- スクリプト `scripts/coletar_repos_ia.py` がGitHubの公開検索を呼び出し、スター数順に並べます。
- 対象はアクティブで説明があり、名前・説明・トピックのいずれかにAIであることが明確に示され、ブロックリスト(成人向け、海賊版、不正行為)に含まれないリポジトリだけです。
- スター数は収集した日のものです。1つのリポジトリが複数の職種に登場することもあります。
