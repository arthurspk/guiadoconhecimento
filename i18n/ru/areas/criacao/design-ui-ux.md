## ⭐ Начните здесь

> Главное по теме «UI/UX-дизайн», отобранное вручную куратором: если времени мало, начните с этих ссылок.

- [Figma](https://www.figma.com/) - Стандартный на рынке инструмент для совместной работы по дизайну интерфейса, прототипированию и передаче с бесплатным планом.
- [Penpot](https://penpot.app/) - Альтернативный с открытым исходным кодом Figma, работает в браузере и может быть размещен самостоятельно.
- [Laws of UX](https://lawsofux.com/) - Сборник основных законов и эвристики психологии, применяемых к дизайну интерфейсов.
- [Nielsen Norman Group - Artigos](https://www.nngroup.com/articles/) - Статьи и видео, основанные на исследованиях удобства использования, UX-исследованиях и дизайне взаимодействия.
- [Material Design 3](https://m3.material.io/) - Система дизайна Google с рекомендациями, компонентами и токенами для интерфейсов. <sub>📖 документация</sub>
- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) - Официальные рекомендации Apple по разработке интерфейсов на iOS, macOS и других платформах. <sub>📖 документация</sub>
- [WCAG - W3C WAI](https://www.w3.org/WAI/standards-guidelines/wcag/) - Официальный обзор Руководства по доступности веб-контента (WCAG 2.2). <sub>📖 документация</sub>
- [Google UX Design Professional Certificate](https://www.coursera.org/professional-certificates/google-ux-design) - Сертификация Google в Coursera охватывает весь процесс UX, от исследования до прототипа. <sub>🎓 курс</sub>
- [Interaction Design Foundation](https://www.interaction-design.org/) - Курсы UX и энциклопедия, дизайн взаимодействия с открытыми статьями и подписными курсами. <sub>🎓 курс</sub>
- [Mobbin](https://mobbin.com/) - Библиотека реальных экранов и потоков приложений и веб-сайтов для ссылки на пользовательский интерфейс с бесплатным планом.
- [The Component Gallery](https://component.gallery/) - Каталог компонентов интерфейса с примерами из десятков общедоступных систем проектирования.
- [Growth.Design - Case Studies](https://growth.design/case-studies) - Тематические исследования комиксов по UX-решениям и психологии продуктов в известных компаниях.
- [UX Collective Brasil](https://brasil.uxdesign.cc/) - Публикация на португальском языке со статьями и переводами об UX, UI и дизайне карьеры. <sub>🇧🇷 pt-BR</sub>
- [Origamid](https://www.origamid.com/) - Бразильская школа с курсами дизайна пользовательского интерфейса, типографики и фронт-энда. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Refactoring UI](https://www.refactoringui.com/) - Практическая книга с техниками пользовательского интерфейса для тех, кому нужно сделать интерфейсы более четкими и красивыми. <sub>📚 книга</sub>
- [Dribbble](https://dribbble.com/) - Сообщество дизайнеров для визуального вдохновения и портфолио UI. <sub>👥 сообщество</sub>

## 🤖 ИИ: UI/UX-дизайн

> Инструменты, skills, MCP, курсы, руководства по промптам и ответственному использованию ИИ для тех, кто работает в направлении «UI/UX-дизайн». См. также [🤖 ИИ для всех направлений](../../ia/README.md).

### 💎 Главное по ИИ

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Документация официального MCP-сервера Figma, которая дает агентам ИИ контекст проектирования файлов для генерации кода и редактирования холста; широкое использование требует Dev или Full seat в… <sub>📖 документация</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Официальный репозиторий Figma с руководством по установке и навыками для агентов (проектирование реализации, создание библиотеки, правила системы проектирования) с использованием Figma MCP.
- [Figma Make](https://www.figma.com/make/) - Ресурс Figma AI, который преобразует подсказки и кадры в функциональные прототипы с кодом; включен в планы Figma, с долей кредитов ИИ.
- [Google Stitch](https://stitch.withgoogle.com/) - Эксперимент Google Labs, который генерирует приложения и веб-интерфейсы из текста или изображения с экспортом в Figma и код.
- [Framer AI](https://www.framer.com/ai/) - Создатель веб-сайтов с агентом ИИ на холсте, который создает и редактирует отзывчивые страницы из инструкций; бесплатная для начала платная профессиональная публикация.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - Сервер с открытым исходным кодом MCP, который отправляет макет Figma и стили файлов в Cursor, Claude Code и другие агенты более точно реализуют экраны.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Penpot-интегрированный MCP сервер, инструмент дизайна с открытым исходным кодом, который позволяет агентам ИИ читать и создавать элементы в файлах проектирования.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Официальный навык Клода, который направляет создание интерфейсов с определенным визуальным направлением, избегая типичного общего вида страниц, генерируемых ИИ.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Команды навыков и дизайна для агентов кода с автоматическими правилами, которые обнаруживают общие визуальные искажения в интерфейсах, генерируемых ИИ.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Навыки, основанные на доступных для поиска стилях, палитрах, типографских парах и рекомендациях UX для агентов для создания интерфейсов в нескольких фреймворках.
- [The Shape of AI](https://www.shapeof.ai/) - Бесплатная библиотека UX-стандартов для продуктов ИИ (вход, корректировки, элементы управления, признаки доверия), полезная при проектировании интерфейсов ресурсов ИА.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Бесплатное руководство Google по разработке ориентированных на людей продуктов ИИ с шаблонами ожиданий, объяснений, обратной связи и ошибок. <sub>📖 документация</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Сборник статей NN/g и исследований по ИИ в UX: исследования с AI, дизайн чат-ботов и раскрытие использования ИИ; бесплатные статьи, платные курсы.

### 🧪 Другие инструменты и ресурсы по ИИ

- [Accessibility DevKit LLM](https://github.com/lukeslp/accessibility-devkit-llm) - Alt text generation, WCAG auditing CLI и MCP server using language models for accessibility workflows. Работает с OpenAI, Anthropic, HuggingFace и Ollama.
- [AI Web Design Codex](https://github.com/Eneryleen/ai-web-design-codex) - База знаний 60 перекрестно связанных руководств по веб-дизайну, UX, доступности и конверсии для людей и агентов ИИ.

- [Designesy](https://www.designesy.org/) - 40-проверка механизма проверки контрактов системы проектирования. Оценка любого URL против соответствия токена DTCG 2025.10, WCAG 2.2 AA, движения и типографики. Включает в себя валидатор токенов…
- [Alt Text Local AI](https://github.com/lukeslp/alt-text-local-ai) - Настольное приложение, которое генерирует альтернативный текст для изображений с использованием локальных моделей видения Ollama — не требуется ключ API, ничто не покидает вашу машину.
- [RatedWithAI](https://ratedwithai.com/) - Сканер доступа к веб-сайту на базе искусственного интеллекта, который проверяет соответствие требованиям ADA и WCAG 2.2 с помощью топорного ядра. Бесплатный мгновенный аудит с действенными…
- [Tactual](https://github.com/tactual-dev/tactual) - Анализатор стоимости навигации для чтения экрана. Моделирует реальные усилия пользователей вспомогательных технологий (AT) по поиску, охвату и управлению интерактивным веб-контентом в рамках 5…
- [Transcription Vidéo (RGAA Checker)](https://rgaa-checker.com/outils/transcription-video) - Бесплатный генератор подзаголовков AI для загруженного аудио / видео: производит подписи VTT, SRT и TXT в соответствии с французскими рекомендациями по субтитрам RGAA и Arcom.
- [RGAA Checker](https://rgaa-checker.com/) - Сканер веб-доступности, согласованный с французским стандартом RGAA 4.1 и WCAG. Комбинирует статический анализ, динамическое тестирование (осевой ядро) и анализ изображений ИИ, генерирует декларацию…
- [AltTextLab](https://www.alttextlab.com/) - Генератор альтернативного текста на основе ИИ для изображений.
