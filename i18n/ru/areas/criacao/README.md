## ⭐ Немного из каждого направления

> Первые главные ссылки каждого направления этой сферы, чтобы вы почувствовали, что есть на каждой странице.

### 🖌️ UI/UX-дизайн

- [Figma](https://www.figma.com/) - Стандартный на рынке инструмент для совместной работы по дизайну интерфейса, прототипированию и передаче с бесплатным планом.
- [Penpot](https://penpot.app/) - Альтернативный с открытым исходным кодом Figma, работает в браузере и может быть размещен самостоятельно.
- [Laws of UX](https://lawsofux.com/) - Сборник основных законов и эвристики психологии, применяемых к дизайну интерфейсов.
- [Nielsen Norman Group - Artigos](https://www.nngroup.com/articles/) - Статьи и видео, основанные на исследованиях удобства использования, UX-исследованиях и дизайне взаимодействия.
- [Material Design 3](https://m3.material.io/) - Система дизайна Google с рекомендациями, компонентами и токенами для интерфейсов. <sub>📖 документация</sub>

→ [Все ссылки направления «UI/UX-дизайн»: 193](./design-ui-ux.md)

### 🖍️ Графический дизайн и иллюстрация

- [GIMP](https://www.gimp.org/) - Бесплатный и бесплатный редактор изображений для ретуширования, композиции и графического создания.
- [Inkscape](https://inkscape.org/) - Векторный графический редактор с открытым исходным кодом, альтернатива Illustrator.
- [Krita](https://krita.org/) - Программа цифровой живописи и иллюстрации с открытым исходным кодом.
- [Photopea](https://www.photopea.com/) - Редактор изображений в браузере совместим с PSD, AI, Figma и другими форматами.
- [Affinity](https://www.affinity.studio/) - Профессиональный дизайн люкса, фото и диаграммы, бесплатно для индивидуального использования.

→ [Все ссылки направления «Графический дизайн и иллюстрация»: 213](./design-grafico.md)

### 🎞️ Видеомонтаж

- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - Профессиональный редактор с редактированием, цветовой оценкой, VFX и аудио в одном инструменте с бесплатной версией.
- [Treinamento oficial DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve/training) - PDF книги и бесплатные видео-классы Blackmagic, с несколькими модулями на португальском языке. <sub>🎓 курс</sub>
- [Kdenlive](https://kdenlive.org/) - Видеоредактор с открытым исходным кодом KDE с мультикамерой, цветовой градуировкой и автоматическими субтитрами.
- [Shotcut](https://www.shotcut.org/) - Бесплатный и мультиплатформенный видеоредактор с нативным редактированием различных форматов.
- [OpenShot](https://www.openshot.org/) - Простой видеоредактор с открытым исходным кодом для новичков, с ключевыми кадрами и эффектами.

→ [Все ссылки направления «Видеомонтаж»: 209](./edicao-de-video.md)

### 🎥 Filmmaking и кино

- [StudioBinder - Blog](https://www.studiobinder.com/blog/) - Подробные руководства по сценарию, языку камеры, направлению и производству.
- [No Film School](https://nofilmschool.com/) - Новости, учебные пособия и подкасты о самостоятельном создании фильмов.

- [Fountain](https://fountain.io/) - Простой язык маркировки текста для написания сценариев в стандартном формате. <sub>📖 документация</sub>

### 🪄 Ресурсы для аудио и видео

- [Lutify.me Free LUTs](https://lutify.me/free-luts/) - Бесплатный пакет Premiere, DaVinci Resolves, Final Cut и совместимых с Photoshop кинематографических LUT.
- [Juan Melara - Print Film Emulation LUTs](https://juanmelara.com.au/blog/print-film-emulation-luts-for-download) - Бесплатная копия эмуляции ЛУТ (Kodak 2383 и Fujifilm 3510) с объяснением того, как их использовать. <sub>📄 научная статья</sub>
- [Fresh LUTs](https://freshluts.com/) - Репозиторий сообщества для поиска, загрузки и отправки LUT, созданных другими колористами.
- [ARRI LUT Generator](https://www.arri.com/en/learn-help/learn-help-camera-system/tools/lut-generator) - Официальный инструмент ARRI для генерации преобразований LUT из LogC3 в набор и пост-продакшн.
- [Panasonic LUT Library (V-Log)](https://av.jpn.support.panasonic.com/support/global/cs/dsc/download/lut/index.html) - Официальный сайт Panasonic с LUT для V-Log записал материал на камеры Lumix.

→ [Все ссылки направления «Ресурсы для аудио и видео»: 306](./recursos-audiovisuais.md)

### 📷 Фотография

- [darktable](https://www.darktable.org/) - Разработчик RAW и менеджер фотографий с открытым исходным кодом, альтернатива Lightroom.
- [RawTherapee](https://www.rawtherapee.com/) - Файловый процессор с открытым исходным кодом RAW с 32-битным двигателем и расширенными элементами управления.
- [digiKam](https://www.digikam.org/) - Менеджер сбора фотографий с открытым исходным кодом с распознаванием лиц и расширенным поиском.
- [Unsplash](https://unsplash.com/) - Высококачественный фотобанк со свободной лицензией.
- [Pexels](https://www.pexels.com/) - Бесплатный банк фотографий и видео, с интерфейсом на португальском языке.

→ [Все ссылки направления «Фотография»: 187](./fotografia.md)

### 🧊 Моушн-дизайн, 3D и анимация

- [Blender](https://www.blender.org/) - Бесплатный 3D-комплект для моделирования, анимации, симуляции, рендеринга, композиции и редактирования.
- [Manual do Blender](https://docs.blender.org/manual/en/latest/) - Официальная документация Blender с переводами на несколько языков. <sub>📖 документация</sub>
- [Blender Studio](https://studio.blender.org/) - Курсы, открытые фильмы и производственные файлы от Blender Foundation с частью по подписке. <sub>🎓 курс</sub>
- [Curso de Blender 5.1 para iniciantes (Allan Brito)](https://www.youtube.com/watch?v=4KAxWqMiKpQ) - Бесплатный курс около 4 часов на португальском из Бразилии, выпущенный BlenderNation. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Poly Haven](https://polyhaven.com/) - Бесплатные текстуры, HDRI и 3D модели в открытом доступе.

→ [Все ссылки направления «Моушн-дизайн, 3D и анимация»: 212](./motion-3d.md)

### 🎧 Аудио, музыка и подкасты

- [Audacity](https://www.audacityteam.org/) - Бесплатный аудиоредактор для записи, резки, очистки шума и экспорта звука.
- [REAPER](https://www.reaper.fm/) - Легкий и полный DAW с дешевой лицензией и расширенной бесплатной оценкой.
- [Ardour](https://ardour.org/) - DAW open source для многодорожечной записи, редактирования и микширования.
- [LMMS](https://lmms.io/) - Бесплатная музыкальная станция с секвенсором, синтезаторами и фортепианным рулоном.
- [BandLab](https://www.bandlab.com/) - Бесплатная платформа для создания музыки на браузере и мобильном телефоне, владелец Cakewalk.

→ [Все ссылки направления «Аудио, музыка и подкасты»: 215](./audio-musica.md)

- [Write the Docs](https://www.writethedocs.org/) - Глобальное сообщество документации с руководством, конференциями и Slack. <sub>👥 сообщество</sub>
