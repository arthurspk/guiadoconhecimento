## ⭐ Немного из каждого направления

> Первые главные ссылки каждого направления этой сферы, чтобы вы почувствовали, что есть на каждой странице.

### 🛡️ Кибербезопасность

- [Cartilha de Segurança para Internet (CERT.br)](https://cartilha.cert.br/) - Бесплатный бразильский материал с брошюрами о мошенничестве, паролях, вредоносных программах и защите данных. <sub>🇧🇷 pt-BR</sub>
- [CERT.br](https://www.cert.br/) - Национальные меры реагирования на инциденты в Бразилии со статистикой, передовой практикой и материалами. <sub>🇧🇷 pt-BR</sub>
- [OWASP Top 10](https://top10.owasp.org/) - Список наиболее важных рисков безопасности в веб-приложениях. <sub>📖 документация</sub>
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) - Бесплатное обучение по веб-безопасности с теоретическими и практическими лабораториями. <sub>🎓 курс</sub>
- [Hacker101](https://www.hacker101.com/) - Бесплатные классы веб-безопасности HackerOne и CTF, нацеленные на вознаграждение за ошибки. <sub>🎓 курс</sub>

→ [Все ссылки направления «Кибербезопасность»: 305](./ciberseguranca.md)

### 🔎 OSINT и расследования

- [OSINT Framework](https://github.com/lockfale/osint-framework) - Интерактивная карта инструментов OSINT, организованных по типу исследуемых данных.
- [Bellingcat](https://www.bellingcat.com/) - Организация следственной журналистики, которая является мировым справочником в расследованиях из открытых источников.
- [Bellingcat Online Investigation Toolkit](https://bellingcat.gitbook.io/toolkit) - Обзор каталога исследовательских инструментов, с использованием руководств.
- [Guias da Bellingcat](https://www.bellingcat.com/category/resources/how-tos/) - Практические учебники по геолокации, спутниковые снимки и верификации.
- [Abraji](https://abraji.org.br/) - Бразильская ассоциация журналистских расследований с курсами и руководствами по оценке. <sub>👥 сообщество · 🇧🇷 pt-BR</sub>

→ [Все ссылки направления «OSINT и расследования»: 205](./osint.md)

### 🕶️ Приватность и защита данных

- [LGPD - Lei 13.709/2018](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm) - Официальный и обновленный текст Закона о защите персональных данных. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [ANPD](https://www.gov.br/anpd/pt-br) - Национальный орган по защите данных с руководствами, правилами и каналом отчетности. <sub>🇧🇷 pt-BR</sub>
- [Curso de Introdução à LGPD (Escola Virtual.Gov)](https://www.escolavirtual.gov.br/curso/153) - Открытый и бесплатный курс федерального правительства по ЛГПД, с сертификатом. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Cartilha CERT.br - Fascículos](https://cartilha.cert.br/fasciculos/) - Бесплатные брошюры о конфиденциальности, защите данных, социальных сетях и утечках. <sub>🇧🇷 pt-BR</sub>
- [Surveillance Self-Defense (EFF)](https://ssd.eff.org/pt-br) - Руководство EFF на португальском языке для защиты от цифрового наблюдения. <sub>🇧🇷 pt-BR</sub>

→ [Все ссылки направления «Приватность и защита данных»: 212](./privacidade.md)
