### 📊 Анализ данных и BI

- [Documentação do Power BI](https://learn.microsoft.com/pt-br/power-bi/) - Официальная документация на португальском языке Power BI, от рабочего стола до облачного сервиса. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [Certificação PL-300 (Power BI Data Analyst)](https://learn.microsoft.com/pt-br/credentials/certifications/data-analyst-associate/) - Официальный веб-сайт сертификации аналитиков данных Power BI с бесплатным руководством по обучению и практической оценкой. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [DAX Guide](https://dax.guide/) - Полная ссылка на функции языка DAX и операторов, используемых в Power BI и Excel. <sub>📖 документация</sub>
- [Fundação Bradesco - Escola Virtual](https://www.ev.org.br/) - Бесплатные онлайн-курсы с сертификатом, включая Excel от базовых до продвинутых. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Hashtag Treinamentos](https://www.youtube.com/@HashtagTreinamentos) - Бразильский канал с классами Excel, Power BI, SQL и Python для рынка труда. <sub>📺 канал · 🇧🇷 pt-BR</sub>

### 🔀 Инженерия данных

- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) - Свободный и открытый курс строительства полного трубопровода с Docker, Terraform, dbt, Spark и Kafka. <sub>🎓 курс</sub>
- [roadmap.sh - Data Engineer](https://roadmap.sh/data-engineer) - Интерактивный сценарий, вместо того чтобы учиться на инженера данных.
- [Microsoft Learn - Engenheiro de Dados](https://learn.microsoft.com/pt-br/training/career-paths/data-engineer) - Официальная и бесплатная португальская трасса с модулями обработки данных в Azure. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Designing Data-Intensive Applications](https://dataintensive.net/) - Книга Мартина Клеппмана об основах распределенных систем данных, хранения и потоковой передачи. <sub>📚 книга</sub>
- [Big Book of Data Engineering](https://www.databricks.com/resources/ebook/big-book-of-data-engineering) - Databricks бесплатная электронная книга с шаблонами и практическими случаями трубопроводов и озерного домика. <sub>📚 книга</sub>

→ [Все ссылки направления «Инженерия данных»: 210](./engenharia-de-dados.md)

### 🧠 Наука о данных и machine learning

- [Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) - Классический вводный курс ML от Stanford и DeepLearning.AI с возможностью бесплатной регистрации. <sub>🎓 курс</sub>
- [Machine Learning Crash Course (Google)](https://developers.google.com/machine-learning/crash-course) - Бесплатный и практичный курс Google с видео, интерактивными видами и упражнениями. <sub>🎓 курс</sub>
- [Practical Deep Learning for Coders (fast.ai)](https://course.fast.ai/) - Бесплатный курс глубокого обучения применяется к тем, кто уже программирует с помощью PyTorch и фастай. <sub>🎓 курс</sub>
- [An Introduction to Statistical Learning](https://www.statlearning.com/) - Справочник по статистическому обучению, с бесплатными PDF и изданиями на R и Python. <sub>📚 книга</sub>
- [Dive into Deep Learning](https://d2l.ai/) - Интерактивная и бесплатная книга глубокого обучения с исполняемым кодом в PyTorch, TensorFlow и JAX. <sub>📚 книга</sub>

→ [Все ссылки направления «Наука о данных и machine learning»: 298](./ciencia-de-dados-ml.md)

### ✨ Генеративный ИИ и LLM

- [Prompt Engineering Guide](https://www.promptingguide.ai/pt) - Открытое руководство по быстрым, RAG и инженерным техникам агентов с португальской версией. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [Generative AI for Beginners (Microsoft)](https://github.com/microsoft/generative-ai-for-beginners) - Бесплатный курс по 21 уроку приложений с генеративным ИИ, с переводом на португальский язык. <sub>🎓 курс</sub>
- [Hugging Face Learn](https://huggingface.co/learn) - Бесплатные курсы LLM, агентов, диффузии и контекстной инженерии. <sub>🎓 курс</sub>
- [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/) - Короткие и бесплатные курсы по подсказкам, RAG, агентам и тонкой настройке, проводимые с компаниями сектора. <sub>🎓 курс</sub>
- [Guia de prompt engineering da Anthropic](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview) - Официальная документация с оперативными методами и передовым опытом для моделей Клода. <sub>📖 документация</sub>
