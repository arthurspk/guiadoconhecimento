### 💎 Главное по ИИ

- [SQL Console do Hugging Face](https://huggingface.co/docs/hub/datasets-viewer-sql-console) - Консоль браузера (DuckDB) для просмотра наборов данных Hub в SQL или на естественном языке и результатов экспорта. <sub>📖 документация</sub>
- [Corpus Carolina](https://huggingface.co/datasets/carolina-c4ai/corpus-carolina) - Корпус открылся из современного бразильского португальского языка USP/C4AI, с более чем 2 миллионами документов и зарегистрированным происхождением; CC BY 4.0. <sub>🇧🇷 pt-BR</sub>
- [Chatbot da Base dos Dados](https://basedosdados.org/chatbot-lp) - Чат-бот с Близнецами, который превращает вопросы в запросы о более чем 740 публичных таблицах Бразилии; бесплатный тест на 7 дней, затем подпись. <sub>🇧🇷 pt-BR</sub>
- [Croissant (MLCommons)](https://mlcommons.org/working-groups/data/croissant/) - Открытый шаблон метаданных для наборов данных ML, используемых Hugging Face, Kaggle и Google Dataset Search. <sub>📖 документация</sub>
- [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) - Справочная статья, в которой предлагается документировать мотивацию, состав, сбор и рекомендуемое использование всех наборов данных ML. <sub>📖 документация</sub>
- [Data Provenance Initiative](https://www.dataprovenance.org) - Исследовательская инициатива, которая проверяет происхождение, лицензии и ограничения данных, используемых для обучения моделей ИИ.
- [Common Crawl](https://commoncrawl.org) - Открытый и бесплатный архив веб-отслеживания с сотнями миллиардов страниц, основа многих корпусов LLM.
- [SDV (Synthetic Data Vault)](https://github.com/sdv-dev/SDV) - Библиотека Python для генерации синтетических табличных данных из реальных данных, полезная для тестирования и безопасного обмена.
- [distilabel](https://github.com/argilla-io/distilabel) - Открытый исходный код для создания и оценки синтетических наборов данных с помощью LLM (инструкции, предпочтения, оценка).
- [Argilla](https://github.com/argilla-io/argilla) - Платформа с открытым исходным кодом для кураторства и аннотации данных с поддержкой LLM и обратной связью с людьми.
- [Label Studio](https://github.com/HumanSignal/label-studio) - Инструмент с открытым исходным кодом для маркировки текста, изображения, аудио и видео с предварительным обозначением моделями ML.
