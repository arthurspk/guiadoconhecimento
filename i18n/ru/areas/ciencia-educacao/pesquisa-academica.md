### 💎 Главное по ИИ

- [Elicit](https://elicit.com/) - Научный сотрудник с ИИ, который ищет статьи, извлекает данные в таблицах и генерирует отчеты со ссылками; бесплатный план.
- [Consensus](https://consensus.app/) - Механизм поиска ИИ по рецензируемой литературе, который суммирует то, что показывают исследования; freemium.
- [Ai2 Asta](https://asta.allen.ai/) - Научный сотрудник Института Аллена, который находит, обобщает и анализирует научные данные в миллионах статей.
- [SciSpace](https://scispace.com/) - AI Assistant для обзора литературы, чтения PDF и письма с цитатами; бесплатный и платный план.
- [scite](https://scite.ai/) - Он показывает, поддерживает ли каждая цитата или оспаривает находку (умные цитаты) и отвечает на вопросы на основе литературы; оплачивается тестом.
- [ResearchRabbit](https://www.researchrabbit.ai/) - Откройте для себя связанные статьи и просмотрите сети цитирования и соавторство для обзоров литературы; бесплатно с платным планом.
- [Gemini Notebook (antigo NotebookLM)](https://notebook.google/) - Инструмент Google, который анализирует ваши собственные источники (PDF, статьи) и генерирует тезисы, вопросы и аудио; бесплатно.
- [PaperQA](https://github.com/Future-House/paper-qa) - Агент с открытым исходным кодом, который отвечает на вопросы цитатами из научных PDF-файлов с высокой точностью RAG.
- [arXiv MCP Server](https://github.com/blazickjp/arxiv-mcp-server) - MCP-сервер для Клода и других агентов для поиска, чтения разделов и создания статей BibTeX из arXiv; с открытым исходным кодом.
- [Zotero MCP](https://github.com/54yyyu/zotero-mcp) - MCP-сервер, который соединяет вашу библиотеку Zotero с Claude и ChatGPT для поиска, обобщения и записи ссылок.
- [Scientific Agent Skills (K-Dense)](https://github.com/K-Dense-AI/claude-scientific-skills) - Навыки для агентов с обзором литературы, научным письмом, управлением цитатами, статистикой и плакатами; MIT.
- [SciELO - Guia de uso de ferramentas de IA](https://wp.scielo.org/wp-content/uploads/Guia-de-uso-de-ferramentas-e-recursos-de-IA-20230914.pdf) - Руководство Сети SciELO на португальском языке по прозрачности и авторству в использовании ИИ в научной коммуникации. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [COPE - Autoria e ferramentas de IA](https://publicationethics.org/cope-position-statements/ai-author) - Комитет по этике публикаций: ИИ не может быть автором, и его использование должно быть указано в методах. <sub>📖 документация</sub>
