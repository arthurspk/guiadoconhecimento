- [Polymathic AI](https://polymathic-ai.org/) - Инициатива, которая разрабатывает междисциплинарные фундаментальные модели для научных данных, фокусируясь на физике и астрофизике.
- [The Well (Polymathic AI)](https://github.com/PolymathicAI/the_well) - Коллекция больших наборов физических симуляций, готовых обучать и оценивать модели машинного обучения.
- [Pathfinder (UniverseTBD)](https://github.com/UniverseTBD/pathfinder) - Инструмент RAG с LLM для семантического поиска, вопросов и ответов по астрономическим статьям; открытый исходный код.
- [astroML](https://www.astroml.org/) - Python модуль машинного обучения и интеллектуального анализа данных для астрономии, с примерами, связанными с книгой Ивезич и др.; бесплатно. <sub>📖 документация</sub>
- [Machine Learning for Physics and Astronomy (Acquaviva)](https://press.princeton.edu/books/paperback/9780691206417/machine-learning-for-physics-and-astronomy) - Практический учебник машинного обучения по физике и астрономии, с примерами ноутбуков Jupyter; платная книга. <sub>📚 книга</sub>
- [Deep Skies Lab](https://deepskieslab.com/) - Сообщество, применяющее ИИ к астрофизическим проблемам с открытыми рабочими группами, семинарами и практикумами. <sub>👥 сообщество</sub>
- [IML - LHC Machine Learning Working Group (CERN)](https://iml.web.cern.ch/) - CERN Форум по машинному обучению в экспериментах БАК, с публичными собраниями и материалами. <sub>👥 сообщество</sub>
