## 🤖 ИИ: Биология и биоинформатика

> Инструменты, skills, MCP, курсы, руководства по промптам и ответственному использованию ИИ для тех, кто работает в направлении «Биология и биоинформатика». См. также [🤖 ИИ для всех направлений](../../ia/README.md).

### 💎 Главное по ИИ

- [AlphaFold Server](https://alphafoldserver.com/) - Веб-сервис Google DeepMind с AlphaFold 3 для прогнозирования белковых структур и их взаимодействия с ДНК, РНК и связующими; бесплатное некоммерческое использование.
- [ColabFold](https://github.com/sokrypton/ColabFold) - Ускоренная версия AlphaFold, работающая на ноутбуках Google Colab для прогнозирования структур без собственной инфраструктуры; бесплатная.
- [ESM (EvolutionaryScale)](https://github.com/evolutionaryscale/esm) - Протеиновые модели ESM3 и ESM C для генерации и анализа последовательностей, структур и функций; с открытым исходным кодом.
- [Evo 2 (Arc Institute)](https://github.com/ArcInstitute/evo2) - Фундаментальная модель ДНК, обученная геномам всех областей жизни для прогнозирования эффектов вариантов и генерации последовательностей.
- [AlphaGenome](https://github.com/google-deepmind/alphagenome) - Google DeepMind API и модель для прогнозирования регуляторных эффектов вариантов в последовательностях ДНК; некоммерческое использование.
- [Virtual Cells Platform (Biohub/CZI)](https://virtualcellmodels.cziscience.com/) - Экосистема с готовыми к ML данными, биологи определили ориентиры и модели виртуальных клеток, включая безкодовое пространство.
- [Biomni](https://github.com/snap-stanford/Biomni) - Стэнфордский биомедицинский агент, который объединяет LLM, инструменты и базы данных для выполнения исследовательских задач в биологии.
- [Life Sciences Marketplace para Claude](https://github.com/anthropics/life-sciences) - Официальные плагины Anthropic с MCP и серверами навыков для PubMed, BioRender, Synapse и других инструментов.
