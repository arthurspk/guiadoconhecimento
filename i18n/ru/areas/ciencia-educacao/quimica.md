- [NOMAD](https://nomad-lab.eu/nomad-lab/) - Репозиторий и архив FAIR для необработанных и нормализованных данных по вычислительным материалам-науке с API и поиском на основе метаданных. Опубликованные данные доступны в разделе CC BY 4.0.
- [awesome-cheminformatics](https://github.com/hsiaoyi0504/awesome-cheminformatics) - Другой список посвящен Cheminformatics, включая инструменты не только на Python. <sub>📋 awesome-список</sub>
