- [Aider](https://aider.chat/) - Мастер парного программирования в терминале с открытым исходным кодом, который редактирует хранилище Git с LLM по вашему выбору.

- [Sourcery](https://sourcery.ai/) - Пересмотр кода и рефакторинг ИИ для запросов на вытягивание и IDE, происходящих из экосистемы Python.
- [awesome-cursorrules](https://github.com/PatrickJS/awesome-cursorrules) - Сбор правил и инструкций, готовых направлять помощников по коду на каждом языке.
