### 💎 Главное по ИИ

- [Playwright Test Agents](https://playwright.dev/docs/test-agents) - Официальные агенты Playwright (планировщик, генератор и обогреватель), которые планируют, генерируют и корректируют сквозные тесты. <sub>📖 документация</sub>
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - Microsoft MCP-сервер позволяет агентам просматривать и тестировать страницы через дерево доступности.
- [Stagehand](https://github.com/browserbase/stagehand) - Рамки автоматизации браузера, которые смешивают код и инструкции на естественном языке; открытый исходный код.
- [Keploy](https://github.com/keploy/keploy) - Генерировать тестирование API и интеграцию с макетами фактического трафика, записанного через eBFF; открытый исходный код.
- [Qodo](https://www.qodo.ai/) - Платформа для анализа кода и генерация тестов ИИ для PR и IDE; бесплатная пробная версия, а затем платная.
- [Diffblue](https://www.diffblue.com/) - Генерирует тесты Java с помощью AI; платный.
- [Applitools](https://applitools.com) - Сквозная платформа тестирования с визуальным ИИ для обнаружения визуальных регрессий; платное.
- [Meticulous](https://www.meticulous.ai/) - Генерирует и поддерживает визуальные регрессионные тесты с фактических сеансов пользователя; платный.
- [Octomind](https://octomind.dev) - Агент, который обнаруживает, генерирует и поддерживает сквозные тесты в Playwright; платный.
- [Checksum](https://checksum.ai) - Генерирует и поддерживает сквозные тесты с ИИ от фактического использования приложения; платный.
- [promptfoo](https://www.promptfoo.dev) - Инструмент с открытым исходным кодом для тестирования, оценки и красных командных приложений с помощью LLM.
- [DeepEval](https://github.com/confident-ai/deepeval) - Pytest-стиль фреймворка с открытым исходным кодом для единичных тестов LLM, RAG и выходов агентов.
- [ISTQB CT-AI (Certified Tester AI Testing)](https://www.istqb.org/certifications/certified-tester-ai-testing-ct-ai) - Бесплатная сертификация ISTQB и учебный план по тестированию систем ИИ, включая ML и LLM. <sub>🎓 курс</sub>
