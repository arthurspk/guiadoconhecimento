- [Glassdoor Brasil](https://www.glassdoor.com.br/) - Вакансии, оценки компании и диапазоны заработной платы, о которых сообщают сотрудники. <sub>🇧🇷 pt-BR</sub>
- [Indeed Brasil](https://br.indeed.com/) - Поисковик, который собирает рекламу с различных веб-сайтов и компаний. <sub>🇧🇷 pt-BR</sub>
- [Catho](https://www.catho.com.br/) - Бразильский сайт вакансий с регистрацией учебных программ и руководствами по заработной плате. <sub>🇧🇷 pt-BR</sub>

### ⏱️ Продуктивность и организация

- [Notion](https://www.notion.com/) - Рабочее пространство для заметок, вики, задач и баз данных.
- [Obsidian](https://obsidian.md/) - Приложение Note на локальном Markdown со ссылками между заметками и плагинами.
- [Logseq](https://logseq.com/) - Приложение с открытым исходным кодом, ориентированное на конфиденциальность.
- [Joplin](https://joplinapp.org/) - Приложение с открытым исходным кодом с синхронизацией и шифрованием.
- [Anytype](https://anytype.io/) - Заметки, задачи и базы данных с данными, хранящимися на устройстве.

### ♿ Доступность

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) - Рекомендация W3C, определяющая критерии доступности веб-контента. <sub>📖 документация</sub>
- [WCAG 2.1 em português](https://www.w3c.br/traducoes/wcag/wcag21-pt-BR/) - Официальный перевод на португальский язык руководящих принципов WCAG 2.1, подготовленный компанией W3C Brasil. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [W3C WAI](https://www.w3.org/WAI/) - Портал W3C Web Accessibility Initiative Portal с руководствами по профилю. <sub>📖 документация</sub>
- [eMAG](https://emag.governoeletronico.gov.br/) - Модель доступности в электронном правительстве, бразильский справочник на основе WCAG. <sub>📖 документация · 🇧🇷 pt-BR</sub>
- [Lei Brasileira de Inclusão](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2015/lei/l13146.htm) - Закон 13146/2015, который гарантирует права людей с ограниченными возможностями, включая цифровой доступ. <sub>📖 документация · 🇧🇷 pt-BR</sub>
