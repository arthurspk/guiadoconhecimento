### 💎 Главное по ИИ

- [IA para seu novo emprego: do currículo à entrevista (Fundação Bradesco)](https://www.ev.org.br/cursos/iaempregos) - Бесплатный 2-часовой курс, на португальском языке и сертифицированный, об использовании ИИ для просмотра учебного плана, профиля LinkedIn, ключевых слов и подготовки к собеседованию. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [FluêncIA em Inteligência Artificial (Fundação Bradesco + Microsoft)](https://www.ev.org.br/cursos/fluencia) - Бесплатный 4-часовой курс на португальском языке с основами искусственного интеллекта для работы; хорошая отправная точка для любой профессии. <sub>🎓 курс · 🇧🇷 pt-BR</sub>
- [Orientação da Anthropic sobre uso de IA por candidatos](https://www.anthropic.com/candidate-ai-guidance) - Пример четкого правила компании: ИИ может помочь просмотреть приложение и подготовиться, но он не может использоваться в живых тестах и интервью без разрешения; читайте правила каждого процесса. <sub>📖 документация</sub>
- [Resume Matcher](https://github.com/srbhr/Resume-Matcher) - Инструмент с открытым исходным кодом, который сравнивает резюме с описанием вакансий и предлагает корректировки; работает локально с Ollama, не отправляя ваши данные третьим лицам.
- [Reactive Resume](https://github.com/AmruthPillai/Reactive-Resume) - Бесплатный редактор учебных программ с открытым исходным кодом, самоорганизующийся, с дополнительной интеграцией в модели ИИ (OpenAI, Gemini, Claude) для просмотра текстов.
- [Jobscan](https://www.jobscan.co) - Проверка учебного плана по системам сортировки (ATS), которые сравнивают ключевые слова с вакансиями; имеет бесплатное ограниченное использование и платный план.
- [Teal](https://www.tealhq.com) - résumé builder с ИИ и трекером приложений; бесплатный план без карт и платные расширенные функции.
- [Roadmap de AI Engineer (roadmap.sh)](https://roadmap.sh/ai-engineer) - Бесплатный и интерактивный скрипт шаг за шагом для тех, кто хочет перенести свою карьеру в ИИ-инжиниринг.
- [aijobs.net](https://aijobs.net) - Вакансии, ориентированные на ИИ, машинное обучение и наука о данных с удаленными фильтрами и местоположением.
