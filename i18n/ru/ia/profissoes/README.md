## 🔎 Как составляется список

> Отбор автоматический и воспроизводимый, ничего не пишется вручную.

- Запросы для каждой профессии хранятся в `data/repos-ia-consultas.json`, сгруппированные по темам.
- Скрипт `scripts/coletar_repos_ia.py` обращается к публичному поиску GitHub и сортирует результаты по звёздам.
- Попадают только активные репозитории с описанием, с явным признаком ИИ в названии, описании или топиках, и не входящие в список блокировки (контент для взрослых, пиратство, обман).
- Звёзды указаны на день сбора данных. Один репозиторий может встречаться в нескольких профессиях.
