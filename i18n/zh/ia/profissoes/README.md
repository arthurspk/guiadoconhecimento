## 🔎 列表是如何生成的

> 筛选过程自动完成且可复现；没有任何内容是手写的。

- 每个职业的查询条件保存在 `data/repos-ia-consultas.json` 中，按主题分组。
- 脚本 `scripts/coletar_repos_ia.py` 调用 GitHub 的公开搜索，并按星标数排序。
- 只收录活跃的、有描述的仓库，且名称、描述或话题中要有明确的 AI 标志，同时不在屏蔽名单内（成人内容、盗版、作弊）。
- 星标数为采集当天的数据。同一个仓库可能出现在多个职业中。
