## 🎨 前端开发工程师

> 构建人们在浏览器中使用的界面。

1. **[🎨 前端](../areas/tecnologia/front-end.md)**: HTML、CSS、JavaScript、框架、无障碍和 Web 性能。
2. **[🔤 编程语言](../areas/tecnologia/linguagens.md)**: Python、JavaScript、Java、Go、Rust、C#、PHP、Kotlin、Swift 以及其他数十种语言。
3. **[🖌️ UI/UX 设计](../areas/criacao/design-ui-ux.md)**: 界面设计、UX 研究、设计系统和原型制作。
4. **[♿ 无障碍](../areas/carreira/acessibilidade.md)**: 数字无障碍、辅助技术和包容性。
5. **[🛠️ 开发者工具](../areas/tecnologia/ferramentas-dev.md)**: 编辑器、Git、终端、效率工具和开发实用程序。
6. **[✅ QA 与测试](../areas/tecnologia/qa-testes.md)**: 自动化测试、手动测试、性能测试、移动端测试和软件质量。
7. **[🎁 免费资源](../areas/ferramentas/recursos-gratuitos.md)**: 图库、图标、字体、配色、mockup 和模板。
8. **[💼 职业发展与求职](../areas/carreira/carreira-vagas.md)**: 职位、简历、面试、职业发展路线图和薪资。

## ⚙️ 后端开发工程师

> 创建 API、业务逻辑、系统集成，以及运行在服务器上的一切。

1. **[⚙️ 后端](../areas/tecnologia/back-end.md)**: API、服务端框架、身份认证、消息队列和微服务。
2. **[🔤 编程语言](../areas/tecnologia/linguagens.md)**: Python、JavaScript、Java、Go、Rust、C#、PHP、Kotlin、Swift 以及其他数十种语言。
3. **[🗄️ 数据库](../areas/tecnologia/bancos-de-dados.md)**: SQL、NoSQL、建模、优化和运维管理。
4. **[🏛️ 软件架构与工程](../areas/tecnologia/arquitetura-software.md)**: 系统设计、设计模式、整洁代码、DDD 和可扩展性。
5. **[☁️ DevOps 与云](../areas/tecnologia/devops-cloud.md)**: CI/CD、容器、Kubernetes、IaC、AWS、Azure、GCP 和 SRE。
6. **[✅ QA 与测试](../areas/tecnologia/qa-testes.md)**: 自动化测试、手动测试、性能测试、移动端测试和软件质量。
7. **[🔗 公共 API](../areas/ferramentas/apis-publicas.md)**: 可用于项目、学习和原型的免费 API。
8. **[🐧 Linux、系统与终端](../areas/tecnologia/sistemas-linux.md)**: Linux、shell、系统管理和命令行。
