### 🖌️ UI/UX 设计

- [Figma](https://www.figma.com/) - 市场标准协作工具用于接口设计,原型化和与自由计划交接.
- [Penpot](https://penpot.app/) - 替代Figma的开源,在浏览器中运行,可以自行托管.
- [Laws of UX](https://lawsofux.com/) - 用于界面设计的心理学主要定律和heuristics的集合.
- [Nielsen Norman Group - Artigos](https://www.nngroup.com/articles/) - 基于可用性研究,UX研究和互动设计的文章和视频.
- [Material Design 3](https://m3.material.io/) - Google设计系统,包含接口的准则,组件和符号. <sub>📖 文档</sub>

→ [查看 UI/UX 设计 的全部 193 个链接](./design-ui-ux.md)

### 🖍️ 平面设计与插画

- [GIMP](https://www.gimp.org/) - 自由自由图像编辑器,用于重修,组成和图形创作.
- [Inkscape](https://inkscape.org/) - 开源矢量图形编辑器,替代 Illustrator.
- [Krita](https://krita.org/) - 开源数码绘画与插图程序.
- [Photopea](https://www.photopea.com/) - 浏览器中的图像编辑器与PSD,AI,Figma等格式兼容.
- [Affinity](https://www.affinity.studio/) - 专业套房设计,照片和图表制作,免费供个人使用.

→ [查看 平面设计与插画 的全部 213 个链接](./design-grafico.md)

### 🎞️ 视频剪辑

- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - 专业编辑器有编辑,色彩分级,VFX和音频在一个工具中免费版本.
- [Treinamento oficial DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve/training) - PDF书籍和免费的Blackmagic视频课,有多个葡萄牙语单元. <sub>🎓 课程</sub>
- [Kdenlive](https://kdenlive.org/) - KDE 开源视频编辑器带有多相机,色彩分级和自动字幕.
- [Shotcut](https://www.shotcut.org/) - 免费多平台视频编辑器,并使用多种格式的本土编辑.
- [OpenShot](https://www.openshot.org/) - 简单开源视频编辑器,用于初学者,带有键框和效果.

→ [查看 视频剪辑 的全部 209 个链接](./edicao-de-video.md)

### 🪄 影音素材

- [Lutify.me Free LUTs](https://lutify.me/free-luts/) - 免费的Primee, DaVinci 解析,最后剪辑和照片shop 兼容的电影LUT.
- [Juan Melara - Print Film Emulation LUTs](https://juanmelara.com.au/blog/print-film-emulation-luts-for-download) - 免费复制胶片仿真LUT(Kodak 2383 and Fujifilm 3510),并解释如何使用. <sub>📄 学术论文</sub>
- [Fresh LUTs](https://freshluts.com/) - 社区存储器用于搜索,下载和发送其他配色师创建的LUT.
- [ARRI LUT Generator](https://www.arri.com/en/learn-help/learn-help-camera-system/tools/lut-generator) - 官方的ARRI工具生成LUT从LogC3转换到设置和后生产.
- [Panasonic LUT Library (V-Log)](https://av.jpn.support.panasonic.com/support/global/cs/dsc/download/lut/index.html) - Panasonic官方网站有LUTs用于V-Log录制的Lumix相机上的材料.

### 📷 摄影

- [darktable](https://www.darktable.org/) - RAW开发商和开源照片管理器,替代Lightroom.
- [RawTherapee](https://www.rawtherapee.com/) - 开源RAW文件处理器,拥有32位引擎和高级控制.
- [digiKam](https://www.digikam.org/) - 开源照片收藏管理器,带有面部识别和高级搜索功能.
- [Unsplash](https://unsplash.com/) - 优质照片库免费持证.
- [Pexels](https://www.pexels.com/) - 照片和视频的自由库,界面为葡萄牙语.

→ [查看 摄影 的全部 187 个链接](./fotografia.md)

### 🧊 动态设计、3D 与动画

- [Blender Studio](https://studio.blender.org/) - 课程,公开电影和Blender基金会的制作文件,每集订阅部分内容. <sub>🎓 课程</sub>

- [Poly Haven](https://polyhaven.com/) - 公共领域的免费纹理,HDRIs和3D模型.

### 🎧 音频、音乐与播客

- [Audacity](https://www.audacityteam.org/) - 免费音频编辑器,用于录音、剪辑、清理噪音和输出音频。
- [REAPER](https://www.reaper.fm/) - 轻而易举地完成DAW,拥有廉价的许可证和扩展的自由评价.
- [Ardour](https://ardour.org/) - DAW 用于多轨录制,编辑和混合的开源.
- [LMMS](https://lmms.io/) - 免费音乐制作站设有测序器,合成器和钢琴卷.
- [BandLab](https://www.bandlab.com/) - 在浏览器和移动机上制作音乐的自由平台,Cakewalk的拥有者.
