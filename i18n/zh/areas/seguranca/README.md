### 🛡️ 网络安全

- [Cartilha de Segurança para Internet (CERT.br)](https://cartilha.cert.br/) - 免费的巴西材料,有关于骗局,密码,恶意软件和数据保护的分册. <sub>🇧🇷 pt-BR</sub>
- [CERT.br](https://www.cert.br/) - 巴西对事件的国家反应,包括统计、良好做法和材料。 <sub>🇧🇷 pt-BR</sub>
- [OWASP Top 10](https://top10.owasp.org/) - 网络应用中最重大安全风险列表. <sub>📖 文档</sub>
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) - 免费网络安全培训与理论和实践实验室. <sub>🎓 课程</sub>
- [Hacker101](https://www.hacker101.com/) - 黑客One的免费网络安全和CTF课程,旨在bug赏金. <sub>🎓 课程</sub>

### 🔎 OSINT 与调查

- [OSINT Framework](https://github.com/lockfale/osint-framework) - 按调查数据类型排列的OSINT工具互动地图.
- [Bellingcat](https://www.bellingcat.com/) - 组织调查性新闻工作,这是公开来源调查中的世界参考。
- [Bellingcat Online Investigation Toolkit](https://bellingcat.gitbook.io/toolkit) - 审查研究工具目录,附有使用指南。
- [Guias da Bellingcat](https://www.bellingcat.com/category/resources/how-tos/) - 实用地理定位教程,卫星图像与验证.
- [Abraji](https://abraji.org.br/) - 巴西调查新闻协会,提供课程和评估指南。 <sub>👥 社区 · 🇧🇷 pt-BR</sub>

### 🕶️ 隐私与数据保护

- [LGPD - Lei 13.709/2018](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm) - 《一般个人资料保护法》的正式文本和更新文本。 <sub>📖 文档 · 🇧🇷 pt-BR</sub>
- [ANPD](https://www.gov.br/anpd/pt-br) - 国家数据保护局,设指南,规章和报告渠道. <sub>🇧🇷 pt-BR</sub>
- [Curso de Introdução à LGPD (Escola Virtual.Gov)](https://www.escolavirtual.gov.br/curso/153) - 联邦政府关于LGPD的开放和自由路线,并附有证书. <sub>🎓 课程 · 🇧🇷 pt-BR</sub>
- [Cartilha CERT.br - Fascículos](https://cartilha.cert.br/fasciculos/) - 关于隐私,数据保护,社交网络和泄密的免费分册. <sub>🇧🇷 pt-BR</sub>
- [Surveillance Self-Defense (EFF)](https://ssd.eff.org/pt-br) - EFF指南在葡萄牙语保护自己免受数字监控. <sub>🇧🇷 pt-BR</sub>
