- [DAX Guide](https://dax.guide/) - 充分参考Power BI和Excel中使用的DAX语言函数和运算符. <sub>📖 文档</sub>
- [Fundação Bradesco - Escola Virtual](https://www.ev.org.br/) - 免费的在线课程,有证书,包括从基础到高级的Excel. <sub>🎓 课程 · 🇧🇷 pt-BR</sub>
- [Hashtag Treinamentos](https://www.youtube.com/@HashtagTreinamentos) - 巴西频道,开设Excel、Power BI、SQL和Python等课程,供劳动力市场使用。 <sub>📺 频道 · 🇧🇷 pt-BR</sub>

### 🔀 数据工程

- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) - 自由开放的航线与多克,Terraform,dbt,Spark和Kafka一起建造了完整的管道. <sub>🎓 课程</sub>
- [roadmap.sh - Data Engineer](https://roadmap.sh/data-engineer) - 互动脚本比学习成为数据工程师.
- [Microsoft Learn - Engenheiro de Dados](https://learn.microsoft.com/pt-br/training/career-paths/data-engineer) - 官方和免费的葡萄牙小径,在阿苏雷设有数据工程模块. <sub>🎓 课程 · 🇧🇷 pt-BR</sub>
- [Designing Data-Intensive Applications](https://dataintensive.net/) - 马丁·克莱普曼(Martin Kleppmann)的著作"分布式数据系统,存储和流传的基本原理". <sub>📚 书籍</sub>
- [Big Book of Data Engineering](https://www.databricks.com/resources/ebook/big-book-of-data-engineering) - 数据砖免费电子书,有管道和湖屋的图案和实际案例. <sub>📚 书籍</sub>

### 🧠 数据科学与 Machine Learning

- [Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) - 来自斯坦福和DeepLlearning.AI的经典ML入门课程,可免费注册. <sub>🎓 课程</sub>
- [Machine Learning Crash Course (Google)](https://developers.google.com/machine-learning/crash-course) - Google免费实用课程,内容包括视频,互动观点和练习. <sub>🎓 课程</sub>
- [Practical Deep Learning for Coders (fast.ai)](https://course.fast.ai/) - 自由深层学习课程适用于已经进行节目的人,有PyTorch和fatai. <sub>🎓 课程</sub>
- [An Introduction to Statistical Learning](https://www.statlearning.com/) - 统计学学习中的参考文献,有免费PDF和R版及Python版. <sub>📚 书籍</sub>
- [Dive into Deep Learning](https://d2l.ai/) - 在PyTorch,TensorFlow和JAX中带有可执行代码的交互式和免费深层学习本. <sub>📚 书籍</sub>

### 🗃️ 数据集与开放数据

- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 巴西联邦政府官方开放数据目录. <sub>🇧🇷 pt-BR</sub>
- [Base dos Dados](https://basedosdados.org/) - 公共数据Lake有数百个巴西数据库经过处理并准备用于SQL,Python和R. <sub>🇧🇷 pt-BR</sub>

- [SIDRA - IBGE](https://sidra.ibge.gov.br/) - IBGE系统,用于查阅和下载研究表格、人口普查和索引。 <sub>🇧🇷 pt-BR</sub>
