## ⭐ 从这里开始

> 公共 API 的精选链接，由策展人亲自挑选：如果你只有时间看几个链接，就从这些开始。

- [Public APIs](https://github.com/public-apis/public-apis) - 最著名的自由API列表,按类别排列.
- [BrasilAPI](https://brasilapi.com.br/) - 免费API,包含CEP,CNPJ,银行,节假日,FIPE等巴西数据. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - 在JSON或XML中免费提供CEP查询的网络服务. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - 交换系列,Selic,Pix和信用与API访问. <sub>📖 文档 · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - 联邦政府开放数据集目录. <sub>🇧🇷 pt-BR</sub>
- [API do Portal da Transparência](https://api.portaldatransparencia.gov.br/) - API拥有支出数据,合同和联邦政府服务器. <sub>📖 文档 · 🇧🇷 pt-BR</sub>
- [Dados Abertos da Câmara](https://dadosabertos.camara.leg.br/) - API拥有议员,选票,提案和众议院开支. <sub>📖 文档 · 🇧🇷 pt-BR</sub>
- [AwesomeAPI](https://docs.awesomeapi.com.br/) - 自由巴西Coin Quote API和CEP. <sub>🇧🇷 pt-BR</sub>
- [JSONPlaceholder](https://github.com/typicode/jsonplaceholder) - 免费假的REST API用于测试和原型.
- [PokéAPI](https://pokeapi.co/) - 免费的REST和GraphQL API与Pokémon数据,非常适合学习.
- [REST Countries](https://restcountries.com/) - 国家数据:人口,货币,语言,旗帜.
- [Open-Meteo](https://open-meteo.com/) - 自由,无键气候 API 具有预览和历史.
- [OpenWeather](https://openweathermap.org/api) - 天气API对当前天气和预报有免费计划.
- [NASA Open APIs](https://api.nasa.gov/) - 免费NASA APIs,比如当天的天文照片和火星的图像.
