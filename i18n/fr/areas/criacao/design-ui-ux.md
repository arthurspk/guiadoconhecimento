## 🤖 L'IA pour Design UI/UX

> Outils, skills, MCP, cours, guides de prompts et usage responsable de l'IA pour celles et ceux qui travaillent dans Design UI/UX. Voir aussi [🤖 L'IA pour tous les domaines](../../ia/README.md).

### 💎 Essentiels de l'IA

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Documentation du serveur officiel MCP de Figma, qui donne aux agents d'IA le contexte des fichiers de conception pour générer du code et éditer la toile; une large utilisation nécessite Dev ou Full… <sub>📖 documentation</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Dépôt officiel de Figma avec guide d'installation et compétences pour les agents (conception de la mise en œuvre, générer une bibliothèque, règles du système de conception) à l'aide de Figma MCP.
- [Figma Make](https://www.figma.com/make/) - La ressource Figma AI qui transforme les invites et les cadres en prototypes fonctionnels avec code; inclus dans les plans Figma, avec une part de crédits d'IA.
- [Google Stitch](https://stitch.withgoogle.com/) - L'expérience de Google Labs qui génère des interfaces app et web à partir de texte ou d'image, avec exportation vers Figma et code.
- [Framer AI](https://www.framer.com/ai/) - Créateur de site Web avec agent d'IA en toile, qui crée et modifie des pages réactives à partir des instructions; libre de commencer, publication professionnelle rémunérée.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - Serveur MCP open source qui envoie les styles de mise en page et de fichiers Figma à Cursor, Claude Code et d'autres agents implémentent les écrans plus fidèlement.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Serveur MCP intégré Penpot, outil de conception open source qui permet aux agents d'IA de lire et de créer des éléments dans les fichiers de conception.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Compétence officielle de Claude qui guide la création d'interfaces avec une direction visuelle définie, évitant l'aspect générique typique des pages générées par l'IA.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Commandes de compétences et de conception pour les agents de code, avec des règles automatiques qui détectent les biais visuels communs dans les front-ends générés par l'IA.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Compétence basée sur des styles de recherche, palettes, paires typographiques et lignes directrices UX pour les agents à générer des interfaces sur plusieurs cadres.
- [The Shape of AI](https://www.shapeof.ai/) - Librairie gratuite de normes UX pour les produits AI (entrées, ajustements, contrôles, signes de confiance), utile pour concevoir des interfaces ressources IA.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Guide gratuit de Google pour concevoir des produits d'IA centrés sur les personnes avec des modèles sur les attentes, l'explication, la rétroaction et les erreurs. <sub>📖 documentation</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Collecte d'articles NN/g et études sur l'IA en UX : recherche avec l'AI, conception de chatbot et divulgation de l'utilisation de l'IA; articles gratuits, cours payants.
