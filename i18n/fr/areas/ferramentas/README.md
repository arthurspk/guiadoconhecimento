## ⭐ Un aperçu de chaque domaine

> Les premiers essentiels de chaque domaine de ce secteur, pour vous donner une idée du contenu de chaque page.

### 🌍 Outils en ligne

- [iLovePDF](https://www.ilovepdf.com/pt) - Outils en ligne pour joindre, diviser, compresser et convertir des PDF. <sub>🇧🇷 pt-BR</sub>
- [PDF24 Tools](https://tools.pdf24.org/pt/) - Collection gratuite d'outils PDF dans le navigateur, sans limites artificielles. <sub>🇧🇷 pt-BR</sub>
- [CloudConvert](https://cloudconvert.com/) - Convertisseur de fichiers en ligne avec support pour plus de 200 formats.
- [TinyPNG](https://tinypng.com/) - Compresse les images PNG, JPEG et WebP tout en maintenant la qualité visuelle.
- [Squoosh](https://squoosh.app/) - Compresseur d'image Google fonctionnant localement dans le navigateur.

→ [Voir les 297 liens de Outils en ligne](./ferramentas-online.md)

### 🪄 Outils d'IA

- [ChatGPT](https://chatgpt.com/) - OpenAI AI Wizard pour texte, code, images et recherche.
- [Claude](https://claude.ai/) - Assistante anthropique de l'IA pour la rédaction, l'analyse et la programmation.
- [Gemini](https://gemini.google.com/) - Assistant AI de Google intégré dans les services du compte Google.
- [Microsoft Copilot](https://copilot.microsoft.com/) - Assistant Microsoft AI gratuit pour la création de chat et d'image.
- [Perplexity](https://www.perplexity.ai/) - Rechercher avec AI qui répond en citant les sources.

→ [Voir les 268 liens de Outils d'IA](./ferramentas-ia.md)

### 🏠 Self-hosted

- [awesome-selfhosted.net](https://awesome-selfhosted.net/) - Navigable version de la liste principale de logiciels pour vous héberger.
- [selfh.st](https://selfh.st/) - Bulletin hebdomadaire et répertoire d'applications auto-organisées.
- [Docker Docs](https://docs.docker.com/) - Documentation officielle Docker, base de la plupart des installations auto-accueillées. <sub>📖 documentation</sub>
- [LinuxServer.io](https://www.linuxserver.io/) - Images Docker standard et documentées pour des dizaines d'applications.
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) - Ouvrez la plateforme de virtualisation pour les serveurs domestiques et professionnels.

→ [Voir les 299 liens de Self-hosted](./self-hosted.md)

### 🖥️ Applis pour macOS, Windows et Linux

- [AlternativeTo](https://alternativeto.net/) - Trouver des alternatives à n'importe quel programme, filtrer par système et licence.
- [Homebrew](https://brew.sh/) - Gestionnaire de paquets pour macOS et Linux.
- [WinGet](https://learn.microsoft.com/pt-br/windows/package-manager/winget/) - Gestionnaire de paquets Windows officiel par ligne de commande. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [Scoop](https://scoop.sh/) - Installation du programme Windows via la ligne de commande, pas de UAC.
- [Ninite](https://ninite.com/) - Installez et mettez à jour plusieurs programmes Windows en même temps, sans barre d'outils.

→ [Voir les 298 liens de Applis pour macOS, Windows et Linux](./apps-sistemas.md)

### 📲 Applis pour Android et iOS

- [F-Droid](https://f-droid.org/) - Gratuit et open source Android app store.
- [Obtainium](https://obtainium.imranr.dev/) - Installez et mettez à jour les applications Android directement depuis les pages de sortie (GitHub, GitLab).
- [Aurora OSS](https://auroraoss.com/) - Projet Aurora Store, client open source alternatif pour le Play Store.
- [Signal](https://signal.org/) - Messager avec chiffrement de bout en bout, pas d'annonces et aucun suivi.
- [Organic Maps](https://organicmaps.app/) - Cartes hors ligne avec navigation, sentiers et aucun suivi basé sur OpenStreetMap.

→ [Voir les 208 liens de Applis pour Android et iOS](./apps-celular.md)

### 🧩 Extensions de navigateur

- [uBlock Origin](https://ublockorigin.com/) - Léger, bloqueur d'annonces open source et trackers.
- [Privacy Badger](https://github.com/EFForg/privacybadger) - Extension du FEP qui apprend et bloque les trackers invisibles.
- [Dark Reader](https://darkreader.org/) - Appliquer le mode sombre sur n'importe quel site, avec des réglages de luminosité et de contraste.
- [SponsorBlock](https://github.com/ajayyy/SponsorBlock) - Saute automatiquement des extraits sponsorisés sur les vidéos YouTube.
- [Return YouTube Dislike](https://github.com/Anarios/return-youtube-dislike) - Rejouer le nombre estimé de disques sur YouTube.

→ [Voir les 207 liens de Extensions de navigateur](./extensoes-navegador.md)

### 🔗 API publiques

- [Public APIs](https://github.com/public-apis/public-apis) - La liste la plus connue des API gratuites, organisée par catégorie.
- [BrasilAPI](https://brasilapi.com.br/) - API gratuite avec CEP, CNPJ, banques, jours fériés, FIPE et autres données brésiliennes. <sub>🇧🇷 pt-BR</sub>
- [ViaCEP](https://viacep.com.br/) - Service web gratuit de la requête du CEP en JSON ou XML. <sub>🇧🇷 pt-BR</sub>
- [Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/) - Série Exchange, Selic, Pix et crédit avec accès API. <sub>📖 documentation · 🇧🇷 pt-BR</sub>
- [Portal Brasileiro de Dados Abertos](https://dados.gov.br/) - Catalogue des ensembles de données ouvertes du gouvernement fédéral. <sub>🇧🇷 pt-BR</sub>

→ [Voir les 298 liens de API publiques](./apis-publicas.md)

### ⚡ Automatisation et no-code

- [n8n](https://n8n.io/) - Automatisation du flux avec éditeur visuel et code, qui peut être auto-organisé.
- [Zapier](https://zapier.com/) - Automatisation sans code reliant des milliers d'applications.
- [Make](https://www.make.com/) - Automatisation visuelle des flux avec des milliers d'intégrations et de plan libre.
- [IFTTT](https://ifttt.com/) - Déclenchement simple et automatismes d'action entre les applications et la maison intelligente.
- [Node-RED](https://nodered.org/) - Programmation de flux visuel pour intégrer les API, appareils et services.
