## 🔎 Comment la liste est constituée

> La sélection est automatique et reproductible ; rien n'est écrit à la main.

- Les requêtes de chaque métier se trouvent dans `data/repos-ia-consultas.json`, regroupées par thème.
- Le script `scripts/coletar_repos_ia.py` interroge la recherche publique de GitHub et trie par étoiles.
- Seuls les dépôts actifs sont retenus, avec une description, un signal clair d'IA dans le nom, la description ou les topics, et absents d'une liste de blocage (contenu pour adultes, piratage, triche).
- Les étoiles sont celles du jour de la collecte. Un dépôt peut apparaître dans plusieurs métiers.
