### 💎 KI-Essentials

- [Figma MCP Server (documentação oficial)](https://developers.figma.com/docs/figma-mcp-server/) - Dokumentation des offiziellen Figma MCP-Servers, der KI-Agenten den Kontext von Designdateien zur Generierung von Code und Bearbeitung von Canvas bietet; eine breite Verwendung erfordert Dev oder… <sub>📖 Dokumentation</sub>
- [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) - Offizielles Figma-Repository mit Installationsanleitung und Fähigkeiten für Agenten (Implementieren von Design, Generieren von Bibliotheken, Entwurfssystemregeln) unter Verwendung von Figma MCP.
- [Figma Make](https://www.figma.com/make/) - Figma AI-Ressource, die Eingabeaufforderungen und Frames in funktionale Prototypen mit Code umwandelt; in den Figma-Plänen enthalten, mit einem Anteil an KI-Credits.
- [Google Stitch](https://stitch.withgoogle.com/) - Google Labs Experiment, das App- und Webschnittstellen aus Text oder Bild generiert, mit Export nach Figma und Code.
- [Framer AI](https://www.framer.com/ai/) - Website-Builder mit KI-Agent in Canvas, der responsive Seiten aus Anweisungen erstellt und bearbeitet; kostenlos zu starten, bezahlte professionelle Veröffentlichung.
- [Framelink Figma MCP (GLips/Figma-Context-MCP)](https://github.com/GLips/Figma-Context-MCP) - MCP Open Source Server, der Figma-Layout und Dateistile an Cursor sendet, implementiert Claude Code und andere Agenten Bildschirme zuverlässiger.
- [Penpot MCP](https://github.com/penpot/penpot/tree/develop/mcp) - Penpot-integrierter MCP Server, ein Open Source Design Tool, mit dem KI Agenten Elemente in den Designdateien lesen und erstellen können.
- [frontend-design (skill da Anthropic)](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Claudes offizielle Fähigkeit, die das Erstellen von Schnittstellen mit definierter visueller Richtung leitet und den typischen generischen Look der durch KI generierten Seiten vermeidet.
- [Impeccable (pbakaus/impeccable)](https://github.com/pbakaus/impeccable) - Fertigkeits- und Designbefehle für Codeagenten mit automatischen Regeln, die häufige visuelle Verzerrungen in Frontends erkennen, die von KI generiert werden.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Fähigkeiten basierend auf durchsuchbaren Stilen, Paletten, typografischen Paaren und UX-Richtlinien für Agenten zur Erstellung von Schnittstellen über mehrere Frameworks hinweg.
- [The Shape of AI](https://www.shapeof.ai/) - Kostenlose Bibliothek von UX-Standards für KI-Produkte (Einträge, Anpassungen, Kontrollen, Vertrauenszeichen), die nützlich sind, um IA-Ressourcenschnittstellen zu entwerfen.
- [People + AI Guidebook (Google PAIR)](https://pair.withgoogle.com/guidebook/) - Googles kostenloser Leitfaden zum Entwerfen von personenzentrierten KI-Produkten mit Mustern über Erwartungen, Erklärungen, Feedback und Fehler. <sub>📖 Dokumentation</sub>
- [Nielsen Norman Group: Artificial Intelligence](https://www.nngroup.com/topic/ai/) - Sammlung von NN / g-Artikeln und Studien über KI in UX: Forschung mit AI, Chatbot Design und Offenlegung der Nutzung von KI; kostenlose Artikel, kostenpflichtige Kurse.
