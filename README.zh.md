## 🎯 项目宗旨

> **Guia do Conhecimento** 是一份开放、免费的知识地图：**55357 个链接**，组织为 **9 个行业**、**72 个领域**和 **38 个职业**，让**任何人**都能找到自己领域中最好的网站、课程、工具、仓库、awesome 列表、社区和实用程序：开发、数据、安全、设计、视频剪辑、电影、摄影、音乐、营销、付费流量、销售、金融、法律、健康、科学、教育、语言等。每个领域都从**精选链接**开始，包含一个**面向该职业的人工智能应用**章节，随后是社区中最佳精选列表的链接。每个职业还配有 **1000 个 AI 仓库**。每个链接都有说明，整个指南提供 **12 种语言**版本。

- 🗂️ [领域目录](i18n/zh/areas/CATALOGO.md): 全部 72 个领域，按行业划分，并附链接数量。
- 🧭 [职业学习路径](i18n/zh/trilhas/README.md): 38 条学习路径，从前端开发者到 filmmaker，从流量投放运营到教师。
- 🧠 [按职业划分的 AI 仓库](i18n/zh/ia/profissoes/README.md): 38000 个 AI 仓库，每个职业 1000 个。

## 💡 本指南的组织方式

> 三个层级，从整体到具体：**行业**（例如：设计与创作）→ **领域**（例如：视频剪辑）→ **主题**（例如：非线性编辑软件）。每个领域是一个页面，包含目录、一个 **⭐ 从这里开始**章节、一个 **🤖 AI** 章节，以及按数量从多到少排序的主题，每个主题都有自己的说明。所有内容来自一个开放数据库（`data/links.jsonl`），并由 Python 脚本生成，因此整个指南可以重新生成、验证和扩充。其组织方式沿用了 [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) 和 [guiadomaestri](https://github.com/arthurspk/guiadomaestri) 指南。

## 📜 可用脚本

| 脚本 | 功能 |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | 下载精选列表（使用 Scrapling，git 作为备用），并提取每个链接的名称、说明和主题。 |

## 🛠️ 重新生成与验证

> 生成和验证只需要 Python 3 标准库。Scrapling 可以改进采集，Argos Translate 负责翻译。

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```
