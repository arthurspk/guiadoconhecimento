<h1 align="center">Guia do Conhecimento</h1>

## 🎯 Das Konzept

> Der **Guia do Conhecimento** ist eine offene, kostenlose Wissenslandkarte: **55357 Links**, geordnet in **9 Sektoren**, **72 Bereiche** und **38 Berufe**, damit **jeder** die besten Websites, Kurse, Tools, Repositories, Awesome-Listen, Communities und Hilfsmittel für das eigene Fachgebiet findet: Entwicklung, Daten, Sicherheit, Design, Videoschnitt, Film, Fotografie, Musik, Marketing, bezahlter Traffic, Vertrieb, Finanzen, Recht, Gesundheit, Wissenschaft, Bildung, Sprachen und vieles mehr. Jeder Bereich beginnt mit **handverlesenen Essentials**, enthält einen Abschnitt zu **künstlicher Intelligenz, angewandt auf diesen Beruf**, und folgt mit den Links der besten kuratierten Listen der Community. Jeder Beruf hat zudem **1000 KI-Repositories**. Jeder Link hat eine Beschreibung, und der gesamte Guide ist in **12 Sprachen** verfügbar.

- 🗂️ [Katalog der Bereiche](i18n/de/areas/CATALOGO.md): alle 72 Bereiche, nach Sektor, mit Linkzahl.
- 🧭 [Lernpfade nach Beruf](i18n/de/trilhas/README.md): 38 Lernpfade, vom Front-end-Entwickler bis zum Filmmaker, vom Traffic-Manager bis zur Lehrkraft.
- 🧠 [KI-Repositories nach Beruf](i18n/de/ia/profissoes/README.md): 38000 KI-Repositories, 1000 für jeden Beruf.

## 💡 Wie dieser Guide aufgebaut ist

> Drei Ebenen, vom Allgemeinen zum Speziellen: **Sektor** (z. B. Design und Kreation) → **Bereich** (z. B. Videoschnitt) → **Thema** (z. B. nichtlineare Schnittprogramme). Jeder Bereich ist eine Seite mit Inhaltsverzeichnis, einem Abschnitt **⭐ Hier starten**, einem Abschnitt **🤖 KI** und den Themen, vom größten zum kleinsten sortiert, jeweils mit eigener Beschreibung. Alles stammt aus einer offenen Datenbasis (`data/links.jsonl`) und wird von Python-Skripten erzeugt, sodass der gesamte Guide neu generiert, validiert und erweitert werden kann. Der Aufbau folgt dem der Guides [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) und [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Verfügbare Skripte

> Alles wird mit Python erzeugt. Keine Seite wird von Hand bearbeitet.

| Skript | Funktion |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Lädt die kuratierten Listen herunter (Scrapling, mit git als Rückfall) und extrahiert jeden Link mit Name, Beschreibung und Thema. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normalisiert, dedupliziert, wendet die Lizenzrichtlinie an, verlangt eine Beschreibung und wählt die Links jedes Bereichs mit Obergrenze und Wechsel zwischen den Quellen aus. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Sucht auf GitHub die KI-Repositories jedes Berufs, 1000 pro Beruf. |
| [`scripts/descrever.py`](scripts/descrever.py) | Holt die öffentliche Beschreibung der Repositories, die noch keine haben. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Übersetzt Beschreibungen und Themen in die Sprachen des Guides, offline, mit offenen Modellen. |
| [`scripts/gerar.py`](scripts/gerar.py) | Erzeugt das README, die Seiten für Sektoren, Bereiche, Lernpfade und KI in allen Sprachen, den Katalog und die CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Prüft, ob die Links antworten, und markiert defekte. |
| [`tests/validar.py`](tests/validar.py) | Prüft Daten, Seiten, Anker, Beschreibungen, Sprachen und Zählungen. |

## 🛠️ Neu generieren und validieren

> Zum Generieren und Validieren ist nur die Standardbibliothek von Python 3 nötig. Scrapling verbessert die Erhebung, und Argos Translate übernimmt die Übersetzung.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```

## 🤝 Mitwirken

> Vorschläge sind sehr willkommen: ein fehlender Link, ein neuer Bereich, ein Lernpfad, eine bessere Übersetzung.

- **Neuer Link:** Tragen Sie ihn in `data/essenciais.json` ein (wenn er zu den Essentials des Bereichs gehört) oder schlagen Sie eine **kuratierte Liste** in `data/fontes.json` vor. Starten Sie danach den Generator.
- **Defekter Link oder schlechte Übersetzung:** Eröffnen Sie ein Issue mit der Adresse der Seite und dem Link.
- Schritt für Schritt in [docs/08 · Mitwirken](docs/08-como-contribuir.md) und in [CONTRIBUTING.md](CONTRIBUTING.md).
