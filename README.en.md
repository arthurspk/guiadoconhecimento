<h1 align="center">Guia do Conhecimento</h1>

## 🎯 The idea

> **Guia do Conhecimento** is a free, open knowledge map: **55357 links** organized into **9 sectors**, **72 areas**, and **38 professions**, so that **anyone** can find the best websites, courses, tools, repositories, awesome lists, communities, and utilities for their field: development, data, security, design, video editing, film, photography, music, marketing, paid traffic, sales, finance, law, health, science, education, languages, and much more. Each area starts with **hand-picked essentials**, includes a section on **artificial intelligence applied to that profession**, and continues with links from the community's best curated lists. Each profession also has **1000 AI repositories**. Every link has a description, and the whole guide is available in **12 languages**.

- 🗂️ [Area catalog](i18n/en/areas/CATALOGO.md): all 72 areas, by sector, with link counts.
- 🧭 [Learning paths by profession](i18n/en/trilhas/README.md): 38 learning paths, from front-end developer to filmmaker, from traffic manager to teacher.
- 🧠 [AI repositories by profession](i18n/en/ia/profissoes/README.md): 38000 AI repositories, 1000 for each profession.

## 💡 How this guide is organized

> Three levels, from general to specific: **sector** (e.g., Design and Creative) → **area** (e.g., Video Editing) → **topic** (e.g., Non-linear editors). Each area is a page with a table of contents, a **⭐ Start here** section, a **🤖 AI** section, and topics ordered from largest to smallest, each with its own description. Everything comes from an open database (`data/links.jsonl`) and is generated by Python scripts, so the whole guide can be regenerated, validated, and expanded. The organization follows that of the [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) and [guiadomaestri](https://github.com/arthurspk/guiadomaestri) guides.

## 📜 Available scripts

> Everything is generated by Python. No page is edited by hand.

| Script | What it does |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Downloads the curated lists (Scrapling, with git as a fallback) and extracts each link with its name, description, and topic. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normalizes, deduplicates, applies the license policy, requires a description, and picks the links for each area with a cap and rotation among sources. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Searches GitHub for the AI repositories of each profession, 1000 per profession. |
| [`scripts/descrever.py`](scripts/descrever.py) | Fetches the public description of repositories that were left without one. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Translates descriptions and topics into the guide's languages, offline, using open models. |
| [`scripts/gerar.py`](scripts/gerar.py) | Generates the README, the sector, area, learning path, and AI pages in every language, the catalog, and the CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Checks that links respond and flags the broken ones. |
| [`tests/validar.py`](tests/validar.py) | Checks data, pages, anchors, descriptions, languages, and counts. |

## 🛠️ Regenerate and validate

> Only the Python 3 standard library is required to generate and validate. Scrapling improves collection, and Argos Translate handles translation.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```
