<h1 align="center">Guia do Conhecimento</h1>

## 🎯 A proposta

> O **Guia do Conhecimento** é um mapa de conhecimento aberto e gratuito: **55357 links** organizados em **9 setores**, **72 áreas** e **38 profissões**, para que **qualquer pessoa** encontre os melhores sites, cursos, ferramentas, repositórios, listas awesome, comunidades e utilitários da sua área: desenvolvimento, dados, segurança, design, edição de vídeo, cinema, fotografia, música, marketing, tráfego pago, vendas, finanças, direito, saúde, ciência, educação, idiomas e muito mais. Cada área começa com **essenciais escolhidos a dedo**, traz uma seção de **inteligência artificial aplicada àquela profissão** e segue com os links das melhores listas curadas da comunidade. Cada profissão tem ainda **1000 repositórios de IA**. Todo link tem descrição, e o guia inteiro está em **12 idiomas**.

- 🗂️ [Catálogo de áreas](areas/CATALOGO.md): todas as 72 áreas, por setor, com a contagem de links.
- 🧭 [Trilhas por profissão](trilhas/README.md): 38 trilhas, de desenvolvedor(a) front-end a filmmaker, de gestor(a) de tráfego a professor(a).
- 🧠 [Repositórios de IA por profissão](ia/profissoes/README.md): 38000 repositórios de IA, 1000 para cada profissão.

## 💡 Como este guia é organizado

> Três níveis, do geral ao específico: **setor** (ex.: Design e Criação) → **área** (ex.: Edição de Vídeo) → **tópico** (ex.: Editores não lineares). Cada área é uma página com índice, uma seção **⭐ Comece por aqui**, uma seção **🤖 IA** e os tópicos ordenados do maior para o menor, cada um com a sua descrição. Tudo vem de uma base de dados aberta (`data/links.jsonl`) e é gerado por scripts em Python, então o guia inteiro pode ser regenerado, validado e ampliado. A organização segue a dos guias [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) e [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Scripts disponíveis

> Tudo é gerado por Python. Nenhuma página é editada à mão.

| Script | O que faz |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Baixa as listas curadas (Scrapling, com git como reserva) e extrai cada link com nome, descrição e tópico. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normaliza, deduplica, aplica a política de licenças, exige descrição e escolhe os links de cada área com teto e rodízio entre fontes. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Busca no GitHub os repositórios de IA de cada profissão, 1000 por profissão. |
| [`scripts/descrever.py`](scripts/descrever.py) | Busca a descrição pública dos repositórios que ficaram sem descrição. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Traduz descrições e tópicos para os idiomas do guia, offline, com modelos abertos. |
| [`scripts/gerar.py`](scripts/gerar.py) | Gera o README, as páginas de setor, área, trilha e IA em todos os idiomas, o catálogo e o CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Confere se os links respondem e marca os quebrados. |
| [`tests/validar.py`](tests/validar.py) | Confere dados, páginas, âncoras, descrições, idiomas e contagens. |

## 🛠️ Regenerar e validar

> Só a stdlib do Python 3 é obrigatória para gerar e validar. O Scrapling melhora a coleta, e o Argos Translate faz a tradução.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```

## 🤝 Contribuição

> Sugestões são muito bem-vindas: um link que faltou, uma área nova, uma trilha, uma tradução melhor.

- **Link novo:** adicione em `data/essenciais.json` (se é essencial da área) ou sugira uma **lista curada** em `data/fontes.json`. Depois rode o gerador.
- **Link quebrado ou tradução ruim:** abra uma issue com o endereço da página e o link.
- Passo a passo em [docs/08 · Como contribuir](docs/08-como-contribuir.md) e em [CONTRIBUTING.md](CONTRIBUTING.md).
