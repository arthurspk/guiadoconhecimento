<h1 align="center">Guia do Conhecimento</h1>

## 🎯 الفكرة

> **Guia do Conhecimento** خريطة معرفية مفتوحة ومجانية: **55357 رابطًا** منظمة في **9 قطاعات** و**72 مجالًا** و**38 مهنة**، ليجد **أي شخص** أفضل المواقع والدورات والأدوات والمستودعات وقوائم awesome والمجتمعات والأدوات المساعدة في مجاله: التطوير والبيانات والأمن والتصميم ومونتاج الفيديو والسينما والتصوير والموسيقى والتسويق والإعلانات المدفوعة والمبيعات والمالية والقانون والصحة والعلوم والتعليم واللغات وغيرها الكثير. يبدأ كل مجال بـ**روابط أساسية منتقاة بعناية**، ويضم قسمًا عن **الذكاء الاصطناعي المطبّق على تلك المهنة**، ثم يتبعه بروابط أفضل القوائم المنتقاة من المجتمع. ولكل مهنة أيضًا **1000 مستودع للذكاء الاصطناعي**. لكل رابط وصف، والدليل كله متاح بـ**12 لغة**.

- 🗂️ [فهرس المجالات](i18n/ar/areas/CATALOGO.md): جميع المجالات الـ 72، مقسمة حسب القطاع، مع عدد الروابط.
- 🧭 [مسارات التعلّم حسب المهنة](i18n/ar/trilhas/README.md): 38 مسارًا، من مطوّر Front-end إلى صانع الأفلام، ومن مدير الإعلانات المدفوعة إلى المعلم.
- 🧠 [مستودعات الذكاء الاصطناعي حسب المهنة](i18n/ar/ia/profissoes/README.md): 38000 مستودعًا للذكاء الاصطناعي، 1000 لكل مهنة.

## 💡 كيف يُنظَّم هذا الدليل

> ثلاثة مستويات، من العام إلى الخاص: **القطاع** (مثل: التصميم والإبداع) ← **المجال** (مثل: مونتاج الفيديو) ← **الموضوع** (مثل: برامج المونتاج غير الخطي). كل مجال صفحة فيها فهرس وقسم **⭐ ابدأ من هنا** وقسم **🤖 الذكاء الاصطناعي** والموضوعات مرتبة من الأكبر إلى الأصغر، ولكل منها وصفه. كل شيء مصدره قاعدة بيانات مفتوحة (`data/links.jsonl`) وتولّده سكربتات Python، لذلك يمكن إعادة توليد الدليل كله والتحقق منه وتوسيعه. ويتبع تنظيمه تنظيم دليلَي [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) و[guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 السكربتات المتاحة

> كل شيء يُولَّد بواسطة Python. ولا تُحرَّر أي صفحة يدويًا.

| السكربت | وظيفته |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | ينزّل القوائم المنتقاة (عبر Scrapling، مع git بديلًا) ويستخرج كل رابط باسمه ووصفه وموضوعه. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | يوحّد الصيغ ويزيل التكرار ويطبّق سياسة التراخيص ويشترط وجود وصف، ثم يختار روابط كل مجال بحد أقصى وبالتناوب بين المصادر. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | يبحث في GitHub عن مستودعات الذكاء الاصطناعي لكل مهنة، بواقع 1000 لكل مهنة. |
| [`scripts/descrever.py`](scripts/descrever.py) | يجلب الوصف العام للمستودعات التي بقيت بلا وصف. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | يترجم الأوصاف والموضوعات إلى لغات الدليل، دون اتصال بالإنترنت، بنماذج مفتوحة. |
| [`scripts/gerar.py`](scripts/gerar.py) | يولّد README وصفحات القطاعات والمجالات والمسارات والذكاء الاصطناعي بجميع اللغات، والفهرس وملف CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | يتحقق من استجابة الروابط ويضع علامة على المعطلة منها. |
| [`tests/validar.py`](tests/validar.py) | يتحقق من البيانات والصفحات والروابط الداخلية والأوصاف واللغات والأعداد. |

## 🛠️ إعادة التوليد والتحقق

> المكتبة القياسية لـ Python 3 وحدها كافية للتوليد والتحقق. يحسّن Scrapling عملية الجمع، ويتولى Argos Translate الترجمة.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```
