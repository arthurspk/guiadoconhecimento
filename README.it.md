<h1 align="center">Guia do Conhecimento</h1>

## 🎯 L'idea

> **Guia do Conhecimento** è una mappa della conoscenza aperta e gratuita: **55357 link** organizzati in **9 settori**, **72 aree** e **38 professioni**, perché **chiunque** trovi i migliori siti, corsi, strumenti, repository, liste awesome, community e utility del proprio campo: sviluppo, dati, sicurezza, design, montaggio video, cinema, fotografia, musica, marketing, traffico a pagamento, vendite, finanza, diritto, salute, scienza, istruzione, lingue e molto altro. Ogni area parte da **essenziali scelti a mano**, offre una sezione di **intelligenza artificiale applicata a quella professione** e prosegue con i link delle migliori liste curate dalla community. Ogni professione ha inoltre **1000 repository di IA**. Ogni link ha una descrizione, e l'intera guida è disponibile in **12 lingue**.

- 🗂️ [Catalogo delle aree](i18n/it/areas/CATALOGO.md): tutte le 72 aree, per settore, con il conteggio dei link.
- 🧭 [Percorsi per professione](i18n/it/trilhas/README.md): 38 percorsi, da Front-end Developer a filmmaker, da traffic manager a insegnante.
- 🧠 [Repository di IA per professione](i18n/it/ia/profissoes/README.md): 38000 repository di IA, 1000 per ogni professione.

## 💡 Come è organizzata questa guida

> Tre livelli, dal generale allo specifico: **settore** (es.: Design e Creatività) → **area** (es.: Montaggio Video) → **argomento** (es.: Editor non lineari). Ogni area è una pagina con indice, una sezione **⭐ Parti da qui**, una sezione **🤖 IA** e gli argomenti ordinati dal più grande al più piccolo, ciascuno con la propria descrizione. Tutto proviene da una base di dati aperta (`data/links.jsonl`) ed è generato da script in Python, quindi l'intera guida può essere rigenerata, validata e ampliata. L'organizzazione segue quella delle guide [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) e [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Script disponibili

> Tutto è generato da Python. Nessuna pagina viene modificata a mano.

| Script | Cosa fa |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Scarica le liste curate (Scrapling, con git come riserva) ed estrae ogni link con nome, descrizione e argomento. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normalizza, deduplica, applica la politica delle licenze, richiede la descrizione e sceglie i link di ogni area con un limite e una rotazione tra le fonti. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Cerca su GitHub i repository di IA di ogni professione, 1000 per professione. |
| [`scripts/descrever.py`](scripts/descrever.py) | Recupera la descrizione pubblica dei repository rimasti senza descrizione. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Traduce descrizioni e argomenti nelle lingue della guida, offline, con modelli aperti. |
| [`scripts/gerar.py`](scripts/gerar.py) | Genera il README, le pagine di settore, area, percorso e IA in tutte le lingue, il catalogo e il CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Verifica se i link rispondono e segna quelli interrotti. |
| [`tests/validar.py`](tests/validar.py) | Controlla dati, pagine, ancore, descrizioni, lingue e conteggi. |

## 🛠️ Rigenerare e validare

> Per generare e validare basta la stdlib di Python 3. Scrapling migliora la raccolta, e Argos Translate si occupa della traduzione.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```
