# 02 · Organização e taxonomia

> O guia tem três níveis: **setor → área → tópico**. Esta página explica cada nível, a lista completa de setores e áreas, e como decidir onde um link novo entra.

[🏠 Início](../README.md) · [🗂️ Catálogo de áreas](../areas/CATALOGO.md)

## Os três níveis

- **Setor:** um grande campo de atuação (ex.: *Marketing e Vendas*). São 9.
- **Área:** uma profissão, disciplina ou tipo de recurso dentro do setor (ex.: *Tráfego Pago*). Cada área tem uma página.
- **Tópico:** um assunto dentro da área (ex.: em *Edição de Vídeo*, *Non-Linear Editors* e *Audio Plugins*). Os tópicos vêm dos cabeçalhos das listas curadas de origem; nomes equivalentes (singular e plural, maiúsculas, pontuação) viram um só dentro de cada área, e cada página mostra até 15 tópicos com pelo menos 6 links (o resto fica em *Mais links*).

A fonte da verdade é [`data/taxonomia.json`](../data/taxonomia.json): para criar ou renomear uma área, edite esse arquivo e rode o gerador.

## Por que esses 9 setores

A divisão segue como as pessoas procuram conhecimento: pela profissão (tecnologia, criação, marketing, negócios), pelo campo de estudo (ciência, saúde, educação), pela carreira (vagas, produtividade, comunidades) e pela necessidade prática (ferramentas e utilitários). Ferramentas e recursos gratuitos têm setor próprio porque servem a todo mundo.

## Onde um link entra

1. **É de uma profissão ou disciplina?** Vai para a área dela (um tutorial de color grading vai para *Edição de Vídeo*).
2. **É uma ferramenta geral, usada por qualquer pessoa?** Vai para o setor *Ferramentas e Utilitários* (um conversor de PDF vai para *Ferramentas Online*).
3. **Serve a duas áreas?** Pode aparecer nas duas. Dentro de uma mesma área, nunca aparece duas vezes.
4. **É um recurso de carreira (vaga, currículo, comunidade)?** Vai para o setor *Carreira e Produtividade*, mesmo que seja de uma área técnica.
