# 01 · Como usar este guia

> O guia é um mapa: você não precisa ler tudo, só achar o caminho até o que precisa. Esta página mostra os três jeitos de navegar e o que significa cada símbolo.

[🏠 Início](../README.md) · [🗂️ Catálogo de áreas](../areas/CATALOGO.md) · [🧭 Trilhas](../trilhas/README.md)

## Três jeitos de navegar

1. **Pela profissão:** abra as [Trilhas por profissão](../trilhas/README.md). Cada trilha lista, em ordem, as áreas que importam para aquela carreira, com os primeiros links de cada uma.
2. **Pelo assunto:** abra o [Catálogo de áreas](../areas/CATALOGO.md) e vá direto para a área. Cada setor também tem uma página de resumo (ex.: [Design e Criação](../areas/criacao/README.md)).
3. **Pela busca:** dentro de uma página de área, `Ctrl+F` (ou `Cmd+F`). Para buscar no guia inteiro, use a busca do GitHub no repositório, ou abra [`data/links.csv`](../data/links.csv) numa planilha e filtre por área, tipo, idioma ou palavra.

## Como é uma página de área

- **Cabeçalho:** o que a área cobre e quantos links tem.
- **📚 Índice:** os tópicos da página, com a quantidade de links em cada um.
- **⭐ Comece por aqui:** de 12 a 20 links escolhidos a dedo, com descrição em português. Se você só tem 10 minutos, fique aqui.
- **◾ Tópicos:** os demais links, agrupados pelo tópico da lista curada de onde vieram, do maior para o menor. Tópicos muito pequenos ficam juntos em **Mais links**.
- **🧾 Fontes desta área:** as listas de onde os links vieram, com licença e quantidade.

## Símbolos

| Símbolo | Significado |
|---|---|
| <sub>pt-BR</sub> | Conteúdo em português. |
| <sub>curso</sub>, <sub>canal</sub>, <sub>livro</sub>, <sub>comunidade</sub>, <sub>app</sub> | O tipo do link, quando não é um site comum. |
| <sub>lista awesome</sub> | Outra lista curada: um bom ponto para ir mais fundo. |
| `<sub>N</sub>` no índice | Quantos links o tópico tem. |

## Como estudar com o guia

- **Escolha pouco.** Um curso, uma documentação e uma comunidade valem mais que cinquenta abas abertas.
- **Pratique cedo.** Quase toda área tem uma seção de exercícios, desafios ou projetos: comece por ela assim que tiver o básico.
- **Use as trilhas como ordem, não como obrigação.** Pule áreas que você já domina.
- **Desconfie de tudo que promete atalho.** O guia aponta para conteúdo gratuito e de referência sempre que existe.
