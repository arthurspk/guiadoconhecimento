<h1 align="center">Guia do Conhecimento</h1>

## 🎯 Идея

> **Guia do Conhecimento** это открытая бесплатная карта знаний: **ссылок: 55357**, организованных по **сферам: 9**, **направлениям: 72** и **профессиям: 38**, чтобы **каждый** мог найти лучшие сайты, курсы, инструменты, репозитории, awesome-списки, сообщества и утилиты в своей области: разработка, данные, безопасность, дизайн, видеомонтаж, кино, фотография, музыка, маркетинг, платный трафик, продажи, финансы, право, здравоохранение, наука, образование, языки и многое другое. Каждое направление начинается с **главного, отобранного вручную**, содержит раздел об **искусственном интеллекте в этой профессии** и продолжается ссылками из лучших кураторских списков сообщества. Кроме того, для каждой профессии есть **1000 репозиториев ИИ**. У каждой ссылки есть описание, а весь гид доступен на **языках: 12**.

- 🗂️ [Каталог направлений](i18n/ru/areas/CATALOGO.md): все направления (72) по сферам, с числом ссылок.
- 🧭 [Маршруты обучения по профессиям](i18n/ru/trilhas/README.md): маршрутов: 38, от front-end-разработчика до filmmaker, от трафик-менеджера до преподавателя.
- 🧠 [Репозитории ИИ по профессиям](i18n/ru/ia/profissoes/README.md): репозиториев ИИ: 38000, по 1000 на каждую профессию.

## 💡 Как организован этот гид

> Три уровня, от общего к частному: **сфера** (напр., Дизайн и творчество) → **направление** (напр., Видеомонтаж) → **тема** (напр., Нелинейные редакторы). Каждое направление это страница с содержанием, разделом **⭐ Начните здесь**, разделом **🤖 ИИ** и темами, упорядоченными от самой большой к самой малой, у каждой есть своё описание. Всё берётся из открытой базы данных (`data/links.jsonl`) и генерируется скриптами на Python, поэтому весь гид можно пересоздать, проверить и расширить. Организация следует гидам [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) и [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Доступные скрипты

> Всё генерируется на Python. Ни одна страница не редактируется вручную.

| Скрипт | Что делает |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Скачивает кураторские списки (Scrapling, с запасным вариантом через git) и извлекает каждую ссылку с названием, описанием и темой. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Нормализует, дедуплицирует, применяет политику лицензий, требует описание и выбирает ссылки для каждого направления с лимитом и чередованием источников. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Ищет на GitHub репозитории ИИ для каждой профессии, по 1000 на профессию. |
| [`scripts/descrever.py`](scripts/descrever.py) | Получает публичное описание репозиториев, у которых его не оказалось. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Переводит описания и темы на языки гида офлайн, с помощью открытых моделей. |
| [`scripts/gerar.py`](scripts/gerar.py) | Генерирует README, страницы сфер, направлений, маршрутов и ИИ на всех языках, каталог и CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Проверяет, отвечают ли ссылки, и помечает нерабочие. |
| [`tests/validar.py`](tests/validar.py) | Проверяет данные, страницы, якоря, описания, языки и подсчёты. |

## 🛠️ Пересоздание и проверка

> Для генерации и проверки обязательна только stdlib Python 3. Scrapling улучшает сбор данных, а Argos Translate выполняет перевод.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```

## 🤝 Участие

> Предложения очень приветствуются: пропущенная ссылка, новое направление, маршрут, лучший перевод.

- **Новая ссылка:** добавьте её в `data/essenciais.json` (если это главная ссылка направления) или предложите **кураторский список** в `data/fontes.json`. Затем запустите генератор.
- **Нерабочая ссылка или плохой перевод:** создайте issue с адресом страницы и ссылкой.
- Пошаговая инструкция в [docs/08 · Как внести вклад](docs/08-como-contribuir.md) и в [CONTRIBUTING.md](CONTRIBUTING.md).
