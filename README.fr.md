<h1 align="center">Guia do Conhecimento</h1>

## 🎯 L'objectif

> **Guia do Conhecimento** est une carte du savoir ouverte et gratuite : **55357 liens** organisés en **9 secteurs**, **72 domaines** et **38 métiers**, pour que **tout le monde** trouve les meilleurs sites, cours, outils, dépôts, listes awesome, communautés et utilitaires de son domaine : développement, données, sécurité, design, montage vidéo, cinéma, photographie, musique, marketing, trafic payant, ventes, finance, droit, santé, sciences, éducation, langues et bien plus. Chaque domaine commence par des **essentiels sélectionnés à la main**, propose une section d'**intelligence artificielle appliquée à ce métier** et se poursuit avec les liens des meilleures listes de référence de la communauté. Chaque métier dispose en plus de **1000 dépôts d'IA**. Chaque lien est accompagné d'une description, et le guide entier est disponible en **12 langues**.

- 🗂️ [Catalogue des domaines](i18n/fr/areas/CATALOGO.md): les 72 domaines, par secteur, avec le nombre de liens.
- 🧭 [Parcours par métier](i18n/fr/trilhas/README.md): 38 parcours, de développeur front-end à filmmaker, de traffic manager à enseignant.
- 🧠 [Dépôts d'IA par métier](i18n/fr/ia/profissoes/README.md): 38000 dépôts d'IA, 1000 pour chaque métier.

## 💡 Comment ce guide est organisé

> Trois niveaux, du général au particulier : **secteur** (ex. : Design et Création) → **domaine** (ex. : Montage vidéo) → **sujet** (ex. : Logiciels de montage non linéaire). Chaque domaine est une page avec un sommaire, une section **⭐ Commencez ici**, une section **🤖 IA** et les sujets classés du plus fourni au moins fourni, chacun avec sa description. Tout provient d'une base de données ouverte (`data/links.jsonl`) et est généré par des scripts Python : le guide entier peut donc être régénéré, validé et enrichi. L'organisation suit celle des guides [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil) et [guiadomaestri](https://github.com/arthurspk/guiadomaestri).

## 📜 Scripts disponibles

> Tout est généré par Python. Aucune page n'est modifiée à la main.

| Script | Rôle |
|---|---|
| [`scripts/coletar.py`](scripts/coletar.py) | Télécharge les listes de référence (Scrapling, avec git en secours) et extrait chaque lien avec son nom, sa description et son sujet. |
| [`scripts/selecionar.py`](scripts/selecionar.py) | Normalise, déduplique, applique la politique de licences, exige une description et choisit les liens de chaque domaine avec un plafond et une rotation entre les sources. |
| [`scripts/coletar_repos_ia.py`](scripts/coletar_repos_ia.py) | Recherche sur GitHub les dépôts d'IA de chaque métier, 1000 par métier. |
| [`scripts/descrever.py`](scripts/descrever.py) | Récupère la description publique des dépôts restés sans description. |
| [`scripts/traduzir.py`](scripts/traduzir.py) | Traduit les descriptions et les sujets dans les langues du guide, hors ligne, avec des modèles ouverts. |
| [`scripts/gerar.py`](scripts/gerar.py) | Génère le README, les pages de secteur, de domaine, de parcours et d'IA dans toutes les langues, le catalogue et le CSV. |
| [`scripts/checar_links.py`](scripts/checar_links.py) | Vérifie que les liens répondent et marque ceux qui sont cassés. |
| [`tests/validar.py`](tests/validar.py) | Vérifie les données, les pages, les ancres, les descriptions, les langues et les totaux. |

## 🛠️ Régénérer et valider

> Seule la bibliothèque standard de Python 3 est requise pour générer et valider. Scrapling améliore la collecte, et Argos Translate assure la traduction.

```bash
python3 scripts/coletar.py            # → data/brutos.jsonl.gz
python3 scripts/descrever.py          # → data/descricoes.json
python3 scripts/selecionar.py         # → data/links.jsonl
python3 scripts/coletar_repos_ia.py   # → data/repos-ia.jsonl
python3 scripts/traduzir.py           # → data/i18n/desc.<idioma>.json.gz
python3 scripts/gerar.py              # → README*, areas/, trilhas/, ia/, i18n/
python3 tests/validar.py              # → "OK"
```
